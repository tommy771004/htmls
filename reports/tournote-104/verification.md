# 寓約 TourNote / App 104 驗證

日期：2026-09-27。範圍：`app/104-tournote.html` 與作品集 App 註冊。

版面來源：[Nizam 的 Schedule flow](https://x.com/nizamdesign/status/2103759673833009156)。在 Chrome 查看三張參考圖：行程、詳情、預約抽屜。保留暖灰底、日期膠囊、時間軸、白色預約卡、黃色跟進便條與底部抽屜；中文內容與虛構房源另行編寫，室內圖改為內嵌 SVG 示意。依既有專案約定使用單檔、系統字與零外部資源。

## 已通過

- Chrome 桌機 1440×900、手機 390×844、較小手機 375×667；頁面無水平溢出，小螢幕抽屜可捲動到表單底部。
- 日期切換與零行程空狀態；新增預約能出現在正確日期，帶看方式同步至詳情。
- 已占用時段停用；若預設時段已有預約，送出會顯示錯誤且不新增。
- 重新安排後詳情更新為 15:30—16:00；標記完成後有恢復狀態按鈕。
- 編輯便條後，在跟進清單及重新載入後仍可讀到相同內容；改期與完成狀態同樣保留。
- 房源清單與房源詳情可開啟；Escape 關閉預約抽屜並回到原觸發按鈕。
- App 分頁顯示 104 件；理財商務分類加上 TourNote 搜尋，只顯示新增作品；縮圖成功載入，內嵌 iframe 顯示帶看行程。
- 新頁面 Chrome error/warn 記錄為空；Node JavaScript 語法檢查、sitemap XML 與唯一性、App 區段註冊與索引連結檢查通過；`git diff --check` 通過。
- 靜態檢查確認沒有外部腳本、圖片、字型或 fetch／XHR／WebSocket 依賴。
