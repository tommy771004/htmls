# 雪夜五月廣場（266）

- 單檔 `web/266-eternauta-plaza.html`，沒有 build。場景 splat、玩家 FBX 與動畫從上游 santisiri/eternauta-online 的 GitHub 固定版本即時下載（Spark 2.3.1 + Three.js 0.186.0 由 CDN 載入）。
- 延伸玩法（任務、喪屍、士兵與金屬人、武器、裝備、巡邏車與公車亭等道具）用到的 `.spz` 在 `assets/266/`：網路上沒有授權清楚的喪屍／武器 splat，所以由 `games/266-eternauta-plaza/tools/bake.mjs` 把 Quaternius 與 Poly Haven 的 CC0 模型、以及 Sketchfab 的 CC BY 模型（重新綁到 Quaternius 骨架，作者列在同資料夾的 `CREDITS.md` 與頁面 `.credit`，要保留）在無頭 Chrome 裡烘焙成 SPZ v2；喪屍另有 `.skin`（Spark `SplatSkinning` 權重）與 `manifest.json` 裡的骨架和動畫。改了烘焙參數要重跑並 commit `assets/266/`。`npm start` 的伺服器已能送出 `.spz`、`.skin`。
- 任務的英文無線電導引語音是 `assets/266/voice/*.wav`（8 kHz 單聲道，只在 http(s) 下載）：台詞在 `games/266-eternauta-plaza/tools/voice-lines.json`，`tools/voice.py` 用 Kokoro-82M 離線合成；對講機音色在頁面的 `radio()`／`voPump()` 即時加。改台詞要重跑並 commit 產出的 WAV。
- 三個室內場景在頁面的 `ROOMS`，放在同一個 three 場景的 400 m 外，第一次進門才下載：聖堂野戰醫院是 splat（`scene: true` 烘焙進 `manifest.json` 的 `scenes`）；地鐵站＋列車是網格 `assets/266/metro.glb`（`tools/room-glb.mjs` 合併原檔，低面數貼圖模型烘成 splat 會糊，所以不烘），真實站名與品牌在那支腳本裡換素色或模糊；街角便利店 `assets/266/store.glb` 也是網格（借 260 處理過的 `apt_store.glb`，解開 meshopt 後用 `cut` 剪掉門洞碎片與店招、`matRe` 一次模糊整批商品包裝）。廣場的棄置車輛、軍方檢查哨、街道設施與球棒／狙擊槍／手榴彈同樣借自 260 的模型烘成 splat（`PROPS`／`PROP_BOX`、`WEAPONS`、`NADE`），作者照抄 `assets/260/CREDITS.md`。`PRIM_RAW` 只留 splat 裡看得到的東西（splat 沒畫出來的柱子、樹拿掉了，不然會撞到空氣）；`PROP_BOX` 的盒子可帶第 7 個值（盒子自己的偏航）。換場走 `setWorld()`（交換尋路網格 `NAVS`、切換 splat／光暈／雪／道具、收回喪屍）；碰撞盒由 `tools/room-col.mjs` 從原始網格柵格化後貼進 `ROOMS.<id>.prims`，門洞與車門用 `carve` 清開。
- 效能：道具與武器的 PackedSplats 用 `lod: true`（和場景共用 LoD 預算；喪屍不行，蒙皮權重照原始順序），`GPU_TIERS` 依 GPU 名稱給 splat 預算、像素比上限與 Spark 排序間隔（排序的 GPU 回讀是卡頓主因），`adapt()` 每半秒依掉幀與頓挫調預算，`perfHold()` 在場景到達、進場、換場時暫停判斷；`webglcontextlost` 回到開場畫面請玩家重新載入。
- Esc 選單（`#menu`，左邊任務與戰績、右邊設定／操作／關於三個分頁）沿用開始畫面的版面與除錯面板的 `.sl`／`.sw`，設定存在 `localStorage` 的 `eter266.settings`（`SET_DEF`、`setApply(k)`）；完整素材來源在「關於」分頁的 `.credit-full`，開始畫面只留一行聲明。HUD 與開始畫面的文字都不墊卡片，靠文字陰影撐可讀性。
- 格式、來源與指令見 `games/266-eternauta-plaza/README.md`；`window.__eter` 的 `spawn`／`give`／`mission(i 或 id)`／`god`／`clear(x, z)`／`enter(id)`／`menuOpen()` 可直接擺場景測試。
