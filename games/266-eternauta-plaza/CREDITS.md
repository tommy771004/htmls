# 266 雪夜五月廣場 · 素材來源

`assets/266/` 裡的 `.spz`／`.skin` 都是由 `tools/bake.mjs` 從下列網格模型取樣烘焙出來的 Gaussian splat。烘焙時改了顏色（喪屍化的膚色、軍服壓暗、金屬鏽斑、積雪），並重新綁到 Quaternius 的骨架上；原始模型不在 repo 裡（放在 gitignore 的 `.cache/`）。
