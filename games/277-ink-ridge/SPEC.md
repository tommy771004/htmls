# 墨嶺行 · 美術與玩法規格（步驟 A）

依使用者提供的參考影片（@xikhar 2026-11-04 發的 97 秒實機錄影，`ref/contact-sheet.jpg` 每 4 秒一張，`ref/key-frames.jpg` 為石階、庭院、攀崖三張放大）量出來的數字。之後每一關都照這份做；要改先改這裡。

參考只用來定畫風、世界觀與主角外觀。關卡配置、謎題與文字都是本作自己的，不照抄影片的關卡。

## 2. 主角外觀

模型用 `assets/hero.glb`（改作自 xiamilisite 的 wuxia chinese swordman，CC BY 4.0，見 `tools/rig_hero.mjs`），貼圖降彩度 62% 融入水墨色。沒有模型時退回程式自建的旅人。

- 身高 1.75 m（碰撞體），斗笠半徑 0.35 m（量參考影片：直徑約肩寬 1.25 倍），原模型的斗笠放大而來。
- 白色長圍巾從左肩垂到前面膝蓋，另一端垂在背後，**兩段都是布料物理**。
- 腰帶以下一圈破損下緣的布（跑步時被腿撞開、跳躍時往上掀，不會翻過腰帶），也是布料物理。
- 左腰掛刀（黑鞘）、右腰掛葫蘆。出手時拔刀橫斬，收刀回鞘。

### 手（從參考影片逐段量的）

手有 5 組關節：手腕（彎曲、偏斜）、前臂旋轉、四指各三節（模型是拇指＋三指）。手勢由 `hero.js` 的 `curl`（握度 0–1）、`spr`（張開 0–1）、`tb`（拇指）決定：

| 情境 | 參考影片 | 數值 |
| --- | --- | --- |
| 站立 | 手指自然微彎，手臂稍離身體 | curl 0.42、spr 0.35、手腕 0.12 |
| 跑、走 | 半握拳 | curl 0.95、spr 0、拇指 0.9 |
| 空中 | 五指張開搆岩縫 | curl 0.16、spr 1、手腕後仰 0.25 |
| 掛邊 | 手腕折過岩緣、手掌壓在岩面、手指勾住，手肘微彎 | IK 釘住手腕，握距 ±0.31 m，手指朝壁面，curl 0.3 |
| 橫移 | 手一隻一隻換，不是一起平移 | 離原位 0.1 m 換手，0.15 秒，一次一隻 |
| 上攀、側跳 | 一手先伸到下一道岩縫 | 先伸的手早 0.22 秒到、中途五指張開 |
| 翻上 | 手掌撐在岩面、手留在原地 | IK 釘到進度 62% 才放開，手指張開 |
| 出手 | 右手全握刀柄，手腕順著刀；左手收成拳 | 右 curl 1、偏斜 0.7、前臂旋 0.75；左 curl 0.72 |
| 落地 | 手張開撐重心 | 依落地力道往 spr 0.8、curl 0.22 混合 |

掛邊時身體視覺上往壁面移 0.15 m、上提 0.06 m，頭往後仰 0.62 rad，斗笠才不會蓋住雙手。

## 6. 關卡結構（每關都照這個節奏）

1. **入口**：一段只有跑跳的路，讓玩家看到這關的「地標」（鳥居、吊台、遠方的塔）。
2. **教學段**：一個新機制，出現時字幕提示一次（畫面下方置中的斜體襯線字）。
3. **組合段**：新機制＋前面學過的動作。
4. **謎題**：機關（鐘、配重、吊台、門閂）。觸發後要有聲音＋鏡頭看得到的物理反饋。
5. **出口**：石燈籠（檢查點）＋山門。
6. 後段關卡再加入敵人（參考影片的出手是 J／左鍵橫斬），戰鬥規格到那時另寫一節。

每關最多 8 張概念圖，每張蓋成一個可玩區段；地標和配色要能和概念圖對起來。

## 7-2. 第二關「寒潭渡」（`?lv=2`）

概念圖還沒給，這關是用 §1 的語彙原創的：宣紙換成冷灰、朱紅水洗拿掉，山頂雲海換成會致死的黑水，積雪靠材質法線加上去（`inkMaterial({ snow })`）。朱紅只留給鳥居、機關板、石塊的封條與塔頂寶珠，玩家看到紅色就知道是路標或機關。本關不加敵人。

| 段 | 內容 | 練習 | 關鍵數值 |
| --- | --- | --- | --- |
| 壹 雪徑 | 兩道裂隙（1.6、1.8 m）、渡口鳥居、碼頭 | 回憶跑跳 | 掉水線 y<−1（重生回最後點亮的燈籠） |
| 貳 寒潭 | 站上木筏 0.6 秒開動，三根橫木橫跨峽谷 | 在移動平台上跳 | 木筏 2.6×5 m、2.4 m/s，約 13.5 秒；橫木 0.32 m 寬、頂 0.32，比踏階高，不跳會被掃下水；起跳繼承平台水平速度。原地跳要在接觸前約 0.1 秒內起跳，助跑跳很寬鬆，跳早了落在橫木上再踏下去也行 |
| 參 石庭 | 高台 3.8 m（地面跳不到）；推石塊到壁下墊腳抓邊。高台上機關板連閘門 | 推石、機關 | 推力 0.2 秒後 1.6 m/s，只走主軸，推的時候人會被吸到石塊中線；閘門開 1.2 秒、關 0.4 秒，人踩板跑不過，要把第二塊石頭推上板（人的判定 ±0.8 m、石塊 ±1.05 m） |
| 肆 冰壁 | 石縫 S1 → 冰縫 I1 → 側跳 I2 → 石縫 S2 → 壁頂 | 組合抓邊動作，加上時限 | 掛 1.5 秒開始裂、3 秒碎、3.5 秒長回來；離手後計時以一半速度回退 |
| 伍 雪塔 | 五層塔、終點燈籠 | — | — |

石塊規則：出手打中會回原位（解卡住的唯一方法，卡住時有提示）；掉下去 0.8 秒後回原位；原位被人或物占住就等到空出來。

設計檢查清單（這關踩過的）：

- 點亮燈籠只算水平距離，**檢查點要離隔壁區域的牆 2.6 m 以上**，否則隔牆點亮後跳水就繞過謎題。
- 寬路上的檢查點要設 `line`（走過燈籠的 z 就算點亮），重生點放回路徑中線，否則會漏點或一重生就走進水裡。
- 人物高度的霧要加 `fadeNear`，否則鏡頭穿進霧片會整畫面洗白。
- 機關的容差不要只比石塊會停的位置寬 2 cm，石塊路線上不要放障礙物。

## 8. 素材插槽

- `assets/scene.glb`（使用者的 Blender 重建場景）：存在就內嵌進單檔、取代程式自建的地形。名稱以 `col_` 開頭的物件當碰撞盒，`ledge_` 開頭的細長物件當可抓岩縫（取最長軸當邊）。
- `assets/hero.glb`：目前是 `tools/rig_hero.mjs` 的產出（scene extras 帶 `rig`，由程序動畫驅動骨頭）。若換成不帶 `rig` 的模型，會縮放到 1.75 m，並照 `idle`／`run`／`jump`／`fall`／`hang`／`shimmy`／`climb`／`strike` 動畫名稱播放。布料仍由程式模擬。
