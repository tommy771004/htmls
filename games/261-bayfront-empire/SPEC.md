# 261 灣岸商業帝國 — 規格

## 需求對照（海灘改版提示詞）

1. **新地圖區域**：沿海道路（雙黃線、斑馬線）→ 步道（棕櫚、路燈、長椅、公車亭）與深綠護欄（樓梯口與碼頭口斷開）→ 沙灘 → 海面。防波堤石塊斜插入海，租船碼頭是沙灘上的木平台加伸進海裡的棧橋，另有水上摩托車浮動碼頭與紅頂涼亭的觀景棧橋。海面 shader 畫浪推上濕沙、岸邊白浪、往岸推進的浪線與外海湧浪；船隻拖出 V 形航跡。
2. **新商家**：`boat`、`jetski`、`umbrella`、`snack`、`surf`，與城市商家同一份 `BIZ` 資料格式（價格、升級費、客單價、容量、停留時間、工資、營業時間、需求、天氣類別、客流曲線），走同一套 `arrivalPerMin` → `serve` → 任務／財務。升級在畫面上看得到：船與水上摩托車 2→4→6 艘、傘位 4→8→12、衝浪板架與小吃攤座位變多。
3. **海上活動**：環境帆船 5、遊艇 3、貨輪 1；出租船與水上摩托車在顧客上船後依停留時間跑一條隨機航線再回港；衝浪客划出去 → 等浪 → 站起來乘浪回岸；泳客與日光浴遊客依 `beachCrowd`（時段 × 天氣 × 活動）維持人數。顧客從住宅、公車站與步道兩端出發，經人行道與斑馬線走到沙灘。
4. **介面**：收入飄字 `+$4,830`（大額金色）、頂部資金卡（滾動數字與趨勢箭頭）、日期、評分環、帝國等級、遊戲時間卡與天氣圖示（晴／多雲／陰／雨／熱浪／夜間月亮）。
5. **效能與存檔**：見下方。

## 物流與海港改版

- **供應成本**：每位客人消費用掉 1 單位貨（`BIZ[].cargo` 為 `food`／`goods`／`fuel`），成本 ＝ 客單價 × `supply`（4%–27%）。沒有海港時一律以市價進貨，記在 `today.supply`。
- **海港**（`PORT`，`src/port.js`）：$950K 開港，$1.5M／$2.8M 擴建到冷鏈港、區域港。岸橋與泊位 1→2→3、物流車 2→4→6（每台每小時 50 單位）、批發折扣 22%／28%／34%、生鮮每日耗損 5%／1.6%／0.8%、每日營運成本 $14K／$22K／$34K。
- **補給船**：庫存＋在途低於補貨點時自動下單，補到補貨點的 2.5 倍；運費每艘 $5,000＋每櫃 $220，2–4.5 小時到港。狀態 `inbound → waiting（錨地等泊位）→ berthing（40 分鐘）→ unloading → departed`，下雨時航行中的船可能延誤 1–3 小時。每座岸橋每小時卸 3 櫃（每櫃 60 單位），卸下即入庫。
- **配送**：客人消費時若該類貨有庫存且本小時物流車額度未滿，就以批發價出貨並記 `today.saved`、`today.viaPort`；否則改回市價。每整點重置物流車額度、收倉儲費（每單位每天 $3）、扣生鮮耗損。
- **貨運合約**：開港後每 5–8 小時一份招標（最多 3 份，6–10 小時後截止），指導價每櫃 $4,500–8,000。得標機率 ＝ `1.02 − (出價/指導價 − 0.6) × 1.15 + (評分 − 70)/300`，夾在 4%–96%。得標後船進港卸貨，卸完一次收款；超過交期每小時扣 15%，最多扣 50%，評分 −4。
- **畫面**：防波堤西側 x −300…−140 的碼頭平台；岸橋小車與吊具在對應泊位有船卸貨時循環吊櫃；堆場貨櫃數 ＝ 庫存櫃數＋卸下中的合約櫃；貨櫃船位置由狀態與時間插值（每幀只讀經濟狀態，不存畫面專用資料）。
- **任務**：第 5 章「物流與海港」四個任務（開港、完成合約、單日省下 $40K、海港 Lv3）。

## 畫面風格（依影片對照）

- 暖色低彩度的插畫調：石板藍綠路面、奶油色人行道、鼠尾草綠草地，建築外牆用磚紅、芥末黃、霧藍、灰藍幾組，簷口與窗框一律奶油色。
- 城市是 2–4 層步登公寓，沿街一排、後面是後院（木圍籬、菜圃、樹、野餐桌）；已開設的城市商家改成剖面室內（`interior.js`），可直接看到地板、家具、店員與入座的客人。座位數至少等於各等級容量，客滿時多出來的客人才隱藏。
- Lv3 城市商家長出 F2：樓板懸在 F1 上方約 10 公尺（展開式剖面，黃色與鐵紅色細柱支撐），右前角是黃框玻璃電梯井，車廂依 12 秒循環上下，畫面上有 `F1 ▲ 2/4` 式的樓層指示與「F2 · 店名」標籤。F2 座位的客人在電梯口等車廂停靠才進出，路上與等電梯的時間從入座時間扣掉，所以容量佔用與 Lv1–2 相同。
- 夜景是偏藍的月光：月光強度足以投影，天空、地面反射光與夜間海面都往深藍調，亮窗、店內立燈與燈串維持暖色。
- 海面以淡青綠漸層加上沿海岸方向的短浪紋與飄過的雲影；海港岸橋為紅色桁架加深綠機房，另有紅白條紋管制塔與綠色大門門架。

## 時間與經濟

- 1 倍速下一遊戲分鐘 = 0.3 秒，一天約 7.2 分鐘；可暫停、1×、2×、4×。
- 來客率（每分鐘）＝ `demand × 0.13 × 等級吸引力(1／1.4／1.85) × 時段曲線 × 天氣倍率[kind] × 評分倍率(0.7–1.3) × 活動倍率`。容量滿或打烊時拒客，評分下降。
- 工資在每個整點扣 1/24；跨日時把當日營收、成本、投資寫進最近 7 天紀錄。
- 天氣每 2–5 小時依轉移表重抽；熱浪只出現在 9–15 時。週末（`day % 7` 為 6、0）海灘 +35%，其他日子可能有街區市集（城市 +25%）或海灘音樂節（海灘 +50%）。
- 起始資金 $250K。`npm run sim` 依任務順序購買時，約第 2 天開小吃攤、第 8–9 天開到租船與水上摩托車、約第 12 天開海港。

## 存檔格式

`localStorage['bayfront-empire']`，每 15 秒、跨日、購買、`pagehide` 與切到背景時寫入。

- **v1（海灘改版前）**：`{ v: 1, cash, day, time, shops: { 店id: 等級 }, earnedTotal, quest, rating, seed }`
- **v2（物流改版前）**：`{ v: 2, seed, rng, day, minute, money, rating, biz: { id: { lv, earned, visits } }, quest, history[], today: { rev, visits, turned, cost, buy }, weather: { cur, until }, event, stats, opts }`
- **v3（現行）**：v2 加上 `port: { lv, stock, reorder, ships[], offers[], truckUsed, nextShip, nextOffer, offerAt, stats }`，`today` 加上 `supply`、`saved`、`freight`、`storage`、`spoil`、`viaPort`，`today.rev.port` 是合約收入，`history[]` 加上 `supply`、`port`、`saved`。

`migrate()` 規則：v1 只接受城市商家 id（海灘商家一律從 0 開始）、任務進度最多接到海灘改版第一個任務（index 4）、標記 `notice: 'beach-update'` 讓畫面顯示改版公告；v2 補上空的海港（未開設）並標記 `notice: 'port-update'`，任務進度最多接到物流改版第一個任務（index 11）；v3 的 `port` 由 `sanitizePort()` 逐欄位修正（船最多 12 艘、報價最多 4 份）；各版本都逐欄位驗證，未知商家與壞值退回預設；JSON 壞掉時開新局，不丟例外。

## 效能策略

- 靜態場景合併成 5 個網格（一般、地面標線、暗窗、夜間亮窗、燈泡），只建鏡頭看得到的 +x／+z 面的窗框細節；路燈光暈是一個 InstancedMesh。
- 行人（身體＋頭）、毛巾、各類車、各類船、浮標、海鷗、航跡都是 InstancedMesh；手機上限 150 名行人、桌機 220。
- 陰影圖手機 1024、桌機 2048，陰影框跟著鏡頭；手機每 2 幀更新一次陰影。
- 自動畫質：連續 3 秒低於 47fps 依序改成每 3 幀更新陰影 → 解析度降 0.5 → 關閉陰影。設定裡可手動選高／省電。
- 海港增加 3 個靜態網格（隨等級重建一次）、岸橋小車／吊具／鋼索／吊櫃、堆場貨櫃、船身、甲板貨櫃、物流車 8 個 InstancedMesh。
- 驗收量測（含 Lv3 海港與卸貨中的船，鏡頭拉遠同時看城市、海灘與海港）：1440×900 平均 16.7ms（60fps，77 draw calls）；390×844 在 CPU 4× 降速下 16.7ms（60fps，36–58 draw calls，依鏡頭位置）。
