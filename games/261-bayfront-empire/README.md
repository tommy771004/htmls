# 261 灣岸商業帝國 · BAYFRONT EMPIRE

等角視角經營大亨：先在海濱大道開城市商家，再透過「海灘改版」把生意做到沙灘、碼頭與海上，接著以「物流與海港改版」開港降低進貨成本、投標貨運合約，最後的「城市生活改版」加入定價與促銷、疊樓的叫車電梯與換樓層、公寓與房租、三座地標、競爭對手、四季與週五派對、每日任務與成就、離線收入、跟拍鏡頭與照片模式。依一段用 AI 開發商業大亨遊戲海灘改版的影片與提示詞製作（玩法與畫面為原創實作，未使用原作素材）。

## 指令

```bash
npm run build      # 打包成 ../../web/261-bayfront-empire.html（改了 src/ 要重跑並一起 commit）
npm run dev        # 不壓縮的版本，方便除錯
npm run test:econ  # node:test：經濟系統、跨日結算、v1／v2／v3→v4 存檔遷移、海港補給船與合約、定價促銷、疊樓與電梯、公寓與對手、四季與派對、每日任務、離線收入、壞資料
npm test           # test:econ ＋ 兩種尺寸的無頭 Chrome 驗收（跑打包後的單檔，要先 build）
npm run sim        # 在 Node 跑經濟模擬（會開海港並投標），看節奏
npm run thumb      # 產生 ../../thumbs/261.jpg（有 ffmpeg 用 ffmpeg，否則用 sips）
node tools/shot.mjs out.png 390 844 '?auto=legacy' "__bf.setTime(20)"   # 開發用截圖
```

`node_modules` 是指向 `../201-coral-cove/node_modules` 的符號連結（three 0.186.0、esbuild、playwright-core）。

## 操作

拖曳移動地圖、滾輪或雙指縮放、點店面、公寓、地標或標籤看詳情；放大後點街上的人會跟拍他（右側眼睛按鈕會挑一位要搭電梯上樓的客人），拖曳地圖或點上方的跟拍提示就停止。右側相機按鈕進入照片模式：藏起介面，可拖時間、換天氣、24 小時縮時、錄影（MediaRecorder，存成 webm）與截圖（PNG）。鍵盤：WASD／方向鍵移動、Q／E 縮放、空白鍵暫停、1／2／3 切換 1×／2×／4×、Esc 關閉面板、離開跟拍或照片模式。

## 城市生活改版

- **定價與促銷**：每家店可選平價（客單價 85%、來客 122%、評分漲得快）、標準、精品（122%、80%）；促銷花客單價的 25 倍，3 小時客流 +60%。
- **疊樓**：同一棟每多一級別家店，這家客流 +5%。電梯改成叫車制（SCAN 掃描：往同方向把呼叫接完再折返，每站停 2 秒），標準／雙速／高速三級（4／6／8 人，每層 3.2／2.2／1.4 秒）；一樓電梯口排隊超過兩車廂就有客人放棄（`today.liftLost`）。付 $60K 可以交換兩家店的樓層，店內客人會先被請出門。
- **公寓**：街上 9 棟公寓可買下（Lv1）再翻修（Lv2），每天收房租，每級全城城市客流 +2.5%；屋頂加上露台、陽傘、燈串，翻修後掛布條。
- **地標**：防波堤燈塔（水上客流 +15%，夜裡旋轉光束）、海濱夜市（城市 +10%，18 時後再 +25%）、海灣摩天輪（海灘人潮 +20%、戶外與水上 +10%，每小時票房）。
- **競爭對手**：進入海灘章後，每天有一半機會在營收前三名的店對面、你沒買下的公寓一樓開店，搶走 15% 起、每天 +2%、最多 35% 的客人。改平價影響減半、升到 Lv3 再 −20%；可以收購，或買下那棟公寓收回店面。趕走後 5 天內不會再來。
- **季節與活動**：7 天一季（春夏秋冬，海灘 100%／130%／85%／55%、城市 100%／95%／106%／115%，冬天沒有熱浪、夏天少雨）；週五晚上是派對夜（城市 +50%、酒吧加倍，客滿只輕微扣評分），也可能遇到批發短缺（市價進貨貴 50%）。下雨時街上的行人會撐傘。
- **每日任務與成就**：每天 3 個依目前規模出題的任務（來客、營收、合約、海灘、促銷、開店），完成即發獎金；17 個成就。
- **離線收入**：重開時依最近平均淨利的一半結算離線時間，最多一天份。
- **街景**：核心路口有紅綠燈，車在紅燈前停車；店員會在店內巡走；酒吧 Lv3 變成有舞池與 DJ 台的夜店，書店加上咖啡吧；海港物流車到店會冒出「補貨」字樣。

## 測試 API（`window.__bf`）

`setTime(時)`、`setWeather('sunny'|'partly'|'cloudy'|'rain'|'heat')`、`setSpeed(0|1|2|4)`、`look(x, z, 視野高)`、`give(金額)`、`buy(id)`、`buyAll(等級)`、`fast(秒, 倍速)`（不渲染直接推進模擬）、`buyPort(等級)`、`bid(報價id, 每櫃出價)`、`bidWin(報價id)`（必中）、`now()`（絕對遊戲分鐘）、`act(動作, ...參數)`（直接呼叫介面動作，如 `act('tier', 'cafe', -1)`、`act('apt', '0,0,W')`、`act('mark', 'ferris')`、`act('swap', '3,1,W', 'nail', 'books')`）、`follow(true|false)`、`photo(true|false)`、`elevators()`、`estate`、`traffic`、`harbor.stats()`、`load(存檔)`、`exportSave()`、`stopSaving()`、`stats()`。網址加 `?auto=new`、`?auto=legacy`（v1 存檔）或 `?auto=v2`（v2 存檔）跳過開始畫面與公告。

## 已知限制

- 驗收用的無頭 Chrome 跑在桌機 GPU 上，手機 50fps 是以「CPU 4 倍降速＋390×844」模擬，沒有在實機量測；實機若掉到 47fps 以下，自動畫質會依序降低陰影更新頻率、解析度，最後關閉陰影。
- 車會停紅燈，但不處理路口交會，偶爾會在路口重疊；行人不看號誌，直接穿過斑馬線。
- 存檔只在這台裝置的 localStorage；離線收入以裝置時鐘計算，改系統時間可以作弊（上限一天份）。
- 物流車只是畫面上的示意（沿固定環線往返並在店門口停靠），實際配送量由每小時運量上限結算，不會因為塞車而變少。
- 貨櫃船進出港走直線插值，不避讓環境帆船與遊艇。
- 疊樓只有兩棟固定的地（三層與兩層），可以交換既有店家的樓層，但不能把別的店搬進疊樓。
- 錄影依瀏覽器支援的 MediaRecorder 格式，Safari 可能存成 mp4 或不支援。
- 對手只有一家，沒有自己的經營 AI，影響只是對目標店家的客流倍率。
