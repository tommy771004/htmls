## 2. 設計概念（使用者已確認：概念稿風格、密度適中）

**參考實作：聯絡人頁**（`src/pages/contacts.js` + `src/styles/pages/contacts.css`，路由 `#/contacts` 與 `#/contacts/c041`）。其他頁面要跟它看起來是同一套產品：同樣的頁首、統計卡、卡片、膠囊分頁、表格與徽章。動工前先截它的圖來看。

- **畫布＋卡片**：暖白畫布（`--bg`）上放白色大圓角卡片（`.card`，圓角 18px，柔和向下的陰影）。卡片之間間距 20px。沒有整頁白底。
- **深色浮動側欄**：地基負責。目前頁面用柿色膠囊標示，底部是本季業績卡（成交入帳飛進這裡）。
- **頁首直接在畫布上**：26px 粗體頁名＋一行說明，右邊是白色搜尋框與柿色主按鈕。
- **每個清單頁頂端都有 4 張統計卡**（`ui.statCard`）：標籤、粉彩色塊圖示、大數字、變化（`↑21%` 綠 / `↓` 紅）與小走勢。數字要真的從 store 算，可點的就給 `href` 帶篩選。
- **粉彩色分類**：`peach / mint / sky / lemon / lilac / rose / teal / sand` 八組（底色 + 字色），用在徽章（`ui.tag`）、頭像、時間軸圖示、統計卡圖示。一個畫面裡同一種意義固定同一個顏色。
- **柿色 `--accent` 是品牌色**：主按鈕、目前頁面、新增的劃記筆畫、逾期。成功是 mint/pine，警告是 lemon/ochre，負面是 rose。
- **劃記（正字）**：往來次數的招牌呈現，只放在看得清楚的尺寸（≥ 20px），例如詳細頁頂部的淡柿色塊。表格裡用數字加 `ui.activityBars`（近 8 週小長條）。
- **成交入帳**：交易成交時 `ui.bookIn` 讓金額飛進側欄的本季業績卡，量尺填滿、數字滾動。

## 3. 設計系統

所有 token 在 `src/styles/tokens.css`（淺色＋兩種深色選擇器都已定義）。**頁面 CSS 只能用 token。** 元件樣式在 `components.css`，版面在 `shell.css`，完整 API 見 `docs/foundation.md`。

- 字體：系統字（`--font-ui`，蘋方／Noto Sans TC）。頁名 26/700、卡片標題 16/650、內文與表格 14、說明 12–13。數字一律 tabular。只有單號與時間戳用 `--font-mono`。
- 間距：4 的倍數；頁面左右 `--gutter`（桌面 28px、手機 16px）；卡片內距 20–24px；卡片間距 20px。
- 圓角：控制項 10px、卡片 18px、膠囊 `--r-pill`。
- 陰影：卡片 `--shadow-card`，浮層 `--shadow-pop`。按鈕與卡片 hover 不上浮，只換底色。
- 表格：放在卡片裡；表頭 44px（`--subtle` 底）；列高 64px；頭像 36px；金額靠右、粗體。手機改成清單列（`m:'primary'|'end'|'meta'|'hide'`）。
- 分頁：`ui.tabs` 是膠囊（目前項深色實心＋計數）；詳細頁區段可用 `cls:'tabs--line'` 底線式。
- 篩選：工具列裡的 `.tbtn` 膠囊按鈕（啟用時柿色淡底），搜尋用 `.tsearch`。
- 動效：`--ease-out`、`--dur-*`；`prefers-reduced-motion` 時取消位移與描筆。**內容不能以 opacity 0 起始等動畫才出現。**
- 手機（≤ 760px）：側欄變成底部深色浮動分頁列，統計卡兩欄，不得有水平捲動。

### 全域（地基負責）
- ⌘K / Ctrl+K 命令面板：搜尋聯絡人、公司、交易、任務，並可執行動作（新增、切換主題、前往頁面）。鍵盤上下選、Enter 開啟。
- 「＋ 新增」選單：聯絡人、公司、交易、任務、記一筆活動；各自一個表單對話框（地基做好通用表單，頁面代理可直接呼叫）。
- 快捷鍵：`g d` 儀表板、`g c` 聯絡人、`g o` 公司、`g p` Pipeline、`g t` 任務、`g a` 活動、`c` 新增、`/` 搜尋、`?` 快捷鍵說明。
- 使用者選單：主題（淺色／深色／跟隨系統，三段文字切換，**不是日月開關**）、重設示範資料。
- 資料存 localStorage（`tally:v1`），讀寫都要 try/catch，失敗就只在記憶體裡運作。所有破壞性操作有可復原的 toast。

### A. 聯絡人
- 清單：搜尋（姓名、公司、Email、電話）、篩選（負責人、生命週期、標籤、關係溫度）、排序、欄位：人名字塊＋姓名＋職稱、公司、生命週期、近 30 天劃記、關係溫度、最後往來、負責人、進行中交易金額。
- 多選批次：指派負責人、加標籤、刪除（可復原）。儲存的檢視：「我的聯絡人」「該聯絡了（冷＋涼）」「決策者」「展會名單」。
- 詳細：頁首是大號宋體姓名、職稱與公司，旁邊是近 90 天的劃記（依月分三組）與關係溫度；欄位可就地編輯；往來時間軸（可篩類型）；活動輸入器（通話／Email／會議／筆記，送出即寫入）；相關交易、待辦任務、同公司的其他人。

### B. 公司
- 清單：表格與卡片格兩種檢視；篩選產業、地區、規模、負責人；欄位含聯絡人數、進行中交易、累計成交、關係溫度。
- 詳細：公司抬頭（兩字字塊、產業、地區、統編、網址、員工數）；**組織圖**（聯絡人依 `reportsTo` 畫成樹狀）；交易（依階段）、聯絡人、時間軸、營收歷史小圖（歷年成交）。

### C. 交易 Pipeline
- 看板：七欄（新線索→需求確認→場勘 PoC→報價→議價→成交→未成），每欄頂端有筆數、總金額、加權金額。卡片：單號、名稱、公司字塊、金額、預計成交日（逾期柿色）、負責人字塊、停留天數。
- 拖曳換階段（pointer events，含觸控），也可用鍵盤（聚焦卡片按 `[` `]` 左右移）。拖入成交 → 成交入帳動畫；拖入未成 → 先跳出「未成原因」選單，再轉灰加刪除線。
- 清單檢視：可排序表格、分組依階段／負責人／預計成交月。
- 篩選：負責人、預計成交期間、產業、金額範圍。頂部摘要：本季目標、已成交、加權預測、達成率。
- 交易抽屜：階段進度（含每階段進入日期）、報價品項（產品×數量×單價，可增刪，總額自動算）、聯絡人、下一步、活動時間軸、標記成交／未成。

### D. 儀表板
- 問候與今天（日期、今天的任務數、本週要成交的單）。
- 本季預測：目標 vs 已成交 vs 加權 pipeline（水平條，一眼看出缺口）。
- Pipeline 漏斗：各階段金額與筆數、階段轉換率。
- 近 12 週活動量（業務 × 週的格子圖，本週用劃記顯示）、贏單率、平均成交週期、平均單價。
- 「該聯絡了」：關係溫度冷／涼且有進行中交易的聯絡人。
- 即將成交的單、業務排行（已成交／目標）、最新動態。
- 篩選：期間（本月／本季／今年）、業務（全部或單人）。所有數字可點進對應頁面並帶上篩選。

### E. 任務與活動
- 任務：分組 逾期／今天／明天／本週／之後／已完成；清單與週曆兩種檢視；快速新增一行輸入支援自然語言（「明天下午3點 打給陳怡君 確認報價」→ 解析日期時間、關聯聯絡人）；優先度、負責人、關聯紀錄；勾選完成時，關聯紀錄的劃記多一筆，並可復原。
- 活動紀錄：全域時間軸依日期分組；篩選類型（通話、Email、會議、筆記、階段變更、任務完成）、業務、期間；每筆連回聯絡人／公司／交易；可直接記一筆。

## 6. 工程結構

```
games/155-tally-crm/
  build.mjs                 讀 src/，依序內嵌成 web/155-tally-crm.html
  src/shell.html            HTML 骨架，含 /*STYLE*/ 與 /*SCRIPT*/ 佔位
  src/dev.html              開發用：以 <link>/<script> 直接載入各檔，file:// 可開
  src/styles/tokens.css  base.css  components.css  shell.css
  src/styles/pages/<page>.css
  src/core/                 util、icons、seed、store、router、ui、forms、palette、shell
  src/pages/<page>.js       每頁一檔，註冊到 CRM.pages
  src/main.js               最後載入，啟動 app
  tools/check.mjs           headless Chrome 驗收與截圖
  shots/                    截圖輸出（不 commit）
```

- 無框架、無相依套件。每個 JS 檔是 IIFE，掛到全域 `window.CRM` 命名空間。build 依固定順序串接 core，再依字母序串接 `src/pages/*.js` 與 `src/styles/pages/*.css`，**新增頁面檔不需要改 build**。
- 頁面介面：`CRM.pages.<name> = { route: /^\/contacts(?:\/(\w+))?$/, title, nav: 'contacts', mount(el, ctx), unmount?() }`，`ctx` 含路由參數、query、store、ui。store 變更時頁面自行重繪受影響區塊。
- 並行規則：**頁面代理只改自己的 `src/pages/<name>.js` 與 `src/styles/pages/<name>.css`**。需要改 core 時先在自己檔案內寫區域 helper，並在回報中列出建議移入 core 的項目，由主代理整合。

## 7. 驗收

每頁完成時執行 `node games/155-tally-crm/build.mjs && node games/155-tally-crm/tools/check.mjs <route>`（`check.mjs` 用 Node 22 內建 WebSocket 直接走 Chrome DevTools Protocol，不依賴 playwright；主題以 URL 參數 `?theme=dark|light` 強制，app 讀到後設定 `data-theme` 但不寫入偏好）：
