# 靜水釣遊 · STILLWATER ROW & CAST（作品 269）規格與模組契約

俯視角（俯角約 50°）的划船探索與生態收集釣魚。一條由南（木屋碼頭）往北（上游瀑布潭）的河，五個生態區、6 座水道燈樁檢查點、15 個釣點、55 種魚、5 階品質、主線 5 章與木屋佈告欄委託、早／午／黃昏三時段。
企劃原文：使用者提供的《靜水釣遊》企劃書 v2.0（Unity 工作流；本作改成 Three.js 單檔，18 個檢查點的內容都做進同一份頁面）。

所有模型以 Blender 5.2 無頭腳本建模（`blender/*.py`），匯出 `blender/out/*.glb` 並 commit；打包時以 gzip＋base64 內嵌成單檔 `web/269-stillwater.html`，不載入外部資源。

## 指令

```bash
npm run assets         # 依序跑 blender/*.py（common.py 除外），重建 blender/out/*.glb
npm run build          # esbuild 打包 src/ + 內嵌 GLB → ../../web/269-stillwater.html
npm test               # node:test 規則層（tools/core.test.mjs）＋ 兩種尺寸無頭 Chrome 驗收（tools/accept.mjs）
node tools/view.mjs blender/out/boat.glb --node boat --view top
node tools/glbinfo.mjs blender/out/fish.glb --tree
```

## 座標與單位（所有模組共用）

- 1 單位 = 1 公尺。Blender Z 朝上；glTF／three Y 朝上。Blender (x, y, z) → three (x, z, −y)。
- **船的本地座標**（three）：原點在**吃水線中心**，**船頭朝 +Z**，+X 是船的左舷（從船尾往船頭看的左手邊）。Blender 裡船頭朝 −Y。
- 河道：南方是 +Z（木屋碼頭約在 z = 0），北方是 −Z（瀑布潭約在 z = −720）。水面高度 y = 0（瀑布頂除外）。
- 原點：放在地上的東西（木屋、松樹、岩石、燈樁、蘆葦）原點在**底部中心**、底部 y = 0；碼頭的原點在岸邊端的水面高度；魚原點在身體中心。
- 低多邊形：平面著色、少段數、頂點略抖動（`jitter()`），不用貼圖，只用材質底色（遊戲端烘成頂點色）。

## 划槳公式（遊戲與 Blender 共用，必須一致）

槳在 `boat.glb` 裡是獨立節點 `Oar_L`、`Oar_R`，**節點原點＝槳架（oarlock）支點**，由遊戲每幀設定旋轉；漁夫的 `row*` 動作用 IK 把雙手放在槳柄上，所以兩邊要用同一套公式。

- 槳架位置（three，船本地）：`Oar_L` 在 (+0.60, 0.40, −0.28)，`Oar_R` 在 (−0.60, 0.40, −0.28)（舷緣 0.34 上的小墊木＋銅槳架）。
- 槳在靜止（旋轉為 0）時是**水平、沿 X 軸**：`Oar_L` 的槳葉朝 +X（往左舷外），`Oar_R` 的槳葉朝 −X。槳全長 2.30 m，支點內側（槳柄）0.58 m，外側 1.72 m；槳柄中心在節點本地 (∓0.52, 0, 0)（L 為 −0.52，R 為 +0.52），槳葉中心在 (±1.50, 0, 0)。
- 漁夫坐在中央坐板、**面向船尾（−Z）**划槳（真實划船姿勢），所以拉槳時槳葉由船頭側掃向船尾側，船往 +Z 前進。
- 相位 φ ∈ [0, 1)，一次划槳週期 `T = 1.2 s`：
  - 拉槳（drive）φ ∈ [0, 0.45)：s = φ / 0.45，`sweep = lerp(+38°, −20°, ease(s))`，`lift = −18°`（槳葉中心約在水下 6 cm）
  - 回槳（recovery）φ ∈ [0.45, 1)：s = (φ − 0.45) / 0.55，`sweep = lerp(−20°, +38°, ease(s))`，`lift = −10°`（槳葉出水，槳葉中心約高出水面 14 cm）；lift 在 s∈[0,0.12] 內由 −18° 平滑過渡到 −10°、在 s∈[0.88,1] 內由 −10° 平滑回到 −18°（`smoothstep`）。
  - `ease(s) = 0.5 − 0.5·cos(π s)`。
  - sweep 為正 = 槳葉往船頭（+Z）側；lift 為正 = 槳葉抬高。
- 轉成節點旋轉（three 四元數，先 lift 再 sweep）：`Oar_L`：`q = qY(−sweep) · qZ(+lift)`；`Oar_R`：`q = qY(+sweep) · qZ(−lift)`。驗算：槳葉中心的 z 隨 sweep 增加而增加（往船頭），y 隨 lift 增加而增加。Blender 端換算時以此為準（three (x, y, z) = Blender (x, z, −y)）。
- 靜止（不划、釣魚時）：`sweep = +20°`、`lift = −12°`（槳葉平放在水面上方約 9 cm，槳柄在漁夫膝蓋前上方）。
- 只划單邊（原地轉向）：轉向那邊的槳照公式動，另一邊停在靜止姿勢（`sweep = +20°, lift = −12°`）。
- 倒划：φ 反向播放（φ 由大到小）。

## 資產檔與節點名稱（遊戲以名稱取用，不能改）

### `boat.glb`（`blender/boat.py`）

- 根節點 `boat`：木製雙尖頭划艇，全長 3.6 m、寬 1.30 m、船舷高出水面 0.34 m、吃水 0.12 m；外殼 `hull_paint`、內側與坐板 varnish、上緣（gunwale）暗木。三條坐板：中央坐板（z = 0，高 0.30）、船頭小坐板、船尾小坐板。
- 子節點：`Oar_L`、`Oar_R`（見上）；`lantern_mount`（空節點，船頭柱頂，提燈掛點）；`lantern`（船頭防風小提燈，`lamp_glow` 燈光，遊戲預設隱藏，升級後顯示）；`creel`（船尾的竹編魚簍，蓋子 `creel_lid` 子節點可繞 X 軸開合）；`rod_stowed`（收在船內左側的釣竿，划船時顯示、釣魚時遊戲隱藏）；`wake_L`／`wake_R`（空節點，船尾兩側水花發射點）。
- 槳架：舷上的小 U 形銅件，跟船殼合在 `boat` 網格裡。

### `fisher.glb`（`blender/fisher.py`）

- 骨架根 `fisher_rig`，蒙皮網格 `fisher`。**直接以船的本地座標建模**：坐在中央坐板上、面向船尾（three −Z），根骨 `root` 在 (0, 0, 0)（船的吃水線中心，坐板正下方），所以遊戲把它加成船的子物件、位置 0 即可坐好。釣魚時遊戲繞 Y 軸轉整個 `fisher_rig`（以坐板中心為軸）讓他面向釣點。
- Q 版比例（頭略大，坐姿頭頂約高出水面 1.25 m），戴**寬簷草帽**（俯視時的辨識重點：直徑約 0.62 m 的平簷＋低帽冠＋帽帶 `hat_ribbon`），鐵鏽紅上衣、深藍吊帶褲、膠靴。
- 骨頭（名稱固定）：`root`、`hips`、`spine`、`chest`、`neck`、`head`、`upperarm_L`、`forearm_L`、`hand_L`、`upperarm_R`、`forearm_R`、`hand_R`、`thigh_L`、`shin_L`、`foot_L`、`thigh_R`、`shin_R`、`foot_R`；釣竿 `rod_0`（掛 `hand_R`，握把）→`rod_1`→`rod_2`→`rod_3`，竿尖骨 `rod_tip`（**head 在竿尖**，遊戲拿世界座標接釣線），竿長約 2.1 m，竿上有小捲線器（`reel_crank` 是 `rod_0` 的子骨）。左右以角色自身為準（`_L` 在角色左手）。注意：角色面向船尾，所以角色的左手在船的右舷（−X）側，握的是 `Oar_R`。
- **划船時釣竿要藏起來**：`row`／`row_L`／`row_R`／`sit` 動作裡 `rod_0` 的 scale = 0.001（整支竿縮到手心看不到）；釣魚動作 scale = 1。遊戲會在划船時顯示船上的 `rod_stowed`。
- 動作（名稱固定，30 fps）：

| 名稱 | 長度 | 循環 | 內容 |
|---|---|---|---|
| `sit` | 2.0 s | 是 | 坐著，雙手鬆鬆握在靜止的槳柄上（槳在靜止姿勢），輕微呼吸 |
| `row` | 1.2 s | 是 | 雙槳划：時間 t 對應相位 φ = t / 1.2，雙手 IK 在兩支槳的槳柄上（用上面的公式算槳柄位置），拉槳時身體由前傾（往船尾）後仰到後傾 |
| `row_L` | 1.2 s | 是 | 只划 `Oar_L`（角色右手那支），左手握著停住的 `Oar_R`（姿勢同單邊停槳） |
| `row_R` | 1.2 s | 是 | 只划 `Oar_R`（角色左手那支），右手握著停住的 `Oar_L` |
| `cast` | 1.0 s | 否 | 坐姿甩竿：0～0.45 s 竿往後上方舉起，0.45～0.65 s 往前甩，**0.55 s 出線**，結束停在 `wait` 起始姿勢 |
| `wait` | 2.4 s | 是 | 雙手持竿朝正前方（角色前方 = −Z）、竿尖約高於水平 25°，輕微晃動 |
| `hook` | 0.4 s | 否 | 提竿：竿往上猛抬接近垂直，結束時回到 `reel` 起始姿勢 |
| `reel` | 0.6 s | 是 | 收線：竿斜舉，左手轉捲線器（`reel_crank` 一循環一圈），身體後仰用力 |
| `cheer` | 1.4 s | 否 | 釣到魚：左手把魚舉高（遊戲把魚掛在 `hand_L`），右手持竿，身體在坐板上小跳一下 |

### `rod` 的彎曲

遊戲在動作播放後，依張力額外讓 `rod_1`～`rod_3` 往竿的前下方彎（繞骨頭本地 X 軸），所以竿身要在這三根骨頭上平順蒙皮。

### `fish.glb`（`blender/fish.py`）

55 種魚，各一個靜態網格 `f01`～`f55`（編號對應企劃書 #01～#55），**長度正規化為 1.0 m**（頭在 +Z、尾在 −Z），原點在身體中心，遊戲依魚種體長縮放。游動的擺尾由遊戲在頂點著色器做（沿 Z 的波），所以身體沿長軸至少要有 10 段截面，尾鰭也要有段數。花紋（條紋、斑點、鱗光、體側彩帶）用頂點色或分材質做；俯視時背色與輪廓要好辨認。依體型分族（鯉形、雅羅、鱸形、太陽魚、鮭鱒、鯰、鰍／蝦虎、狗魚、鱘、骨舌魚、雀鱔、龍魚），同族共用參數化生成器再換比例、鰭形與配色。

## 遊戲端（src/）

- `src/core/`：魚種資料庫 `fishdb.js`、品質計算 `quality.js`、收線狀態機 `reel.js`、任務與委託 `quests.js`、存檔 `save.js`、地圖資料 `map.js`（河道中心線、五區、檢查點、釣點）。**不碰 DOM 與 three**，Node 測試直接 import。
- `src/view/`：three 場景、地形與水、船、魚影、時段光影、HUD。
- 測試 API：`window.__st`（見 README）。
