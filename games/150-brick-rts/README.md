# 科技樹與對局設定

- **科技樹**：百科多了「科技樹」分類，照 aoetw.com 各文明科技樹頁的排法：每座建築一塊（軍營、射箭場、馬廄、攻城器製造所、城堡、城鎮中心、磨坊、伐木場、採礦營地、碼頭、兵工廠、市集、修道院、學院），再加一塊「村民建造」（民居、城牆與城門、哨站、箭塔、火砲塔、世界奇觀），由上往下是黑暗到帝王時代，同一欄是升級的先後。可以切換 13 個文明與拓荒者，文明沒有的項目變暗並標「沒有」，本作沒有的網站項目（鷹斥候、攻城塔等）可以顯示成淡色；文明加成與團隊加成列在上方，點一下任何項目就打開它的百科頁。
- **對局中的科技樹**：按 F4（或選單「科技樹」）直接打開自己文明的科技樹，標出已完成、擁有幾個、進行中、現在可做、資源不足、條件未到。
- **核對**：13 個文明的科技樹逐格對照網站，只有蒙古的戟兵不同（文明頁與戟兵頁都說沒有，維持之前的決定）；修正一處漏洞：沒有火砲塔的 10 個文明不能再研究沒有用處的火砲塔技術。
- **對局設定**：開啟頁面時先出現設定畫面，按「遊戲開始」才進對局：
  - 遊戲者：你的名稱與文明（可隨機）；紅方是電腦或不行動、文明（可隨機）、電腦開局與難易度（簡單、標準、困難、最難：電腦思考的頻率、村民數與出兵的規模與時機，不給電腦資源加成）。
  - 地圖類型與種子（同一個種子與地圖每次生成同一張，旁邊有預覽）。
  - 資源（低、標準、中、高）、人口上限（25、40、75、100）、顯示地圖（戰爭迷霧、已探索、全部顯示）、遊戲開始時代（黑暗到帝王）、勝利（標準，或只有征服）、所有科技（每個文明都能用全部共通項目，特殊單位與特殊科技仍屬各文明）、記錄遊戲（每一遊戲分鐘自動存檔）。
  - 「載入遊戲」列出手動存檔與自動存檔；「科技樹」打開百科的科技樹（預選你挑的文明）。
  - 本作是一對一，所以沒有隊伍、位置與更多遊戲者的設定；地圖大小跟著地圖類型固定。
- **頁面**：第一次開啟就是設定畫面；對局中選單的「新遊戲設定」可以重開，「取消」（或 Esc）回到原本的對局；上次的設定會記住。F4 開關科技樹。
- 網站的「常見問題」分類依要求跳過。

# 戰術技巧：會落空的箭、姿態、巡邏與開局

- **箭會飛、會落空**：弓兵、弩砲、投石車、火砲、戰船與建築射出的箭和砲彈有飛行時間，照 aoetw.com 的彈速與命中率（弓手 80%、弩手 85%、強弩兵 90%、馬弓騎兵 50%、火槍兵 65% 等）。沒有彈道學時射向目標當下的位置，橫向走開就閃掉；落空的箭可能打中落點旁的敵人。近戰照舊當下命中。
- **學院的彈道學**（第三時代）：弓兵、戰船、城鎮中心、箭塔、城堡與火砲塔會預判移動中的目標。拇指環讓弓兵射擊靜止目標必中，戰狼號讓巨型投石機射擊靜止目標必中；追蹤讓步兵從第二時代起多看 2 格。
- **戰鬥姿態**：攻擊（預設，一路追）、防禦（追太遠就回原位）、堅守（不移動，只打射程內的）、不還擊（不自動開打也不還手）。**巡邏**在兩點間來回，路上依姿態迎敵；**分散移動**讓單位隔開一格，閃投石車。
- **電腦開局**：電腦可以照網站的 9 種阿拉伯開局打（肉馬、小弓、裝甲、裝甲塔、純塔、黑暗爆民兵、黑快轉封、黑快搶城、前置槍矛），例如純塔會派村民到你的石頭旁蓋箭塔；也可以選「隨機」（對局結束後揭曉）或照舊的「標準」。村民數照本作的規模取網站的一半左右，升封建照本作的 300 食物。
- **練習開局**：選一種開局後，戰場左上角出現流程清單，照你實際的人口、採集分配、建築與時代逐步打勾並記下完成時間（F2 收合）。
- **百科**多了「戰術技巧」分類：總覽、10 種開局（老鷹開局需要鷹斥候，標為未實作）的資訊欄、流程、反制與電腦怎麼打，以及拉兵、包圍、點射、合兵、分散、閃躲、分兵、卡位在本作怎麼做（命中率、彈速等表格取自模擬）。
- **頁面**：選士兵時指令格有 Q 攻擊、W 防禦、E 堅守、R 不還擊、A 巡邏（再點地面）、D 分散隊形開關，Alt＋右鍵只讓這一次分散移動；選取的單位會顯示巡邏路線，戰場上看得到飛行中的箭、石彈與砲彈。選單有「電腦開局」（紅方）與「練習開局」。

# 遊戲元素：防禦類型、駐軍、修理與嘲諷

- **防禦類型**：傷害改成原作的算法：攻擊減護甲，再加上每個「攻擊者有加成、目標也屬於」的類型的加成減該類型的護甲。拜占庭聖騎兵與阿拉伯奴隸兵比其他騎兵更不怕長槍兵；建築分成標準建築、石頭建築、城牆和城門、城堡，城牆與城堡比較耐攻城器，磚瓦技術、建築學與垛牆再加強。照 aoetw.com 的防禦類型頁補齊各單位缺的加成（長槍兵對戰象與船、斥候對僧侶、駱駝對船、火砲戰船對步兵弓兵騎兵、民兵系對建築、各種對衝撞車與漁船的加成等）。
- **開火間隔**：弓兵、馬弓騎兵、弩砲等遠程單位對新目標的第一發之前要先瞄準，一移動就重來，所以拉打有代價。
- **擴散範圍**：投石車系與火砲的爆炸會打到自己的單位；戰象踐踏目標旁的敵人（50%）；裝甲與重型衝撞車同時打到附近的敵方建築（一次拆好幾段城牆）。被看不見的單位打到時，會短暫看到攻擊者在哪裡。
- **駐軍**：建築生命剩 20% 以下時裡面的單位全部出來，也不能再進去；城堡回血是城鎮中心與箭塔的兩倍。兵營、靶場、馬廄、攻城器工坊、修道院與碼頭把集結點設在自己身上時，新訓練的單位直接進駐（最多 10 名）。步兵與徒步弓兵可以上衝撞車（4／5／6 名），每名步兵讓它走得更快、打建築更痛。
- **修理**：村民修理自己的建築、攻城器與船（船從岸上修），修滿要原價的一半、邊修邊付；城鎮中心不花石頭但木材加倍。僧侶不治療攻城器與船。電腦會派村民修受損的城鎮中心與城堡。
- **嘲諷**：輸入 1～42 送出網站列的嘲諷句子，雙方都看得到；只用電腦本機的中文語音朗讀（沒有就只顯示文字）。電腦會在出兵、城鎮中心告急等時刻嘲諷。
- **百科**多了「遊戲元素」分類（防禦類型、回血、駐軍、血量、攻擊、射速、開火間隔、擴散範圍、團隊加分、遺跡、嘲諷語音、招降、視野），表格的數字都取自模擬。
- **頁面**：選村民右鍵受損的己方建築、攻城器或船就修理（狀態列顯示修滿要多少資源）；選步兵右鍵己方衝撞車就上車，衝撞車面板顯示乘客與加成，U 放出；選兵營等建築右鍵建築本身，集結點就設在建築內。按 Enter 開聊天列輸入嘲諷編號（手機在選單裡），選單可關掉朗讀。單位資訊顯示類型護甲與開火間隔。

# 建築：碼頭、船、市集、城牆與奇觀

- **新地圖「湖畔」**：32×32 的對戰圖，中央一座大湖，湖裡的深水魚只有漁船捕得到；原本的「曠野」不變。
- **碼頭**（木材 150，蓋在岸邊的水面上）：訓練漁船、運輸船、貿易商船、戰船、火艨艟、自爆筏、火砲戰船（第四時代，要化學）與維京大戰船（維京的第二個特殊單位）；研究弩砲戰船（戰船、火戰船、爆破船一起升級）、重型弩砲戰船、重型火戰船、重型爆破船、精銳火砲戰船、流刺網、航海技術、船塢、造船員。
- **漁船**捕深水魚與岸邊魚、把食物送回碼頭，也能在水上蓋**魚網**（第二時代，木材 100，1000 食物，只有自己的漁船能採）。**運輸船**載陸上單位過湖（5 名，航海技術、船塢與薩拉森更多），沉沒時船上的單位全滅。船只在水上走，陸上單位只在陸上走。
- **市集**（第二時代，木材 175）：用黃金買賣食物、木材、石頭，價格雙方共用、越賣越便宜；交易費 30%（公會制度 15%、薩拉森 5%）。**貿易車隊**往返自己與對方的市集、**貿易商船**往返雙方的碼頭，距離越遠每趟黃金越多；商隊讓它們快 50%。
- **城牆與城門**：木牆、石牆拖曳成一列，每格各自付費；木門與城門放在牆上取代一格，只擋敵人、自己的單位可以通過。學院的垛牆讓石牆與城門更耐打。

# 放牧、狩獵與捕魚

羊、鹿、野豬現在是會走動的動物，食物來源和原作一樣分成放牧、狩獵與捕魚：
- **放牧**：開局 4 隻羊屬於你；曠野外圍還有沒主人的羊，派任何單位走過去就歸你，對手的單位靠近、你的單位離開時會被搶走。選取自己的羊可以右鍵地面趕到別處。村民右鍵自己的羊就宰羊、採集、送回，吃完自動換下一隻。
- **狩獵**：村民右鍵鹿或野豬。鹿受擊會逃，村民會追；野豬會反擊，單獨一名村民會被打死，要多派幾名。死掉的動物留下屍體（羊 100、鹿 140、野豬 340 食物），慢慢腐壞。
- **捕魚**：曠野中間有池塘，岸邊的魚由村民站在岸上採集，送回城鎮中心或磨坊。漁船與碼頭還沒有。

- 在自己建築 4 格內的羊不會被搶。

# 修道院與僧侶

## 操作

畫面：上方資源列，中間戰場，下方左起是指令格（5×3）、選取資訊、小地圖。

1. 選取
   - 左鍵點選單位，或在戰場上拖曳框選；Shift 加選或減選，左鍵點空地取消選取。
   - 左鍵點自己的建築選取建築；H 選取城鎮中心並把鏡頭移過去；「.」或小地圖旁的村民按鈕輪流選取閒置村民（按鈕角落是閒置人數）。
   - Ctrl＋數字儲存編組，按數字叫回；Esc 取消選取。多選時，選取資訊列出每個單位的頭像與血條，點頭像只選那一個，Shift＋點移出選取。
2. 命令
   - 右鍵地面：移動，各自分到目的地附近的站位；點在建築或樹上時走到最近的空地。右鍵樹木、石礦、金礦、野果或己方農田：村民採集，裝滿 10 單位後送到最近能收這種資源的建築（城鎮中心、伐木場、採礦場或磨坊）再回來。右鍵未完工的建築：協助施工。右鍵紅方單位或建築：攻擊；選取中的僧侶改為轉化紅方單位（研究救贖後也能轉化建築）；右鍵受傷的己方單位是治療，右鍵聖物是撿起，攜帶聖物時右鍵己方修道院是存放。右鍵己方完工的箭塔或城堡是進駐；城鎮中心的大廳可以走進去，所以進駐城鎮中心用指令格的「進駐」（G，走進最近還有空位的城鎮中心或箭塔）或鐘聲。能進駐的是村民、步兵、弓兵與僧侶。攻城槌與巨型投石機只能攻擊建築，對單位下令會被拒絕，也不會自己找目標；巨型投石機在射程內停下後先架設 7.5 秒才射擊，移動前先收起 7.5 秒（選取資訊寫「已架設」或「移動狀態」）。輕型投石車、弩砲、巨型投石機與火砲有最近射程：太近的目標不會自動攻擊，下令攻擊時會先退開再射。炸藥桶只去被派去的地方，引爆後消失。
   - S 或指令格的停止：在下一個節點停下。
   - 村民與士兵一起選取時，採集與建造只派出村民，並提示有幾名士兵沒有派出。
   - 右鍵動物：村民宰羊（只能宰自己的羊）或狩獵鹿與野豬，士兵攻擊牠；右鍵岸邊的魚，村民在岸上捕魚。只選取自己的羊時，右鍵地面是把羊趕過去。
   - 框選時框到村民或士兵就不會選到羊；只框到羊才選羊。
3. 指令格
   - 選取村民時，建造格分兩頁，最下排的切換格（N）換頁：第一頁是 Q 住宅、W 兵營、E 農田、R 伐木場、T 採礦場、A 磨坊、D 馬廄、Z 靶場（馬廄與靶場需要第二時代與完工的兵營）、C 鐵匠鋪、V 箭塔（需要第二時代）；第二頁是 X 修道院、B 攻城器工坊（需要鐵匠鋪）、Y 城堡（拓荒者沒有城堡）、U 學院，都需要第三時代。建築的字母在哪一頁都能直接按，指令格會翻到那一頁。文明沒有的建築不會出現在指令格。在戰場上移動滑鼠看占地預覽（綠色可放、紅色會寫出原因），左鍵放置，Shift＋左鍵連續放置，右鍵或 Esc 取消。
   - 選取完工的城鎮中心、兵營、馬廄、靶場、攻城器工坊、修道院、城堡、學院、伐木場、採礦場或磨坊時：生產與研究依序是 Q W E R T A D Z X C V B Y（攻城器工坊訓練攻城槌、輕型投石車、弩砲與火砲；靶場的火槍兵與攻城器工坊的火砲要先在學院研究化學；第四時代的兵種升級在訓練該單位的建築研究）。只列出自己文明能做的項目，費用與時間依文明計算；城堡訓練特殊單位、炸藥桶與巨型投石機（第四時代），研究精銳升級與特殊科技。已研究的時代與科技會從指令格移除。磨坊最後一格是「自動補種」開關。未完工的建築有取消格（Del），全額退款。
   - 滑鼠停在指令格上，左下角會出現說明卡：名稱、快捷鍵、費用（不足的會標色）、時間、人口，以及不能按的原因。沒有停在指令格上時，這裡寫出目前不能建造或生產的原因。
   - 佇列顯示在選取資訊右側，第一項有進度條，每項都能取消並全額退款。選取建築時右鍵地面設定集結點。
4. 鏡頭與小地圖
   - 「,」選取全部軍隊（含攻城器與炸藥桶，不含村民、僧侶與斥候）。方向鍵平移，滾輪或小地圖旁的 +／− 縮放，旋轉鈕每次轉 90 度，F 對準選取的單位。
   - 小地圖依鏡頭方向繪製，白框就是目前看到的範圍。左鍵點或拖曳移動鏡頭；選取單位時右鍵下達移動，選取建築時右鍵設定集結點。
5. 時間
   - F3 或頂列的 ▶／❚❚ 暫停與繼續；速度可切 1×／2×／4×，每個 tick 都會執行。
   - 開啟選單（F10）會暫停，關閉後繼續。背景分頁或視窗失焦會自動暫停；畫面卡頓超過一秒時，遊戲暫時放慢，不會跳過 tick。
   - 選單的「投降」要按兩次才生效；電腦在失去城鎮中心又沒有士兵時也會投降。
6. 選單
   - 儲存／讀取遊戲使用 `brick-rts:sandbox:1` localStorage key；新遊戲不會覆蓋手動存檔。
   - 新遊戲可選地圖（曠野 32×32 隨機出生，或 16×16 的草甸、海岸、高地與淺灘）、紅方（電腦或不行動）、雙方的文明（紅方可選「隨機」，依種子決定）與種子。
   - 「百科」分「文明」「單位」「科技」三類：文明的加成、特殊單位與特殊科技；每條兵種線每一階的數值與研究費用，以及本作還沒有的單位（可依類型或建築分組）；每項科技的費用、時間、前置、效果、各文明的差異與缺少的文明，以及本作還沒有的科技與原因（可依建築或時代分組）。Esc 關閉百科，F10 連選單一起關。
   - 「驗證指令重播」在當前種子下重跑所有指令，比較完整狀態指紋。
7. 勝負：摧毀對方所有單位與建築即獲勝，畫面顯示結果並可「再開一局」。紅方由電腦操控（或選「不行動」）。
8. 觸控：輕觸單位選取，選取後輕觸地面移動或輕觸資源採集。
9. 單位互不重疊也不互相穿過：會排隊、讓路、同組交換站位；無法前進 300 ticks 會顯示「受阻停止」，目標不可達則停在最近點並顯示「無法到達」。
10. 除錯模式 `?debug=1`：右側抽屜有逐 tick、狀態指紋、村民 1–3 按鈕、X／Y 座標移動、迷霧除錯與規則 JSON 驗證器（驗證、還原、匯出；不套用到遊戲）。

背景分頁或失焦會暫停，超過一秒的累積延遲會被丟棄，都不會跳過 tick。模擬不依賴 DOM／Canvas；畫面採独立的種子 stream。移動採整數座標與 31×31 導航節點，單位之間有占位與讓路規則，詳見 docs/first-use-008.md。
