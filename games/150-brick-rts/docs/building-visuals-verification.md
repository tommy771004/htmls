# C：代表建築的外觀狀態

2026-09-25。新增 `apps/web/building-parts.ts`，由遊戲與模型檢視頁共用。state／snapshot 維持 v9，沒有變更模擬規則或杜撰原作成本、生命值與施工時間。

## 已實作與邊界

- 四種時代輪廓：木構／灰泥到石造扶壁、屋脊與屋頂構件；不是只有換色。尺寸與分段門檻是原創美術的 design_default，沒有宣稱符合指定原作版本。
- 五段實體施工外觀：基座、牆柱、屋頂、門窗等機能件、完成旗幟。增加真正的零件，不用透明完整建築冒充施工。
- 受損移除指定屋頂零件，摧毀保留基座與最多 12 塊低矮裝飾殘骸；恢復完整狀態會重建原始零件。
- 模型頁提供時代、施工進度、完整／受損／殘骸與聚焦建築控制，明示只檢查外觀。這些參數不會發出模擬命令。
- 正式沙盒仍固定使用第二種時代、完整建築。門口雖有開口造型，導航仍使用整個建築 AABB，不能進入或駐軍；殘骸不改碰撞，也不是物理碎片。

`npm run test:rig-browser` 通過：實際操作四時代、五段施工、受損／殘骸，再還原第二時代完整狀態；還原後 canvas 截圖與原始完整建築相同，沒有 pageerror。另保留人偶掛點、姿態與播放驗證。執行時以 PLAYWRIGHT_MODULE 指向本機可用的 Playwright。
