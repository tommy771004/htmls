# 地圖驗收資料

`npm run maps:export` 從同一個生成器建立以下 JSON，匯出前執行 validateMap。格式 brick-map-example-1，數值均為 design_default，不能作為原作地圖規則。

| 檔案 | 內容與驗收用途 |
|---|---|
| meadow.json | seed 260925 的既有草甸；作為陸地沙盒基準。 |
| coast.json | seed 決定分段海岸線，南端保留连续海域；深水阻擋陸地通行，沙岸允許陸地通行。 |
| acceptance.json | 固定手工配置，不受 seed 影響：中央 x=7、8 格為河道，y=7 至 9 格為淺灘；雙方住宅與資源位置固定。 |

在 `web/150-brick-rts-models.html` 的「驗收地圖」選單可檢視同一份生成結果。此頁沒有對局或船隻控制，不能以模型顯示宣稱海戰已實作。JSON 是生成器輸出範例，尚無使用者自訂地圖匯入／編輯 UI。

通行驗收由 tests/maps.test.ts 執行：陸地從 (3.5,7) 到 (11.5,7) 必須穿過淺灘；水域路徑由 (8,2) 到 (8,14) 可穿過淺灘；關閉淺灘後陸地路徑不可達，生成器驗證回報出生區互不連通。navigation 的 movement 明確選 land 或 water，不從模型或材質推斷。半徑仍為自訂 0.25 格。

尚未涵蓋高度／坡道、橋樑結構、魚群、海上資源公平、船隻實體、碼頭或多人地圖同步。

後續增量：目前已加入魚群及其水域資料，但尚無捕魚工作；各 JSON 另附 startingResources 驗證報告，可追溯陸地起始容量、路程與鄰近目標。此報告不表示海上資源或整圖競技平衡已完成。

高度增量：acceptance 圖 x=2–5、y=11–14 為高地，x=4、y=8–10 是高度 25／50／75 的土路階梯，平台高度 100。其餘高差邊界阻擋陸地通行；其中 (2,11) 為不可通行崖格，(3,13) 為高地石面。詳見 heights-verification.md。
