# 首次使用修正迴圈 012：戰鬥、摧毀與征服勝負

2026-09-25，E 階段第四個可玩里程碑。玩家可以從開局一路玩到勝利並再開一局，但紅方還沒有 AI，所以仍不是完整對戰。

環境：Node 22.23.1、Darwin 27.0.0 arm64、Chromium 151.0.7922.34。seed 260925，ruleset `93b1d368`，State／snapshot v15。

## 新增的真實行為

- **攻擊命令**：選取單位後，右鍵紅方單位或紅方建築。目標必須在自己的視野內，而且是敵方，否則會說明原因並拒絕。
- **戰鬥規則**：固定傷害、固定冷卻，沒有隨機數。
  - 近戰會找目標周圍還沒有人站的位置，包圍而不重疊。
  - 遠程在射程內就停下射擊。
  - 目標消失或離開視野時，攻擊者在下一個節點停下。
- **自動迎擊**：閒置的士兵會攻擊視距內最近的敵軍；村民不會自動攻擊。
- **死亡**：單位死亡時人口減一，身上的貨記為損失，並留下 2 秒的倒地畫面（死亡姿勢）。
- **建築受損與摧毀**：
  - 生命低於一半時換成破損外觀（沿用模型既有的受損狀態）。
  - 摧毀後移除並恢復導航，重新計算人口上限；地基與佇列的費用不退。
- **征服勝負**：一方沒有任何單位與建築就判負。畫面顯示「勝利／戰敗」與 tick，並提供「再開一局」；判定後模擬拒絕所有命令。
- **畫面**：受傷單位頭上顯示血條；攻擊時人偶面向目標擺出攻擊姿勢，剛受擊時做受擊姿勢。選取清單與建築面板顯示生命值。
- **遊戲速度**：頂列可切換 1×／2×／4×，每秒 20／40／80 tick，不會跳過任何 tick。
- **所有數值都是 design_default**，見 data-model.md 的 v15 段落。

## 實際流程（`npm run test:combat`，4× 速度，全程滑鼠與鍵盤）

1. **開局**：速度切到 4×。村民 1 蓋住宅，村民 2、3 蓋兵營；完工後人口 3/10。
2. **集結點**：右鍵點兵營本身，被拒絕並顯示「集結點不能設在建築、資源或不可通行地形上」；改設 (9.5, 8.5)。
3. **訓練民兵**：加入兩名民兵，同時派三名村民前往紅方基地。
4. **手動攻擊**：右鍵紅方村民 →「村民 1、村民 2、村民 3 攻擊紅方村民」→ 交戰中有人「攻擊中」、有人「等待讓路」→ 紅方村民倒下。兩名民兵出生，人口 5/10。
5. **偵查記憶**：迷霧除錯顯示「紅方城鎮中心 (10, 3)：最後看見 tick 1419」。
6. **攻城**：框選兩名民兵，右鍵紅方城鎮中心 → 兩人「攻擊中」→ tick 2129 顯示「勝利：紅方已沒有任何單位與建築」。
7. **再開一局**：結果層關閉，HUD 回到「第一時代 · 食物 200 · 木材 200 …」。
8. 沒有 pageerror、console.error 或外部請求。

| FU12-2／高（卡住） | 目標死亡後，攻擊者仍沿原路線前往舊位置，在人群裡反覆尋路、等待，最後被判定受阻。 | 目標消失或看不見時，攻擊者在下一個節點停下。測試：擊殺後的下一 tick，攻擊紀錄清除且狀態為待命。 |
