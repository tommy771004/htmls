# C：起始資源可達性

## 實作契約

- 草甸、海岸及手工圖均保留成對的保證樹木與石礦位置；移除會與保證區域重疊的隨機地物，金礦／野果沿用固定成對配置。
- 生成時從雙方主要出生點走完整陸地導航圖，為各資源找安全的鄰近節點；距離依真正可通行的圖邊計算，不用直線距離代替。
- startingResourceRules（design_default）要求每方在 1200 模擬距離內至少有 tree 300、stone 250、gold 250、berries 150 的可接近容量，雙方各種類最近路程差不得大於 500。這是工程起始條件，不是原作規則。
- 原物件占地已擴張單位半徑；鄰近節點必須位於安全側，且與擴張占地的曼哈頓間距在 1–50 之間。此參數目前用於起始資源檢查，不表示村民採集距離已實作。
- 生成失敗沿用最多 8 次確定性重試及可讀錯誤。此門檻只在初始生成驗證，不會在遊戲中因資源正常耗盡判定存檔無效。

匯出的 docs/maps/*.json 新增 startingResources 報告，列出雙方出生點、每種類可接近總量、最近距離、符合門檻的節點 ID 與 approach 座標，可由 tests/starting-resources.test.ts 重建路徑驗證。
