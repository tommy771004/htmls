# C：有開口的拱件

2026-09-25。新增 apps/web/brick-geometries.ts，使用原創 2D 拱形輪廓擠出實體幾何。BuildingPart 可宣告 shape=arch，城鎮中心入口及第三／四時代住宅門框改用此元件。幾何快取仍由 scene.ts 管理；拱件不註冊為一般方塊的低面數替代物，因此 LOD 不會用實心方塊封住拱下開口。

元件原點為 X/Z 中心、Y 底部；外框、弧線與厚度為 design_default 美術參數，不是原作通行數值。這一版拱件沒有倒角，完整元件庫仍未完成。

## 驗證

build 通過。新測試以實際 Three.js Raycaster 檢查三種尺寸：拱下不命中、左右支柱與拱頂會命中，近／中／遠細節均保留同一開口；另檢查有限頂點、底部原點、尺寸與非法參數拒絕。

增加通道高度檢查時，最初用所有拱件高度的 85% 當作開口上限，對較高但同寬的拱件不成立；已改為各實例的明確驗收高度 0.85、1.1、1.25 世界單位，不以錯誤比例要求修改拱形。這只是射線開口證據，不是人偶通行證據。

模型測試覆蓋住宅四時代、城鎮中心切換、近側角度、施工／受損／還原，以及既有 LOD、騎乘、圖形故障與重新載入流程。截圖在 test-results/house-age-3.png、house-age-4.png、economic-town-center.png。

最終結果：75/75 單元測試通過；test:rig-browser 在 Chromium 151.0.7922.34 通過，包含近／中／遠細節還原及兩種渲染故障復原。已人工檢視第三時代住宅與城鎮中心截圖，模型正常顯示；住宅仍保留關閉門板。git diff --check 通過。此輪未重跑完整沙盒 test:browser，也未進行目標硬體效能量測或完整對局驗收。

正式沙盒仍是第二時代住宅，權威碰撞不變；住宅門板與完整 AABB 仍不允許穿越。城鎮中心也仍是展示模型，不能以視覺拱洞宣稱入口導航完成。此增量沒有新可玩里程碑，C 保持 in_progress。
