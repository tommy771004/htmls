# C：城鎮中心、市場與鐵匠舖

2026-09-25。擴充 apps/web/economic-building.ts 與模型頁，現有住宅加七種村落功能建築代表外觀。新增原創鐘樓／階梯／公告板／貨物區、條紋市場攤棚／貨物／秤，以及冷爐／煙囪／砧座／風箱／煤箱。鐵匠舖不播放無真實研究狀態的工作火焰，市場不提供假交易按鈕。

所有美術尺寸及外觀狀態為 design_default，不填入原作未知成本、生命、科技或生產數值。新模型沿用五段施工、受損、最多 12 塊裝飾殘骸及完整還原，並接入近／中／遠三段幾何細節。正式遊戲仍使用住宅，沒有新增權威建築種類、功能或模擬 footprint。

## 邊界

這是代表資產，不是完整村落高細節驗收：城鎮中心拱件、完整時代演進、工作動畫、實際可達入口及完整軍事／宗教等建築仍缺。市場通道是模型留白，未證明導航可通行。生產、交易、研究、駐軍尚未接入；沒有新可玩里程碑，不以此代替 prompt 19 或完整對局。C 保持 in_progress。
