# 首次使用修正迴圈 010：建造與人口

2026-09-25，E 階段第二個可玩里程碑，不是完整對局。

環境：Node 22.23.1、Darwin 27.0.0 arm64、Chromium 151.0.7922.34。seed 260925，ruleset `716338ce`，State／snapshot v13。

## 新增的真實行為

- **放置**：選取村民 → 側欄「住宅 · 木材 30」或「兵營 · 木材 150」（名稱與費用讀自規則資料）→ 場景中出現占地預覽。
  - 預覽合法時為綠色；不合法時為紅色，並即時寫出原因：與建築或資源重疊、地形不可建造、高度不一致、尚未探索、有單位站在預定地上、超出地圖。
  - 左鍵放置；Shift＋左鍵連續放置；右鍵或 Esc 取消，不會發出任何命令。
- **按鈕停用原因**：按鈕不能按時，下方會寫出具體原因（先選取村民；「木材不足：需要 30，目前 20」），不是只變灰。
- **金流**：放置的那個 tick 預留（扣款），完工時結算，取消時全額退款。
  - 同一 tick 兩道命令搶同一筆錢時，後到的那道在執行時被拒，畫面顯示「指令在 tick N 未執行：…」，不會重複扣款。
- **施工**：村民走到地基外圍的施工點，每人每 tick 貢獻 1 點工作量（住宅與兵營各需 400）；兩人施工明顯比一人快。模型依 0／20／40／60／80／100% 分段搭建。
- **人口**：住宅完工後人口上限 +5。上限 = min(40, 己方已完工建築的容量)，城鎮中心提供 5。HUD 顯示「人口 3/5 → 3/10」。
- **建築選取**：左鍵點自己的建築，側欄顯示施工百分比；未完工時可「取消建造（退回 木材 150）」。取消後地面恢復可走，施工者停下。
- **協助施工**：選取村民後，右鍵點未完工的建築。
- **導航**：地基放下後立即阻擋。原本路線穿過地基的單位會在下一個 tick 重新規劃；測試驗證它們繞路抵達，從未踏進地基。
- **規則數值都是 design_default**：容量、施工量、格線 50，以及城鎮中心視野 600。

## 實際流程（`npm run test:build`）

全程用滑鼠與鍵盤；合法與不合法的位置，都用 Worker 同一條規則在同一張 seed 地圖上找出來。

1. **首次進站**：HUD 顯示人口 3/5。按 Esc 取消預設選取後，建造按鈕停用，並說明「先選取村民才能建造。」
2. **框選三名村民，按「住宅」**：
   - 把預覽移到城鎮中心上：紅色，顯示「不能放在這裡：與建築或資源重疊」。
   - 移到空地：綠色，顯示「左鍵放置住宅…」。
3. **放置住宅**：提示「村民 1、村民 2、村民 3 前往建造住宅；放置時扣除 木材 30」；前進 1 tick 後，木材 200 → 170。
4. **施工與完工**：開始模擬後出現「施工中」與「前往工地」，完工後人口 3/5 → 3/10。
5. **放置兵營**：木材 170 → 20。兩個按鈕都停用：「住宅：木材不足：需要 30，目前 20　兵營：木材不足：需要 150，目前 20」。
6. **取消兵營**：點兵營地基，側欄顯示「兵營 施工中 0%」；按「取消建造」→「已取消兵營，退回 木材 150」，木材回到 170。
7. **取消放置模式**：用側欄選村民 1 後進入放置模式，按 Esc 顯示「已取消放置。」；再進一次，右鍵同樣取消，都沒有發出命令。
8. **存讀與重播**：儲存 → 重建（人口回到 3/5）→ 讀取，HUD 與指紋恢復；重播 346 ticks 一致。
9. 沒有 pageerror、console.error 或外部請求。

截圖在 `test-results/`：`build-preview-invalid.png`（紅色預覽）、`build-preview-valid.png`、`build-under-construction.png`（地基與施工中的村民）、`build-house-complete.png`。
