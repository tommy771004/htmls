# C：代表步兵輪廓增量

2026-09-25。`apps/web/unit-rig.ts` 新增劍盾兵、長矛兵、弓兵外觀，模型檢視頁可實際切換。盾牌掛在左手，劍／長矛／弓掛在右手；頭盔、胸甲、羽飾與箭袋形成不同輪廓。外觀是原創 design_default，不包含原作生命、攻速或傷害值。正式遊戲仍使用村民；snapshot v9 不變。

`npm run build` 與 64 項程式測試通過。新增測試檢查每次切換只有一組服裝可見、武器種類及掛點、盾牌切換、還原村民與非法角色拒絕。原有所有工具關節與剛體矩陣檢查亦通過。

完整 `npm run test:browser` 通過桌面／手機、地形、迷霧、存讀、重播、Worker 與 WebGL 故障恢復及網站分類。模型專用 `npm run test:rig-browser` 另操作三種軍種的正側角度，並驗證切回村民後與原始畫面一致；建築狀態還原測試仍保留。瀏覽器為 Chromium 151.0.7922.34。

目視檢查曾發現模型側面被住宅遮擋；第一次移位又靠近羊隻，遂依實際生成器障礙位置，把展示人偶移到 (650,950)、(800,950)。這是驗收頁位置，不改正式遊戲出生、模擬占地或導航。截圖位於 `test-results/role-*.png`。

此增量只驗收步兵模型，不宣稱訓練、投射物、攻擊或完整對局已完成。弓兵目前使用共用姿態，專用拉弓動作、骑乘模型、其餘軍種與遠距 LOD 辨識仍待完成。C 保持 in_progress；最近可玩里程碑首次使用驗證仍見 first-use-006.md。

## 重測異常紀錄

最終展示位置的一輪模型測試在建築還原比對失敗：實際 PNG 約 4 KB，對照約 203 KB，呈現接近空白畫面。當輪未收集 console，無足夠證據判定根因，不能宣稱已修復圖形問題。測試現改用 Buffer.equals 產生簡潔的失敗訊息並包含頁面錯誤文字，同時收集 console error，避免巨大二進位差異輸出。相同建置與同一路徑重跑通過，無錯誤輸出；暫列一次未重現的圖形測試異常，後續可玩里程碑首次使用回歸須繼續追蹤。
