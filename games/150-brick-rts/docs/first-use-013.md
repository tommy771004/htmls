# 首次使用修正迴圈 013：整頁改成遊戲畫面

2026-09-26。使用者說明原本的目標：用積木重做《世紀帝國 II 決定版》，所以整頁都應該是遊戲畫面，其他內容都不需要。這一輪只改畫面與操作，模擬、規則與存檔格式都沒有變。

環境：Node 22.23.1、Darwin 27.0.0 arm64、Chromium 151.0.7922.34。seed 260925，ruleset `93b1d368`，State／snapshot 仍為 v15。

## 畫面配置

- **整個視窗就是遊戲**：頁面不捲動。上方是資源列，中間是 3D 戰場，下方的 HUD 由左到右是指令格、選取資訊、小地圖，順序與原作相同。
- **資源列**：食物、木材、黃金、石頭、人口（滑鼠停留時顯示佇列保留的人口；滿了會變色），置中是時代名稱；右側是遊戲時間、速度、暫停／繼續和「選單」。
- **指令格（5×3）**：只放真的能用的指令，沒有做樣子的按鈕。
  - 選取村民時：住宅（Q）、兵營（W）、停止（S）。
  - 選取建築時：生產與研究依序是 Q W E R T；已研究的時代會從指令格移除；未完工的建築有取消格（Del）。
  - 滑鼠停在格子上時，戰場左下角出現說明卡：名稱、快捷鍵、費用（不足的標色）、時間、人口，以及不能按的原因。沒有停在格子上時，同一處寫出目前不能建造或生產的原因。
- **選取資訊**：
  - 單一單位：頭像、名稱、生命條、攻擊、近戰或射程、攜帶的資源、目前狀態。
  - 多名單位：每人一格頭像加血條；放不下時最後一格顯示「+N」，不會被裁切。
  - 建築：頭像（依時代換外觀）、生命條、施工或完工狀態、集結點；佇列在右側，第一項有進度條，每項都能取消。
- **小地圖**：依鏡頭方向與俯角繪製，所以目前的視野是一個長方形白框。
  - 顯示三態迷霧、已知的建築與資源，以及畫面上看得到的單位。
  - 左鍵點或拖曳移動鏡頭；右鍵對選取的單位下達移動，選取建築時設定集結點。
  - 旁邊依序是閒置村民（角落顯示人數，快捷鍵「.」）、拉近、拉遠、旋轉。
- **選單（F10）**：回到遊戲、儲存、讀取、新遊戲（地圖與種子）、驗證指令重播、操作說明、積木模型檢視與返回作品集。開啟時暫停，關閉後恢復。
- **進站就開始**：鏡頭對準自己的城鎮中心，遊戲直接運行。F3 暫停時，戰場上方顯示「已暫停」；觸控裝置不顯示 F3 提示。
- **圖示**：頭像與所有圖示都是遊戲內積木模型的即時算圖，用獨立的 WebGL context 各畫一次。沒有使用圖示套件，也沒有外部請求。
- **除錯模式**：網址加 `?debug=1` 時，右側（手機為下方）出現除錯抽屜，內容是舊頁面的開發工具：
  - 逐 tick、狀態指紋、村民 1–3 按鈕、X／Y 座標移動。
  - 迷霧除錯、規則 JSON 驗證器、鏡頭歸位。
  - 除錯模式開局是暫停的，既有的自動流程都改用這個模式。
- **拿掉的內容**：
  - 開發日誌與規則說明段落。
  - 側欄與頁尾。
  - 「全景」按鈕：改由 H 鍵回到城鎮中心，除錯抽屜另有「鏡頭歸位」。
- **新增的快捷鍵**：H 選取城鎮中心並移動鏡頭；「.」輪流選取閒置村民；Q W E R T 對應指令格；Del 取消建造；F3 暫停；F10 選單。方向鍵在任何時候都平移鏡頭，因為頁面已經不會捲動。

## 實際流程（`npm run test:hud`，一般模式，不加 debug）

1. **首次進站**：約 0.6 秒後開始運行。頂列、戰場、HUD 剛好填滿 1440×900，沒有捲動。除錯抽屜、逐 tick、迷霧除錯、規則編輯器、座標移動、鏡頭歸位、選單都不在畫面上。資源列顯示 200／200／100／100、人口 3/5、第一時代，圖示是模型算圖。
2. **閒置村民**：閒置人數為 3。按「.」後，選取資訊顯示村民頭像、25/25，指令格出現住宅、兵營、停止。滑鼠停在住宅上，說明卡顯示「住宅（Q）、木材 30、20 秒 · 提供人口 5」。
3. **採集**：切到 4×，右鍵城鎮中心旁的野果，提示「村民 1 前往採集」，資源列的食物變成 210。
4. **建造**：再按「.」選下一名閒置村民，按 Q，把預覽移到空地，出現「左鍵放置住宅」；左鍵放置後木材變成 170，完工後人口 3/10。
5. **生產**：按 H 選取城鎮中心，指令格出現村民與三個時代。點村民後，佇列出現「村民 · 3%」與進度條；村民出生後人口 4/10。
6. **選單與暫停**：F10 開啟選單時遊戲暫停，tick 不再前進；Esc 關閉後繼續。F3 顯示與隱藏暫停提示。
7. **小地圖**：左鍵點右側，鏡頭焦點從 (4.0, 4.85) 移到 (11.7, 4.3)。選取閒置村民後右鍵小地圖，提示「村民 3 的移動指令已排入」。
8. **手機 390×844**：沒有溢出；HUD 高 253 px（30%），戰場高 515 px。輕觸村民會顯示頭像（村民 · 藍方 · #1），輕觸地面則排入移動指令。
9. 沒有 pageerror、console.error 或外部請求。作品集縮圖 `thumbs/150.jpg` 由這個流程從正式遊戲畫面擷取。

截圖在 `test-results/`：`hud-first-visit.png`、`hud-villager.png`、`hud-town-center.png`、`hud-menu.png`、`hud-390.png`。

## 未驗證項

- 多選超過選取區容量時的「+N」格：目前的流程最多只選到 5 名單位，沒有實際觸發。
- 目標硬體效能；小地圖每次畫面更新時重畫整張（256 格），目前沒有量測成本。
- 頭像算圖使用第二個 WebGL context；在只允許一個 context 的裝置上會失敗，此時格子改顯示文字名稱（`no-icons`），這條路徑沒有自動測試。
- 敵方單位與建築的檢視（原作可點選敵方查看資訊）。
- 小地圖訊號、邊緣捲動、快捷鍵自訂。
- 螢幕閱讀器實際朗讀。
