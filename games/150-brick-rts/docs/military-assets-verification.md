# C：兵營、靶場與馬廄代表模型

2026-09-25。新增 apps/web/military-building.ts，模型页可切換兵營、靶場與馬廄。兵營含操練地板、盾牌架與長矛架；靶場含背板、標靶、側欄與箭架；馬廄含隔間、乾草、馬槽與鞍架。保留原創積木材質與玩家色，不使用原作貼圖或推測原作成本。

三種模型都有基座、結構、上層／標靶、功能細節、旗幟五段，以及受損、12 塊有界殘骸與還原。沿用三段 LOD。3×3 美術占地與四時代的參數化支柱／屋頂目前只是代表資產，並非完整四時代細節；靶場也未提供四套時代轮廓。

## 驗證

build 與 74 項程式測試通過，原始輸出在 test-results/military-tests.log。新增測試覆蓋三類×四時代×五段施工：唯一 ID、有限正尺寸、水平占地邊界、分段累加、受損與還原、有限殘骸及不同類型幾何。

模型瀏覽器測試操作三類模型、正側角度、施工與殘骸，最後切回住宅並比對原始 canvas；LOD 還原、人偶／騎乘與圖形故障恢復也保留。已目視檢查 economic-barracks.png、economic-archery-range.png、economic-stable-side.png。檔名前綴沿用既有模型檢查腳本，不代表三者具有經濟功能。
