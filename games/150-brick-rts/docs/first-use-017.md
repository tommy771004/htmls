# 首次使用修正迴圈 017：投降、斥候與大地圖效能

2026-09-26。處理上一輪留下的項目：
- 大地圖上找不到最後一名單位，對局收不了尾；
- 大地圖的畫面效能；
- 原作標準開局的斥候。

State／snapshot v18。

## 新增的真實行為

- **投降**：
  - 選單的「投降」第一次按下只會變成「再按一次確認投降」，4 秒內再按一次才會投降。不使用瀏覽器對話框。
  - 投降後結果畫面顯示「戰敗：你已投降」，可以再開一局。
  - 電腦在沒有城鎮中心、也沒有民兵或弓手時投降。本作的城鎮中心無法重建，所以這時已經不可能翻盤。
- **斥候**（原作標準開局有，見 aoe2-rules-research.md）：
  - 只在曠野出現，雙方各一名，開局人口 4/5。
  - 騎馬的積木人偶；移動速度是村民的兩倍，視野 550（其他單位 400），只在下令時戰鬥。
  - 目前不能訓練：還沒有馬廄。
  - 電腦的斥候：
    - 閒置時自動騎往最近的未探索格，所以電腦攻擊的是實際看到的建築。
    - 找不到建築時，才用地圖點對稱位置作為後備。
- **卡頓處理**：畫面卡住超過一秒時，遊戲暫時放慢，不再自動暫停。
- **分塊繪製**：靜態物件依 8×8 格分塊，畫面外的區塊不繪製。

## 大地圖效能：量到的與沒量到的

- **模擬**（Node 無畫面）：曠野對電腦平均每 tick 0.12 ms。
- **頁面**：
  - 同樣在除錯模式、同樣的畫布，曠野每幀約 40 ms，草甸約 23 ms（無畫面 Chromium、軟體繪圖）。
  - 繪圖呼叫次數相近（172–191）。
  - 剖析顯示頁面 JavaScript 不到 2%，其餘都在軟體光柵化。
  - 分塊剔除在這個環境下沒有改變幀時間，但在實際 GPU 上應能減少畫面外的繪製。
- **沒量到**：實際 GPU 的幀時間。這台機器的無畫面環境無法代表。
