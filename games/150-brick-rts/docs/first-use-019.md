# 首次使用修正迴圈 019：送返建築與馬廄

2026-09-26。F 階段的第一個切片：原作裡村民不必每趟走回城鎮中心，基地會蓋伐木場、採礦場與磨坊；第二時代可以蓋馬廄訓練斥候。State／snapshot v19。

## 新增的真實行為

- **送返建築**（村民的指令格）：
  - R 伐木場：只收木材。
  - T 採礦場：收黃金與石頭。
  - A 磨坊：只收食物。
  - 三者都是木材 100、20 秒、300×300。只有完工的才收貨；村民把貨送到最近能收這種資源的建築。
  - 滑鼠停在指令格上，說明卡寫出這座建築收什麼。
- **馬廄**（D）：木材 175，需要第二時代。
  - 第一時代時按鈕不能按，說明卡與按鈕的無障礙名稱都寫「需要第二時代」；直接送出命令也會以同一個原因拒絕。
  - 完工後可以訓練斥候（食物 80、人口 1）。
- **電腦**：兩名以上村民要從離收貨建築超過 350 的地方送木材（或黃金、石頭）時，在那個資源旁蓋伐木場（或採礦場）。
  - 在 260925 的曠野對局中，伐木場在 tick 5051 完工，採礦場在 tick 7937。
  - 電腦不蓋磨坊與馬廄。

所有費用、時間、生命值與收貨規則都是 design_default，沒有對照原作的數值。

## 實際流程

- `npm run test:hud`（一般模式，曠野）新增：
  - 滑鼠停在伐木場格上，說明卡是「伐木場（R）／100／20 秒 · 村民可在此送交木材」。
  - 滑鼠停在馬廄格上，說明卡是「馬廄（D）／175／20 秒／需要第二時代」，按鈕不能按。
- `npm run test:stable`（一般模式，曠野）：
  1. 在模擬中實際玩出一局：採野果到 300 食物、升第二時代、蓋馬廄、採木、蓋農田並耕作。共 6 筆命令，tick 4692。
  2. 存檔後從選單讀取。頁面會用命令紀錄重新推導，所以存檔不能直接改資源。第一次嘗試直接給資源時，讀取被拒絕：「食物不足：需要 300，目前 200」。
  3. 按 H，再用滑鼠點選馬廄：選取資訊顯示「馬廄」，斥候格可以按。
  4. 訓練斥候：人口 4/5 → 5/5，食物扣 80；斥候在馬廄旁出生，動態訊息顯示「斥候已生產」；食物不夠時，斥候格寫出原因。
  5. 沒有 pageerror、console.error 或外部請求。截圖已人工檢查：馬廄模型、頭像、斥候都正確顯示。

## 驗證

- 單元測試 145 項，這一輪新增或擴充：
  - 營地只收自己的資源、完工後才收，村民把木材送到較近的伐木場（`gather.test.ts`）。
  - 馬廄在第一時代被拒絕，升時代後可以蓋，完工後訓練斥候；馬廄不能訓練民兵（`production.test.ts`）。
  - 電腦的對局中，伐木場與採礦場都完工（`ai.test.ts`）。
- 乾淨目錄結果見文末。

## 未驗證項

- 營地在村民送貨途中被摧毀時的改道：程式會在抵達時改找下一個收貨點，但沒有專門的測試。
- 電腦不蓋磨坊與馬廄，也不訓練斥候；陣亡的斥候不會補。
- 射箭場、鐵匠鋪、市場、修道院、碼頭、箭塔、城牆與城堡都還不能蓋；僧侶（治療、轉化）還沒有。
- 採集科技（例如提高攜帶量的升級）還沒有，所以營地目前只縮短送貨路程。
- 實際 GPU 的幀時間仍未量測。
