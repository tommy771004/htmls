# 首次使用修正迴圈 021：修道院與僧侶

2026-09-26。F 階段第三個切片，對應建置順序 F 的「宗教」：修道院、僧侶的轉化與治療。State／snapshot v21。

## 先查規則

補在 [aoe2-rules-research.md](aoe2-rules-research.md)，可信度都是中：

- **修道院**：城堡時代（本作第三時代），沒有其他前置建築；木材 175。
- **僧侶**：黃金 100，生命值 30，射程 9，攻擊 0；轉化敵方單位，治療己方單位。
- **轉化**：
  - 單位需要 5–15 秒，建築需要 18–30 秒。
  - 轉化後，信仰要 62 秒才能恢復。
  - 沒有「救贖」科技時，不能轉化建築；城鎮中心、修道院與農田即使有「救贖」也不能轉化。
- **查不到**：
  - 治療速度與範圍，以及每 1.2 秒一次轉化判定的機率曲線；
  - 「僧侶轉化僧侶需要贖罪」。本作不讓僧侶轉化僧侶，這是本作的設計，不宣稱是原作規則。

## 新增的真實行為

- **修道院**（村民指令格的 X）：木材 175，需要第三時代。
  - 積木模型：石灰岩中殿與拱門、後角的鐘樓（開放的鐘室，鐘吊在頂板下），以及圍牆香草園。
  - 各時代的外觀不同：第二時代加石頭基座，第三時代加扶壁與屋脊，第四時代加尖塔與圓窗。
  - 所有零件都有支撐，施工與毀損狀態可以還原，這些都有測試。
- **僧侶**：在修道院訓練，黃金 100。
  - 外觀：無染羊毛的修士袍、兜帽、繩腰帶、隊伍顏色的聖帶，以及木杖。
  - 選取資訊顯示「轉化射程 3.5 格」與「信仰 N%」；狀態列顯示「轉化中」「治療中」或「信仰恢復中 N%」。
- **轉化**：選取僧侶，右鍵看得見的敵方單位。
  - 僧侶走到範圍內，停在原地施法，面向目標。
  - 5–15 秒（由對局的種子亂數決定）後，單位連同生命值換邊，外觀改成我方的顏色，動態訊息顯示「轉化了紅方村民」。
  - 同時選取其他士兵時，士兵照常攻擊，僧侶負責轉化。
- **治療**：右鍵受傷的己方單位；閒置的僧侶也會自己治療附近的傷兵，每秒 1 點。
- **不能做的事**會直接說明原因：僧侶攻擊、轉化建築、轉化僧侶、治療僧侶，以及信仰未滿時再轉化。
- **音效**：下令轉化時有一段上行的和聲；轉化成功時有三個上行音。

## 實際流程（`npm run test:monastery`，一般模式，曠野，紅方不行動）

1. 從選單讀取固定腳本的存檔：第三時代，人口 5/5。
2. 點選修道院：僧侶格寫出「僧侶（黃金 100）：黃金不足：需要 100，目前 50」。
3. 點選僧侶本人：選取資訊顯示「轉化射程 3.5 格、信仰 100%、待命」。
4. 右鍵小地圖，讓僧侶走向紅方基地；看得見紅方村民後，右鍵它：「僧侶 6 轉化紅方村民」。
5. 狀態變成「轉化中」，接著動態訊息「轉化了紅方村民」；人口 6/5；僧侶顯示「信仰恢復中」。
6. 轉化後的村民是藍色（截圖確認）。沒有 pageerror、console.error 或外部請求。

- 治療速度與範圍、僧侶速度（和村民相同）、修道院生命值都是 design_default。

- 瀏覽器流程只驗證了轉化；治療由單元測試涵蓋，沒有在頁面上操作。
