# C：騎乘代表模型

2026-09-25。新增 apps/web/character-rig.ts，組合現有人偶與原創積木馬匹。馬匹有四個腿部旋轉關節、頭頸、尾巴、蹄與玩家色鞍墊；具名 rider-saddle 掛點持有騎手，手部工具繼續使用原 hand sockets。

鞍座位置與人偶坐姿相配，腿分開至馬體兩侧；待命、行走及共用攻擊姿態可在模型頁預覽。全部為剛體變換，不伸縮模型。模型頁騎乘選取圈半徑為 0.846 世界單位；遊戲沒有騎兵或其權威碰撞半徑。切回村民會移除馬匹顯示、還原人偶父節點、腿位與圈大小。

未完成的騎乘工作、搬運、受擊與死亡姿態在下拉選單中停用；API 也拒絕，不以步兵倒下假裝馬匹死亡。正式沙盒仍只使用步行村民，沒有生產、升級、騎兵移動／傷害規則。幾何及掛點尺寸均為原創 design_default，snapshot v9 不變。

## 驗證

build 與 71 項程式測試通過，原始結果在 test-results/mounted-tests.log。新增測試以三種姿態各 51 個時間點檢查鞍座連接、固定騎手高度、蹄部未穿地、矩陣有限及 scale=1，並驗證拒絕未支援姿態、切回步行及反覆切換不重建多匹馬。

初次蹄部測試抓到約 -2.38e-9 的 Float32 幾何誤差；已把零容差改為 1e-6 世界單位，並提高步態抬腳量、增加整週期採樣，避免把實際穿地藏在誤差中。

模型瀏覽器測試切換騎兵、正側角度、行走播放與返回村民；既有住宅、經濟建築、LOD 還原與圖形故障恢復流程保留。option 的 disabled 檢查改讀 DOM property，避免 Playwright 的控制項判定不涵蓋 option 而誤判。實際截圖位於 role-cavalry.png、role-cavalry-side.png、cavalry-walk.png。

此版是代表騎乘資產，專用騎乘攻擊細修、死亡拆解、繮繩／騎射、軍種完整矩陣及權威碰撞整合仍待完成。未新增可玩里程碑，不以模型驗收代替 prompt 19 或完整對局。C 保持 in_progress。

最終選取圈調整後的模型測試再次通過；role-cavalry.png 與 cavalry-walk.png 已目視檢查。完整 test:browser 在 Chromium 151.0.7922.34 通過桌面／手機、視野、地形、存讀／重播、Worker／WebGL 故障與分类。
