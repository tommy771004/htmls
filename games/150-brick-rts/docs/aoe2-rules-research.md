## 鐵匠鋪、護甲與兵種相剋（2026-09-29，未另外查證）

- **傷害公式**（一般玩法常識）：傷害 = 攻擊 − 對應護甲（近戰或遠程）＋對目標類別的加成，最少 1。本作照此實作。
- **相剋關係**（一般常識）：長槍兵剋騎兵、散兵剋弓兵、弓兵對長槍兵有加成、騎士是重騎兵；建築對箭矢有較高的遠程護甲。
- **鐵匠鋪科技的名稱、時代與順序**：鍛造、鑄鐵、高爐；鱗甲、鎖子甲、板甲；鱗片／鎖子／板甲馬鎧；羽箭、錐形箭、護腕；襯墊、皮革、環甲弓手甲。費用（例如鍛造食物 150、羽箭食物 100 黃金 50）與效果（攻擊 +1／+1／+2、護甲 +1/+1、+1/+1、+1/+2、弓兵射程 +1）憑記憶，**unverified**。
- **兵種升級**：重步兵、長劍士、長矛兵、弩手、精銳散兵、輕騎兵；費用憑記憶，**unverified**。
- **本作的數值全部是 design_default**：本作的生命、攻擊、冷卻是自己的尺度（例如近戰民兵生命 45、攻擊 6、每秒 1 擊），加成依比例縮放（長槍兵對騎兵 +12，原作 +15）；弓兵射程 +1 格在本作是 +0.5 格。

## 城鎮中心、箭塔、駐軍與攻城槌（2026-09-29，未另外查證）

- 一般玩法常識：城鎮中心與箭塔會自動射箭；進駐的村民（城鎮中心）與弓兵（箭塔）增加箭數；鐘聲讓村民躲進建築，「回去工作」讓他們回到原本的工作；攻城槌只能攻擊建築，遠程護甲極高。
- 憑記憶、**unverified**：城鎮中心容量 15、箭塔 5；箭塔費用木材 25 石頭 125；攻城器工坊木材 200、需要城堡時代與鐵匠鋪（部分版本不需要鐵匠鋪）；攻城槌食物 0 木材 160 黃金 75。
- **本作的射程、傷害、冷卻、容量、回血速度都是 design_default**：城鎮中心射程 3 格、箭塔 3.5 格，在 16 格試驗場上已經覆蓋三分之一的寬度，所以取得比原作比例小。

## 基本玩法流程（一般常識，未逐項引用）

1. 開局用斥候探索找食物；村民先採食物與木材，城鎮中心持續生產村民。
2. 四個時代：黑暗、封建、城堡、帝王。升時代需要資源，也需要前一時代的建築。
3. 食物來源依序是野果、羊、狩獵、農田；人口靠住宅與城鎮中心提供。
4. 兵種互相剋制（步兵、弓兵、騎兵、攻城），城鎮中心可以射箭防守。
5. 勝利條件：征服（標準）、奇觀、聖物；本作目前只有征服。

## 對本作的決定

- **地圖放大**：從 16×16 格放大到 32×32 格。
  - 原作 Tiny 是 120 格、城鎮中心 4 格寬，地圖寬約 30 個城鎮中心。本作城鎮中心 3 格寬、地圖 32 格，約 10.7 個，已比原本的 16 格（約 5.3 個）接近許多。
  - 再放大會讓每 tick 的尋路與全圖掃描成本上升，要量測後再決定。
- **出生位置**：
  - 參考 `random_placement` 與 `circle_radius` 的概念：玩家放在以地圖中心為圓心的圓周上，角度隨機（由種子決定），兩人至少相隔約半圈，半徑帶一點隨機變化。
  - 每人周圍的基地資源以相同的相對配置擺放，並隨出生方向旋轉，確保公平。
  - 具體半徑、角度差與資源距離都是 design_default。
- **開局單位**：原作標準是 3 名村民加 1 名斥候。本作目前沒有斥候兵種，先維持 3 名村民；斥候列為待辦，不宣稱已對齊。

### 換算到本作的尺度

網站的數字照抄，但本作的距離、時間與速度有自己的單位，換算如下（都是 design_default）：

- **射程**：原作 n 格 = 本作 50n＋50；每 +1 格 = +50。弓手 4 格 = 250、長弓兵 5 格 = 300、土耳其火槍兵 8 格 = 450、擲斧兵與阿拉伯奴隸兵 3 格 = 200。羽箭、不列顛射程加成、義勇騎兵與倒鉤斧都照這個規則。
- **視野**：加成每格 = 100（中國城鎮中心 +5 = +500，法蘭克騎士與蒙古斥候 +2 = +200）。單位本身的視野不照原作逐項設定：一般單位共用 400 的視野，近戰單位自動接戰半徑 350、弓兵 400、土耳其火槍兵 450。
- **攻擊間隔**（tick，20 tick = 1 秒）：近戰 = 秒數 ×10（狂戰士 2.03 → 20、拜占庭聖騎兵 1.83 → 18、精銳 1.73 → 17、日本武士 1.93 → 19）；遠程約 = 秒數 ×15 取整（長弓兵 2.03 → 30、連弩兵 3.65 → 55、精銳 3.84 → 58、土耳其火槍兵 3.49 → 50、蒙古突騎 2.0 → 30）。
- **移動速度**：每 tick 走整數單位，節點間距 50，走一個節點要 ceil(50/速度) tick。大約以原作 1.0 ≈ 5.6 換算後取整：條頓武士 0.8 → 4、民兵 0.9 → 5、徒步弓兵 0.96 → 5、日本武士與擲斧兵 1.0 → 6、哥德衛隊與狂戰士 1.05 → 6、菘藍武士 1.2 → 7；騎馬的特殊單位（拜占庭聖騎兵、阿拉伯奴隸兵、蒙古突騎）和騎士同為 10，戰象 4。速度的百分比加成乘上去後四捨五入到整數步長，所以塞爾特步兵 +15% 實際約 +11%（一個節點 10 tick → 9 tick）。
- **百分比加成**：乘在本作的數值上；分時代的加成依時代取代，不累加（例如拜占庭建築生命 +10/+20/+30/+40%）。
- **生命、攻擊、護甲、類別加成、費用、訓練時間**：照網站的數字（去掉已含文明加成的部分，見下）。

### 對本作的決定

- 13 個文明的資料只放在 `packages/content/civs.ts`（加成是效果資料）與 `packages/content/rules.ts`（城堡、特殊單位、精銳升級、特殊科技），模擬由 `packages/sim/civ.ts` 統一計算，沒有依文明名稱分支的程式。所有數值標 design_default，不宣稱等於原作。
- 另加中立的「拓荒者」：沒有加成、沒有城堡，給測試與練習用；除錯模式雙方都是它。它沒有任何效果，每條規則的回答都和不指定文明時相同。
- 目標在本作不存在的加成（船、碼頭、市集、駱駝、城牆、火藥科技、另蓋城鎮中心）不做，寫在 `omitted` 並附原因；目標不存在的 5 項特殊科技（戰狼號、希臘之火、采邑騎兵、砲兵、彈射器）不出現在城堡。
- 海軍特殊單位（維京大戰船）不做。其他 22 個文明之後再加。
- 本作每邊只有一名玩家，團隊加成只作用在自己身上。
