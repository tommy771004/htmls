施工仍然分成五個階段：地基、結構、屋頂、機能件、旗幟與頂飾。受損狀態會移除旗幟、頂飾、風向標、穀物、橫向葉片和部分遮棚；如果頂層屋頂上面還有鐘樓或屋頂小亭，就保留那層屋頂。

## 修正的既有懸空

新增的全建築承托測試找出並修正了以下既有問題：

- 城鎮中心受損時會移除頂層屋頂，但鐘樓原本就坐在這層屋頂上，結果整座鐘樓懸空。
- 住宅門把與窗玻璃、城鎮中心公告紙、兵營盾釘、靶場靶環與靶心、馬廄水面，與承托零件之間各有 0.005 到 0.01 的縫。
- 磨坊塔頂原本插進屋頂，現在屋頂直接落在塔頂上；石柱腳也改成托在木柱下方，不再與柱身重疊。

保留的重疊只有組件套接：斧頭、水車輪轂，以及原本就有的風車輪轂、秤盤吊線等。

## 驗證

- `npm run build` 通過。
- `npm test`：80/80 通過，完整輸出在 `test-results/economic-ages-tests.log`。新增兩項測試：
  - 七類建築的四個時代必須有不同的零件集合，不能只改高度或顏色。
  - `tests/building-support.test.ts` 檢查住宅與十一類建築：四時代 × 六個施工值 × 兩種生命值，每個零件都要透過面接觸或重疊連回地基。只碰到邊或角不算承托。這項測試只是幾何連通檢查，不是結構力學證明，也不能取代完整的穿模驗收。
- `test:rig-browser`，Chromium 151.0.7922.34：
  - 第一次執行在約 190 秒時發生**非注入的** WebGL context lost，停在市場第 3 時代往第 4 時代切換的地方。頁面依照設計停止繪圖並停用控制項。診斷存在 `test-results/economic-ages-run1-context-loss.json` 與 `.png`。
  - 第二次完整執行通過，輸出在 `economic-ages-rig-2.log`，包括二十八組經濟建築時代的雙角度截圖、相鄰時代的畫面差異，以及施工與損壞後的精確還原。三角形觀測值與上一輪相同：near 42,744、medium 32,712、far 14,152。
- 另外在同一個模型頁跑了 400 輪、不截圖，每輪切換建築、時代、施工三個選單，約觸發 1,200 次重建。`renderer.info.memory.geometries` 穩定在 217，沒有 context loss。`performance.memory` 是粗略的分級讀數，一直維持 14 MB，只能當參考。重建流程沒有觀察到幾何洩漏。第一次的 context loss 只出現在長時間、大量截圖的執行中，根因仍然不明，可能和之前記錄的偶發空白畫面有關，但沒有證實。
- 正式沙盒 `test:browser` 全部通過，輸出在 `economic-ages-browser.log`。住宅的兩個 0.005 縫已修正，會影響正式沙盒的外觀。
- 人工檢視了以下截圖：城鎮中心、磨坊、農田、採礦場、伐木場、市場的第 4 時代，鐵匠鋪第 4 時代側視，市場第 2、3 時代，城鎮中心第 3 時代，伐木場第 3 時代側視。新增結構都有出現，沒有看到懸空或凸點穿出。市場第 3 時代的前方拱廊在預設斜角下被旗桿與遮棚擋住，不太容易辨認，遠景辨識仍需另外驗收。

## 界線

目前只有模型檢視頁的時代選單會改變外觀。正式沙盒仍然只有第二時代住宅。這一輪沒有加入採集、生產、交易、研究、放置、入口導航或作業區，也不是新的可玩里程碑，因此沒有執行 prompt 19、完整對局或目標硬體測試。C 仍是 in_progress：元件庫、入口與作業區、權威占地一致性，以及剩餘資產與工作動畫都還沒完成。ART_DETAIL_MATRIX 的近景細節也還沒補齊，例如磨坊可見齒輪與入料口、市場貨箱與車道、鐵匠舖工具架、伐木場樹樁；各建築的工作／互動狀態也都還沒做。
