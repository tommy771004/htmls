## 實際流程

- `npm run test:feudal`（原本的 `test:stable` 改名擴充，一般模式，曠野）：
  1. 在模擬中實際打出一局，共 9 筆命令：野果、升時代、採木、住宅、兵營、馬廄、靶場、農田。
  2. 從選單讀取存檔。
  3. 點選兵營：只有民兵，沒有弓手格。
  4. 點選馬廄，訓練斥候：人口增加，食物扣 80，「斥候已生產」。
  5. 點選靶場，訓練弓手：木材扣 40、黃金扣 30，「弓手已生產」。
  6. 沒有 pageerror、console.error 或外部請求。截圖已看過：靶場模型、頭像、弓手格都正確。
- `npm run test:full`：
  - 升第二時代，採野果的村民去採木。
  - 木材 300 時（tick 4626）用 Z 蓋靶場，tick 5113 完工。
  - 快速雙擊弓手，佇列 2 項，陸續共 3 名弓手，人口 7/10。
  - 之後偵查、攻擊、撤退、再攻擊；軍隊覆沒後投降（戰敗 08:47）；結束後的命令被拒絕，再開一局成功。
- `npm run test:production`（除錯模式、驗收圖）：
  - 兵營只有民兵。
  - 村民 1 採木，木材到 60 後蓋農田並耕作，食物到 60 後訓練民兵。
  - 混合選取時提示「1 名士兵不能採集或建造，未派出」；存讀與重播一致。
