# C：經濟建築代表資產

2026-09-25。新增 `apps/web/economic-building.ts`，模型頁可切換住宅、伐木場、採礦場、磨坊與農田。新模型是原創程序幾何，所有尺寸與外觀門檻為 design_default，不填入任何未確認的原作成本、效率或容量。

## 實作與限制

伐木場有分層木料、開放支柱與鋸架；採礦場有料斗、分類礦塊及鎬具；磨坊有石造支架、軸、十字葉片與糧袋；農田有田壟、間隔作物及邊界。各模型使用同一積木生成器與玩家色。

四種模型可切換五段施工、完整／受損／有限殘骸／還原，殘骸最多 12 塊。美術 footprint 為 3×3 世界單位，全部零件受其水平邊界約束。這不是模擬碰撞證據：目前只在模型頁替換代表位置，正式遊戲仍是住宅，新增建築尚無權威占地、入口通行、選取、派工、資源返還或生產功能。磨坊葉片靜止，沒有用假旋轉宣稱生產。

時代控制會改變部分支柱高度、材質與屋頂，但尚未達到全部四時代的完整細節矩陣；農田沒有四套時代外觀。城鎮中心、市場、鐵匠舖、軍事建築等仍未實作，不能稱完整村落完成。
