# 首次使用修正迴圈 014：電腦對手與第一場完整對局

2026-09-26，E 階段第五個里程碑。紅方改由電腦操控，第一次可以從首次進站一路打到勝負畫面，再開一局。

環境：Node 22.23.1、Darwin 27.0.0 arm64、Chromium 151.0.7922.34。seed 260925，State／snapshot v16。

## 新增的真實行為

- **電腦對手**（`packages/sim/ai.ts`）：
  - 一般進站預設對手為電腦；選單的「紅方」可切成「不行動（練習）」。除錯模式預設不行動。
  - 紅方和藍方一樣從 3 名村民開始，位置左右對稱。
  - 只讀紅方自己的視野；每道命令都走和玩家相同的驗證，不能看穿迷霧，也不能下非法命令。
  - 經濟：補村民到 12 名、快滿人口時蓋住宅、村民 3 名時先蓋兵營、天然食物用完時蓋農田，並依權重分配採集。
  - 升級與造兵：村民 9 名且兵營完工後升第二時代，之後訓練弓手，否則訓練民兵。
  - 戰鬥：
    - 隨時防守基地周圍 700 的範圍。
    - 開局 4 分鐘（tick 4800）內不追擊、不攻城；之後在家等滿 5 名士兵才一起出發。
    - 第一波前往自己城鎮中心的鏡像位置（地圖左右對稱，這是明寫的假設）；之後前往記得的敵方建築，沒有記憶就前往未探索的格子。
  - 重播與存讀一致：電腦的命令不寫入 log，由相同狀態重新推導；存檔與 Worker 恢復點都帶著對手設定。
- **農田**：
  - 選取村民後按 E：木材 60，占地 2×2。
  - 田可以走上去；完工後成為只有擁有者能耕作的 250 食物，耗盡後消失。
  - 選取農田時，面板顯示剩餘食物。
  - 補上這項的原因：每張地圖每方只有 150 食物可採（野果），雙方都無法升時代或養軍隊，對局不可能打完。
- **地圖左右對稱**：邊緣樹林只為西半部亂數產生，再鏡像到東半部。藍方半場和舊版完全相同。
- **建築格線改為 10 單位**：原本 50 單位格線加上占地偏移，讓紅方永遠放不到藍方位置的鏡像。
- **點建築看的是建築本身**：
  - 右鍵或左鍵點在建築的屋頂或牆上，指的是那棟建築，不再是它後方的地面。
  - 對地面或小地圖下的移動與集結點，若落在障礙物內，會走到最近的空地，只用玩家已知的資訊判斷。
  - 除錯用的座標移動維持原樣，讓 Worker 的拒絕規則仍可測試。
- **拒絕訊息**：一般模式不再顯示「tick N / request N / entity N：」前綴；對局結束後的指令會提示「對局已結束：按『再開一局』開始新遊戲」。
- **4× 不再自動暫停**：畫面每幀最多要求 `20×速度` 個 tick，Worker 單次上限提高到 80。

## 實際流程（`npm run test:match`，一般模式、對電腦、4×，只用滑鼠、鍵盤與小地圖）

1. **首次進站**：頂列顯示「對手：電腦」，遊戲自動開始。
2. **開局**：按「.」選村民 1，右鍵野果；再按「.」、Q，蓋住宅；再按「.」、W，蓋兵營（位置都在藍方半場）。
3. **兵營**：點選兵營，右鍵地面設集結點，陸續訓練 5 名近戰民兵，野果收入支付後續費用。
4. **集結**：tick 約 4150 時人口 8/10，框選集結點附近的 5 名民兵並設為編組 1。
5. **進軍**：小地圖右鍵紅方城鎮中心前方的空地。
6. **攻城**：依藍方看過的紅方建築（迷霧記憶，和小地圖顯示的資訊相同），依序右鍵攻擊城鎮中心、住宅、農田與兵營。
7. **結果**：06:21（tick 7630）出現「勝利：紅方已沒有任何單位與建築」。按「再開一局」後人口回到 3/5，對手仍是電腦。
8. 全程沒有自動暫停，也沒有 pageerror、console.error 或外部請求。

## 問題與修正

| 編號／嚴重度 | 重現與根因 | 修正與重測 |
|---|---|---|
| FU14-1／**嚴重**（模擬中斷） | 電腦在行走中村民的旁邊放住宅，模擬丟出「非法碰撞路徑」例外並停止。根因是放置規則判斷「有單位站在預定地上」時用嚴格重疊，但導航把外擴占地的邊緣也算阻擋。建築格線改成 10 之後，邊緣可能剛好落在單位的下一個節點上。 | 放置判斷改為包含邊界，和導航一致。新增回歸測試：拿掉修正時失敗，修正後通過。 |
| FU14-2／**嚴重**（無法完成對局） | 5 名民兵反覆攻擊一棟紅方住宅，卻始終打不到，對局在 40000 tick 時仍未結束。根因是對建築的射程從單位中心起算：當占地邊緣落在某些偏移（例如左緣 ≡ 25 mod 50、上緣 ≡ 5 mod 50）時，每一側 25–50 的範圍內都沒有可站的節點。 | 對建築的射程改從單位身體邊緣起算（射程＋半徑 25），和施工站位的規則一致。回歸測試用 (740, 1020) 的住宅：拿掉修正時失敗，修正後通過。 |
| FU14-3／**嚴重**（無法完成對局） | 每方只有 150 食物可採，雙方都無法升時代或養軍隊。 | 新增農田（見上）；電腦在天然食物用完時自動蓋田。 |
| FU14-4／高（公平） | 紅方角落的樹林比藍方多很多：tick 2000 時，紅方半場可放住宅的位置是 0 處，藍方是 157 處。 | 邊緣樹林改為鏡像；建築格線改為 10，讓鏡像位置合法。 |
| FU14-5／高（體驗） | 早期版本的電腦：唯一的民兵在開局 1 分鐘就殺光藍方村民。原因有三：兵營蓋在中線附近；剛出生、離家較遠的士兵被當成出征；單兵看到建築就開始攻城。 | 兵營必須整個離中線 100 以上；4 分鐘寬限期內，遠離家的士兵先回家；只有出征中的士兵會攻擊建築，在家的等滿 5 名才出發。單元測試斷言：寬限期內藍方沒有損失。 |
| FU14-6／高（體驗） | 電腦把住宅蓋在藍方城鎮中心旁邊（當時的後備規則允許在城鎮中心 900 內任何位置蓋）。 | 建築只能蓋在自己半場；住宅與農田最多越過中線 100。 |
| FU14-7／高（卡住） | 4× 速度下，頁面在 headless Chromium 顯示「模擬落後超過 1 秒，已暫停」。畫面較慢時，每幀最多 20 tick 追不上 80 tick/秒。 | 每幀上限改為 `20×速度`，Worker 單次上限 80。完整對局流程的自動暫停次數為 0。 |
| FU14-8／中（體驗） | 小地圖右鍵落在看不見的樹上時，移動被拒絕（「目標位於建築、資源……」）；右鍵點在建築屋頂時，會被當成後方的地面。 | 移動與集結點走到最近的空地；建築依立體範圍點選。 |
| FU14-9／中（文字） | 對局結束後的指令顯示「tick 7632 / request 1466 / entity 10：對局已結束……」這類技術字串。 | 一般模式去掉前綴；對局結束後的右鍵直接提示按「再開一局」。 |
| FU14-10／低（測試） | 第一版完整對局流程把藍方兵營放在跨中線的位置，被紅方的建築擋住。 | 流程改為只在藍方半場選位置。 |
