# C：建築凸點接合修正

2026-09-25。先前每個磚件獨立生成整排凸點，疊層屋頂或窄屋脊蓋住凸點時，邊緣仍可能穿出上層零件。現在由 building-studs.ts 依實際存在的建築零件生成凸點，scene.ts 將磚身與凸點分別實例化。

- 保留 stud pitch 0.5、radius 0.13、height 0.08 的 design_default 尺寸，不修改原作未知規則。
- 只生成完整落在磚面內的凸點；與其他零件有高度交集且圓柱截面相交時省略。
- 使用含接縫的外框作保守檢查；倒角與拱洞附近可能少畫凸點，不宣稱精確曲面布林運算。
- 施工、損壞、修復採當前零件集合重新計算；上層移除後可重新露出凸點。
- 範圍為十一種建築及正式沙盒住宅；樹木、資源、碰撞、存檔與權威模擬未修改。
