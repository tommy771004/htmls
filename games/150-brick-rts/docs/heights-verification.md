# C：高度、階梯與崖壁

2026-09-25。手工驗收圖新增一格高的高地、石地、不可通行崖格與三級土路階梯。正式沙盒仍使用平坦草甸；此增量沒有新增高地對局選項。

## 共用規則

Tile.height 是整數模擬高度，groundHeight 供 renderer 放置模型及單位腳底。地台以封閉柱體從相同底面填至指定高度，相鄰柱體精確接合。高地上的岩塊使用同一地格高度，不在模型內複製另一套高度。

陸地允許單一邊界差最多 25（自訂 0.25 格），水域不允許高度跳躍。超過限制的邊界以單位半徑擴張後檢查整條移動線段，因此長移動與對角線不能跳過中間崖壁，單位中心也不能站到會讓身體懸出崖邊的位置。階梯是離散高度，不是平滑斜坡；未宣稱完整坡道或攀爬動畫。

規則為 design_default。未加入原作高地戰鬥加成、視線遮擋或猜測的地形倍率。
