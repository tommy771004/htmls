# 首次使用修正迴圈 033：科技樹與對局設定

2026-10-02。接續 032（戰術技巧）。依使用者指示跳過「常見問題」，這一輪做 aoetw.com 的「科技樹」：逐格核對 13 個文明的科技樹，百科新增「科技樹」分類，對局中可以直接打開自己文明的科技樹並標出進度。另外依使用者在這一輪中途的要求，加上「前置開場」：開啟頁面先進入對局設定畫面，選好遊戲者、地圖與遊戲設定才開始，或從這裡載入存檔。核對方法、版面決定與各設定的數值見 `docs/aoe2-rules-research.md` 的「科技樹」「對局設定」兩節，State 與指令見 `docs/data-model.md` 的 v33 一節。

State／snapshot 為 v33（存檔格式 `brick-sandbox-33`）；v32 的存檔會被拒絕讀取（沒有遷移）。

## 新增的真實行為

### 科技樹核對

- 以連結路徑（不是中文名稱）把網站 13 個文明科技樹頁的每一格對應到本作的項目，再和本作每個文明的可用清單比對。
- 結果：只有蒙古的戟兵不同（科技樹頁可用，文明頁與戟兵頁都說沒有），維持 027 依兩頁對一頁的決定。之前「照科技樹頁」的決定（拜占庭的磚瓦技術、建築學與火砲塔，維京的精銳火砲戰船，土耳其的造船員等）都一致；13 個文明的特殊單位、精銳升級與特殊科技也一致。
- 修正：沒有火砲塔的 10 個文明（不列顛、塞爾特、法蘭克、哥德、維京、拜占庭、波斯、薩拉森、日本、蒙古）原本仍能在學院研究只用來解鎖火砲塔的「火砲塔技術」（食物 800、木材 400），現在一併不可用。

### 對局設定（`packages/sim/settings.ts`）

每項設定都存在 State 裡，存檔、讀檔與重播都會保留，讀檔時會檢查。

| 設定 | 選項 | 本作的做法 |
|---|---|---|
| 難易度 | 簡單、標準、困難、最難 | 只改電腦：思考間隔 40／20／20／10 tick、村民目標 8／12／14／16、每波兵力 8／5／4／4、最早出兵 9600／4800／3600／2400 tick；不給電腦資源加成。標準與原本的電腦完全相同。 |
| 資源 | 低、標準、中、高 | 開局存量：食物、木材、黃金、石頭各 100／100／0／0、200／200／100／100（原本的開局）、500／500／300／300、1000／1000／700／700，再加文明的開局加成。 |
| 人口 | 25、40、75、100 | 取代原本固定的 40；文明的人口加成照樣加上。 |
| 顯示地圖 | 標準（戰爭迷霧）、已探索、全部顯示 | 已探索：開局整張地圖都已探索，戰爭迷霧照舊；全部顯示：兩方（含電腦）隨時看得到整張地圖。 |
| 遊戲開始時代 | 黑暗、封建、城堡、帝王 | 兩方從那個時代開始，文明的時代加成與免費科技（例如維京的手推車）照樣生效，建築外觀跟著時代；不另外加資源。 |
| 勝利 | 標準、征服 | 征服時不啟動聖物與奇觀的倒數（聖物仍會產黃金）。 |
| 所有科技 | 勾選 | 每個文明都能用所有共通項目；特殊單位與特殊科技仍只屬於各自的文明，拓荒者仍沒有城堡。 |
| 記錄遊戲 | 勾選 | 對局中每一遊戲分鐘自動存到「自動存檔」。 |

- 遊戲者：你的名稱（顯示在對局資訊與嘲諷上）與文明（可隨機）；紅方是電腦或不行動、文明（可隨機）、電腦開局與難易度。隨機文明依種子決定。
- 地圖：五種地圖類型與種子（可以輸入，或按「換一張」）。
- 本作是一對一、地圖大小跟著地圖類型固定，所以沒有隊伍、位置、尺寸與更多遊戲者的設定，畫面上有一行說明。

## 頁面

- **前置開場**：開啟頁面先出現設定畫面，背後的對局停在 tick 0。左邊是遊戲者，右邊是依地圖類型與種子即時生成的地圖預覽（樹林、礦、聖物與兩方城鎮中心），下方是遊戲設定。「遊戲開始」以這些設定開新局；「載入遊戲」列出手動存檔與自動存檔（附文明、地圖與時間）；「科技樹」打開百科的科技樹並預選你挑的文明。上次的設定會記在瀏覽器裡。
- 對局中選單的「新遊戲設定」重開設定畫面，「取消」或 Esc 回到原本的對局；選單的快速重開沿用這一局的設定。設定畫面開著時，遊戲快捷鍵不作用。
- 手機寬度是單欄，地圖預覽在最上面，沒有水平捲動。
- **科技樹**（百科第八個分類）：照網站的 14 塊建築（軍營、射箭場、馬廄、攻城器製造所、城堡、城鎮中心、磨坊、伐木場、採礦營地、碼頭、兵工廠、市集、修道院、學院），在城鎮中心後面加一塊「村民建造」（黑暗：民居、木牆、木門、哨站；封建：箭塔、石牆、城門；帝王：火砲塔、世界奇觀）。由上往下是時代，同一欄是升級的先後；只在本作真的有前後關係的地方畫連線。網站分成三格的弩砲戰船，本作是同一項研究（火戰船、爆破船兩格標「同一項研究」）；火砲塔拆成學院的火砲塔技術與村民建造的火砲塔；火槍兵、火砲與火砲戰船標「需化學」。
- 可以切換 13 個文明與拓荒者；文明沒有的項目變暗並標「沒有」，本作沒有的網站項目（鷹斥候、攻城塔、卡拉維爾帆船等）可以顯示成淡色。上方列出文明加成與團隊加成；點任何項目打開它的百科頁。
- **對局中**：F4 或選單「科技樹」打開自己文明的科技樹，每一項標出已完成、擁有 n、進行中、現在可做、資源不足、條件未到或此文明沒有；看別的文明時不標。標記是打開當下的狀態。
