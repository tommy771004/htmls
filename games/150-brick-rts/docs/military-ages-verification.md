## 啟動與界線

在 games/150-brick-rts 執行 `npm run build`，從專案根目錄啟動靜態 HTTP 伺服器，開啟 `/web/150-brick-rts-models.html`，選擇兵營／靶場／馬廄與時代 1–4；可切換施工、生命狀態、轉向與縮放。

這些控制只改模型檢視狀態；正式沙盒仍是第二時代住宅。沒有加入造兵、集合點、研究、建築放置或入口導航。C 仍 in_progress；七類經濟／城鎮建築的完整時代輪廓、元件庫、入口與作業區仍是缺口。這輪沒有新可玩里程碑，因此不是 prompt 19 首次使用驗收，也未執行完整對局或目標硬體測試。
