# Zork · 帝國的餘燼

作品 136，分類「遊戲敘事」。入口是 [`../../web/136-zork.html`](../../web/136-zork.html)。程式化 Three.js 第一人稱動作冒險；模型、植物、材質、光束與聲音均在執行時產生。唯一執行依賴是站內的 Three.js 0.186.0，沒有模型、照片、字型或音效下載。

## 執行與建置

從專案根目錄以 HTTP 開啟，例如 `python3 -m http.server 8135`，瀏覽 `http://127.0.0.1:8135/web/136-zork.html`。需要 WebGL，不能直接用 `file://` 載入 ES module。

```sh
node games/136-zork/build.mjs
node --test games/136-zork/engine.test.mjs
node games/136-zork/walkthrough.mjs
# 需可用的 Playwright 與 Chrome。可用 PLAYWRIGHT_MODULE 指定安裝位置。
node games/136-zork/browser-walkthrough.mjs
node games/136-zork/browser-checks.mjs
```

瀏覽器驗證預設使用上面的 8135 網址；`ZORK_URL` 可覆寫，需保留 `?test=1`。測試在獨立瀏覽器 context 中執行，不會清除使用者瀏覽器的存檔。`?test=1` 僅增加唯讀場景快照，沒有傳送、拾取或改寫遊戲狀態的測試 API。

- `world.json`：原作房間、出口条件、道具位置、英文描述、發現與存放分數。
- `engine.mjs`：可獨立測試的規則、背包、謎題、保存及安全點。
- `view.mjs`：程序場景、渲染、輸入、碰撞、敵人 AI 與介面。
- `shell.html`、`style.css`：繁體中文介面與開場版面。
- `build.mjs`：將以上內容內嵌至交付 HTML；改原始碼後需重建。
- `walkthrough.mjs`：依當下可通行出口搜尋路徑，完成全部 285 分；輸出 `walkthrough.json`。
- `browser-walkthrough.mjs`：依同一份路線以實際鍵鼠、滑鼠鎖定、物件互動與文字輸入完成主線，逐步確認出口與拾取結果，最後驗證存檔重讀。
- `browser-checks.mjs`：以獨立存檔 fixture 驗證戰鬥、失去目標、黑暗、死亡、外牆與手機操作；這些定點檢查與完整主線實走分開。

## 版本與來源

選用 **1977 年 6 月 14 日的 285 分版本重建**：80 房間、11 件寶物。1977 年的 Zork 持續演變，並不是後來商業發行的 Zork I。本作不混入後來的 Dungeon Master 終局、電池謎題或不同的獨眼巨人魔法詞。

原作：Tim Anderson、Marc Blank、Bruce Daniels、Dave Lebling。

- [MIT DDC：1977 年 7 月原始 MDL 典藏](https://github.com/MITDDC/zork-1977-07)。MIT 持有權利的部分依 MIT-0 釋出；原授權全文見 [SOURCE-LICENSE.txt](SOURCE-LICENSE.txt)。
- [Henrik Åsman 的 Zork 285 重建](https://github.com/heasm66/mdlzork/tree/master/zork_285)：核對 `aact.zil` 的房間、物件和互動函式、`rooms.zil` 的出口類型、`defs.zil` 的初始化與容器檢查。`world.json` 保留原始房間 ID 以便逐項比對。

保留的地圖是原始有向圖：單向通路、迷宮、會轉向的圓室都不能用普通平面走廊解釋。3D 空間因此在出口互動時切換房間，各房間是可自由行走的獨立區塊；切換時釋放該區塊的幾何、材質與貼圖。只常駐目前房間與少量共用基本幾何。

## 改編與簡化的理由

1. **文字解析器改為靠近、瞄準後按 E 的動作選單。** 減少即時 3D 中猜動詞的操作負擔；物品條件與出口条件仍由規則引擎檢查。魔法詞、回音和謎底保留文字輸入。
2. **即時戰鬥取代回合戰鬥。** 刀、體力、格擋、敵人蓄力攻擊；巡邏→察覺→追擊→搜尋→巡邏。巨魔擲刀與獨眼巨人謎題解法保留；巨人不能直接砍死。
3. **盜賊活動縮為三個房間。** 限定在旋轉圓室、Twisting Passage、Maze 7，讓每房的遭遇可讀；偷走的寶物仍能追回，抵達 Treasure Room 時沿用早期版盜賊死亡事件。
4. **死亡恢復最近安全點的完整快照。** 位置、背包、道具位置、解謎旗標一同回復，避免必需品永久散失導致無解。安全點為白屋西側、廚房、起居室、神殿、祭壇及水壩大廳。
5. **黑暗風險改為可預警倒數。** 無光移動超過六秒會死亡；黑暗中走出口立即觸發墜落。燈外没有補光，但選單保持可讀。
6. **淹水以 45 秒代替回合。** 按藍鈕後仍可用補漏膠封住裂縫；暫停／開選單時不計時。
7. **禁止毀壞關鍵物品的無解操作。** 火炬不會永久燒掉蠟燭，寶物不能隨意摧毀；風洞仍可能吹熄蠟燭。原作的永久失敗趣味讓位給可持續遊玩的安全點設計。
8. **用程序光束近似體積光。** 森林有多層樹冠、霧、草、蕨與加法混合光束；並非昂貴的體積散射求積。低階裝置降低植物數量與像素比。

以上差異也可在遊戲開場「關於此改編 & 原作差異」與 J 手記查看。所有改編都明示為非官方；沒有宣稱是全部歷史版本的完整重製。

## 操作與存檔

WASD 移動、Shift 快跑、滑鼠／方向鍵環顧、E 互動、左鍵或 Space 揮刀、右鍵或 R 格擋、Q 擲刀、L 提燈、I 背包、J 手記、Esc 暫停。手機提供方向鍵、拖曳環顧及操作按鈕。

存檔鍵為 `zork-1977-136-v1`，僅在目前瀏覽器與網域保存。每次互動／切換房間、定時、背景化和離頁嘗試保存。儲存遭限制時 HUD 會提示。重新開始必須經第二次點選確認。
