# 260 — 霓虹夜城 // NEON NIGHT CITY 技術規格書 (SPEC)

## 1. 設計目標與視覺基準
- **參考靈感**：`@Ainthropos` 賽博龐克開放夜城概念影片——強調深邃雨夜空氣感、高反差青/洋紅/琥珀霓虹自發光、濕滑柏油路面積水反射、細膩的車輛與骨骼動畫人群，以及「開車巡航 ↔ 下車走入室內夜店與酒吧」的無縫探索體驗。
- **零外部依賴**：單一檔案 `web/260-neon-nightcity.html` 內含完整 Three.js 引擎、Blender `.glb` 二進位資產（gzip+base64）、Canvas 程序貼圖與 WebAudio 合成器，離線開啟即可完整執行。
- **效能目標**：透過 `InstancedMesh`（大樓窗格、人行道）、多材質靜態與蒙皮網格自動合併（`bakeSkinnedGlow` / `bakeStaticMultiMaterial`）及距離裁剪骨骼更新，維持全場景 Draw Calls < 330、穩定 60fps。

## 2. 城市座標與可進入場館配置
- **世界範圍**：`[-185, 185] × [-185, 185]` 公尺，主幹道座標 `ROADS = [-150, -90, -30, 30, 90, 150]`（路寬 16m），街區中心 `BLOCKS = [-120, -60, 0, 60, 120]`（42m × 42m）。
- **三座可無縫進入的一樓室內場館**：
  1. **PULSE // 脈衝夜店**（中心 `(0, 0)`，北向大門 `(0, -16)` 寬 7m）：內設 8×8 音訊反應 LED 舞池、8 道掃描雷射光束、DJ 舞台、4 座重低音音箱塔、4 組 VIP 卡座，以及 15 名骨骼動畫熱舞角色（14 名舞客 + 1 名 DJ）。
  2. **AFTERGLOW // 餘燼酒吧**（中心 `(-60, 0)`，北向大門 `(-60, -15)` 寬 7m）：內設琥珀發光吧台、三層霓虹酒瓶架、高腳椅、復古街機框體、全息點唱機，以及 1 名調酒師（`bartend` 動作）與 5 名酒客。按 `E` 可點賽博調酒。
  3. **CHROME WORKS // 電馭改裝廠**（中心 `(60, 0)`，北向車道門 `(60, -15)` 寬 9m）：可供跑車直接駛入或步行進入，內設全息掃描環與投影機，按 `E` 或 `C` 可即時切換 5 款車底霓虹與塗裝主題。

| 按鍵 | 駕駛模式 (DRIVING) | 步行模式 (ON FOOT) |

| `V` | — | 將座駕召喚至面前並立即登車 |
