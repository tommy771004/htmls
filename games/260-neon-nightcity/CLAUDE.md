# 霓虹夜城（260）

- 原始碼在 `games/260-neon-nightcity/`（Three.js 0.186.0 + esbuild），有自己的 `package.json`（`node_modules` 連到 201 的）；`npm run build` 把 `src/parts/*.js` 依檔名順序串成**同一個模組**（共用頂層變數，後面的檔案直接用前面宣告的東西）再打包成單檔 `web/260-neon-nightcity.html`，改了 `src/` 要重新 build 並把產出一起 commit。`npm test` 是兩種尺寸的無頭 Chrome 驗收（走完整段任務），`npm run thumb` 產生縮圖。
- 不規則城市（`plans/260-irregular-city.md`）：生成全部在方格的「邏輯座標」跑，照 GTA V 地圖重排成十五片（`tools/check-zones.mjs` 產生 `04-layout.js`，不要手改），`05-zones.js` 的 `ZONES` 每片是剛體變換加片內的平滑彎曲（`warpJ`／`unwarp`，`?warp=0` 關掉），所以片裡的街道是彎的；網格在 `cityAdd` 逐頂點烘焙成世界座標（地面帶 `aL`），會動的東西掛 `localZone`、實例與模型用 `frameM4`，碰撞盒切段（`boxSplitW`，≤ 24 m）帶自己的仿射框 `f`（`frameA`，含斜切，盒在世界裡是平行四邊形；圓對盒走 `quadPush`），有實體建築的街區的盒在模型下載後由 `27-bldfoot.js` 照模型在人的高度的外形重算（`blk` 標記），開場 `cityWorld()` 把碰撞、光源與錨點換成世界座標；玩家、車流、地圖都是世界座標。外緣多邊形 `CITY_POLY`（臨水段 `CITY_SHORE`，擋牆與梯子是 `10-city.js` 的 `SHORE`，外面的山是 `hillH`）、`06-roads.js` 的連接道路、快速道路（`FWY`，`kind: 'f'`，高架跨過連接道路，只在銜接點是沒有片的 `free` 路口；兩條快速道路在高架上分合流（共線段 `joins`），單向匝道 `FWY_RAMPS`（`oneway`、`ramp`、窄的 `hw`／`dw`）落地在連接道路上；高架的路口帶 `y` 與 `nosig`；橋面高度 `fwyH`，地面高度要先問 `deckAt`（疊在一起的橋面看 `deckOn`），生成載具用 `spawnY`，橋上的碰撞盒帶 `ly`；`rnField` 與 GPS 只算單向邊的順向）與縫的步道是世界座標；斜穿片的大道（`DIAG`，`kind: 'd'`）穿過的街區是廣場（`b.plaza`，地塊標 `ghost` 照原寬度抽亂數、不蓋樓），改 `DIAG` 的起點要避開特殊地塊、實體建築、安全屋的門。跳台與斷橋不能飛越片之間的縫（兩片的路對不上）。新程式碰到位置先想清楚是邏輯還是世界（`toW`／`toL`、`spotW`，世界座標的圓柱與光源標 `w: 1`、實例標 `zn: null`），改完要跑 `NC_QUERY='?zrot=25' npm test` 與 `test:glb`（整座城再轉 25°，單位變換驗不出漏掉的換算）；驗收腳本用 `__nc.tpL`／`W`／`L`／`Ws`，不寫死世界座標。存檔第 5 版起位置是世界座標。
- parts 依檔名順序串成同一個模組：頂層程式只能用排在前面的 part 宣告的東西（後面 part 的 `const` 在 TDZ，或在前面呼叫時是 `undefined`）；函式裡可以。例如 69 開頭的檔案頂層不能用 `post`、`camState`、`keys`、`bigmap`、`ctxHooks`、`W`。
- 內嵌 `blender/out/` 的 `interior_props`、`street_props`、`people`、`traffic` 四個 GLB；車流（計程車、警車、房車、貨車共 16 型）是 `tools/traffic.mjs`（`npm run traffic`）從 `assets/260` 實車與 DanielZhabotinsky 的虛構廠牌車烘成的近遠兩級模型；後者原檔在 gitignore 的 `.cache/cars/`，先由 `cars.mjs` 裡標 `traffic: true` 的項目（`TRAFFIC=1 node tools/cars.mjs`）整理到 `.cache/traffic/`，程式建模的車只在 `traffic.glb` 載入失敗時頂替。人物是 Quaternius CC0 底模（`blender/people.py` → `npm run people` 壓縮），`40-people.js` 每人一個 SkinnedMesh，骨架不在場景圖裡、只在畫面內才擺姿勢；動畫庫沒有的動作在播放後用 `aim()` 覆寫骨頭方向，`node tools/pose-gallery.mjs` 截圖檢查。
- 實體建築與道具：`npm run props`（`tools/props.mjs`）把 `.cache/props/` 的 Sketchfab 原檔（DanielZhabotinsky 四套建築組、拉麵攤、點唱機、街機、升降機、工具推車）處理成 `assets/260/props/*.glb` 與 `props.json`（有 commit）；建築組的窗戶遮罩改寫成「R＝玻璃、G＝窗戶編號」的無損貼圖，`26-glb.js` 的 `USE_WINMAP` 依編號點亮每扇窗。`10-city.js` 挑出換成模型的連續地塊（`bldPlace`、`L.glb`，不建程式立面），`27-props.js` 下載後依材質合併擺放，失敗用 `lotFallback()` 補回立面；只在 http(s) 下載，開始畫面會等建築與拉麵攤，室內道具走進酒吧／車庫才下載（`propSwap`／`propWake`）；下載後的處理分幀做（`warmClock`／`warmSlice`，一幀共用 6 ms 預算），放進場景前用 `glbWarm` 先編著色器、逐張上傳貼圖、上傳附近建築的頂點（`?warm=0` 關掉比較；`?perf=1` 與 `__nc.perf.route()` 看卡頓，見 `96-perf.js`），新增大量載入的工作也照這樣切片。
- 車行與車庫：車型目錄 `CARS` 與 `carKit()` 在 `25-cars.js`（程式建模的車只取經典車款的剪影比例，車名虛構、不放廠牌字樣或標誌；現在只用於車流與替身）；門面在 `55-motor-front.js`（要在 60 把 `signLights` 複製成 `outLights`、合併 `signMesh` 之前）；展示廳是 `64-showroom.js` 的三層樓美式車行（明亮配色，曝光與高光肩部在 `ENV.show.post`；中庭挑空、兩側展廊每層每側 8 格 `SHOW_FLOORS`，每層一套碰撞與燈 `show.lv[k]`，換層一律走 `showLevel(k)`，電梯 `showLift`；新車登錄到 `SHOW_FLOORS`，沒排到的會自動補空格），車庫、買車／試駕／出庫／賣車與甩尾打賞在 `65-motors.js`。室內場館都登錄在 60 的 `VENUES`，互動提示可以掛進 `ctxHooks`（比門口、櫃台等固定提示先問；要排在它們之後的掛 `ctxLate`，如招計程車）；玩家座駕只有一個物件（沿用 `kestrel` 變數），換車一律走 `applyCar(v, id, paint)`；搶來或打壞的車流車是 `68-gta.js` 的 `detachCar()` 建的臨時載具（`kind: 'jack'`，不進存檔、不走 applyCar），GTA 式擴充的範圍與未做的階段見同資料夾 README；存檔在 `localStorage` 的 `nc260.motors`。
- 實車模型：車行與車庫只賣 47 台 Sketchfab 的同人實車模型（日系、BMW、Porsche、Ferrari、Lamborghini 等與 4 台機車；CC BY 與 CC BY-NC-SA，保留原廠名稱與彩繪，看車對話標作者與授權，來源見 `assets/260/CREDITS.md`），開場座駕是 `STARTER`（AE86）、路邊機車是 `STREET_BIKE`（ZX-6R）；程式建模的車只留給車流與沒下載到模型時的替身。`npm run cars`（`tools/cars.mjs`，借 197 的 gltf-transform、meshoptimizer、sharp）把 gitignore 的 `.cache/cars/` 原檔處理成 `assets/260/<id>.glb`（約 64 MB，有 commit）與 `cars.json`（打包進頁面）；目錄與貼圖版 uber 材質在 `26-glb.js`。頁面只在 http(s) 下、走進車行／車庫、走近車行門口或換成那台車時才下載（座駕與路邊機車開場就下載），以檔案開啟用 `proxy` 程式建模替身。`npm run test:glb` 以本機 HTTP 驗收實車，`node tools/car-view.mjs <id>` 四視角檢查方向與輪子拆分。輪子節點是 `wheel_XX`，不隨輪轉的卡鉗與機車前叉、龍頭另拆成 `wheel_XX_fix`（頁面掛在轉向節點 `piv`，機車依 `cars.json` 的 `rake` 繞斜軸轉）；重跑 `cars.mjs` 會保留 manifest 裡新規格沒有的欄位（如 `db`）。車窗射擊的座椅高度與前後位置由 `node tools/seats.mjs` 量車頂輪廓寫進 `cars.json` 的 `db`。
- 音效：`80-audio.js` 的音樂與雨、城市低頻是即時合成；槍聲、爆炸、撞擊、腳步、車門、引擎、甩尾、警笛、直升機等是 Freesound 的 CC0 錄音，`node tools/sfx.mjs` 依檔案裡的 `ONE`／`LOOP` 清單（Freesound id、起點、長度）檢查授權並下載到 `assets/260/sfx/`（有 commit，寫出 `sfx.json` 與 `CREDITS.md`），頁面只在 http(s) 下載、解碼後才裁切與淡出，以檔案開啟或還沒解碼完退回合成音。每個音都要有結束點：單發音的長度寫在清單裡（不留長尾），循環音（`rloop`／`lset`）歸零 0.4 s 後停掉來源，新的持續音也要照這個做；`impact(k, kind)` 的 `body`／`ped` 是人的碰撞。不要用原作（GTA V）的音效。`__nc.sfx.rec`、`stats()` 看載入狀態。
- Esc 暫停與設定選單在 `95-menu.js`（仿 GTA V：分頁、類別、設定列；開著時 `loop` 不跑 `step`）；設定值 `SET` 在 `01-settings.js`（排在最前面，任何 part 開場就能讀，存 `localStorage` 的 `nc260.settings`，不進遊戲存檔）。新增畫質或操作相關的常數時優先接到 `SET`（畫質的預設值跟著 `00-core.js` 的顯示卡分級 `GPU_TIERS`／`GT()`：soft／low／mid／high／ultra（ultra 不會自動選到），`?gpu=` 覆寫，驗收工具固定 `gpu=high`；設定檔只存改過的項目）；按鍵綁定是捕獲階段轉送 code，新按鍵要加進 `KEY_ACTS` 才能重綁。
- three r186 的 `new Color(hex)` 已經是線性值，不要再 `convertSRGBToLinear()`（重複轉換會讓整個畫面變暗變髒）。招牌字圖集是 2048×2048，新增招牌格子前先算會不會超出（超出會 `console.warn`）。各檔分工、`window.__nc` 測試 API 見同資料夾的 `README.md`，城市尺寸、場館、任務與渲染流程見 `SPEC.md`，限制與未做的項目見 `HANDOFF.md`。
