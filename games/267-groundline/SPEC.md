# Groundline · 機場停機坪即時調度 — 規格書（#267）

## 1. 3D 資產（Blender Python → glTF/GLB）
- 腳本：`blender/build_apron.py`，匯出 `blender/out/groundline.glb` 並以 gzip+base64 內嵌於 `web/267-groundline.html`。
- 包含物件：
  - `Terminal`：5 跨弧形玻璃屋頂航廈、候機室暖光窗帶與西側航管塔台。
  - `Jetbridge_1..5`、`JetbridgeRotunda`、`JetbridgeArm`、`JetbridgeUnit`：5 座登機門空橋，支援隨客機到站／推出動態旋轉對接。
  - `Aircraft_A320`、`Aircraft_B738`、`Aircraft_A321`、`Aircraft_E190`：4 家航空公司柔和塗裝客機。
  - `FuelTruck`（加油車）、`BaggageTug`（雙拖斗行李拖車）、`CateringTruck`（剪刀式升降餐車）、`CleaningVan`（清潔車）、`PushbackTug`（後推車）。
  - `FuelTankFarm`：東側 3 座圓筒航空油槽、防溢圍堰與灌裝棚。

## 2. Three.js 等角 3D 場景
- 採用低視角等角透視相機（FOV 32°）搭配 `OrbitControls` 縮放與旋轉，並提供「全覽 / 航廈 / 油槽」快速視角切換與 glTF 模型下載。
- 跑道（`27R / 09L`）、滑行道（`Taxiway A`）、機坪引導線（Lead-in Lines）、紅白機坪安全框與服務車道皆繪製清晰的黃色與白色標線。
- 客機依時刻表由跑道降落、滑行進入 G1–G5 登機門停靠，完成過站後由後推車推出至滑行道離場；地勤車輛沿機坪車道自動前往各登機門服務，油量低於門檻時自動返回油槽區補油。

## 3. 過站模擬與策略調度
- 每架飛機過站流程固定為 6 步驟：**到站（4m）→ 下客（7m）→ 清潔（8m）→ 加油（8m）→ 登機（9m）→ 推出（4m）**，每步驟具獨立時間與延誤機率。
- 玩家策略操作：
  - **調整優先順序**：切換「普通 / ▲ 優先 / ★ 緊急」，高優先航班可加速作業並優先獲得閒置地勤車。
  - **手動指派地勤車**：從左下時間軸步驟按鈕或右下「車輛」分頁直接指派加油車、行李拖車、餐車／清潔車前往支援，縮減延誤時間。
  - **改派空閒登機門**：當後續航班因前班延誤而在滑行道等待時，可一鍵改派至空閒登機門以解除連鎖延誤。

## 4. UI 佈局
- **頂部指標卡**：準點率（On-Time Rate）、平均過站分鐘（Turnaround）、使用中登機門（Active Gates 燈號）、處理行李數（Bags Handled）。
- **右上模擬時鐘與倍速**：顯示即時模擬時間（`HH:MM`）與 `⏸ / 1× / 2× / 4× / 8×` 倍速控制。
- **左下選中航班過站時間軸**：顯示航班資訊、優先級切換、連鎖延誤預警橫幅，以及 6 步驟進度條、風險百分比與派車按鈕。
- **右下分頁清單與進度條**：「航班 / 車輛 / 登機門」三分頁切換，即時顯示各航班進度條、車隊派遣狀態與油量、以及各登機門後續排班連鎖影響。
