# 仙境人生 · RO LIFE（作品 282）

致敬《仙境傳說 Ragnarok Online》的非官方同人 2.5D 彈幕生存動作 RPG。作品集第 282 件，網址 <https://htmls-ruddy.vercel.app/web/282-ro-life.html>。

## 執行與打包

```bash
npm run build      # 打包單檔 ../../web/282-ro-life.html（執行時從 ../assets/282/ 載入素材）
npm run build:dev  # 開發模式打包（不壓縮）
```

打包後的單檔 HTML 需透過本地或線上 HTTP 伺服器開啟（例如在作品集根目錄執行 `npx serve -l 8127` 後開啟 `http://127.0.0.1:8127/web/282-ro-life.html`）。

## 遊戲特色

- **14 種職業與三系天賦樹（382 個天賦節點、238 招技能）**：
  - **初階 6 職**：劍士（Swordsman）、法師（Mage）、弓箭手（Archer）、服事（Acolyte）、盜賊（Thief）、商人（Merchant）。
  - **擴充特殊 3 職**：跆拳少年／少女（Taekwon）、忍者（Ninja）、神槍手（Gunslinger）。
  - **二轉進階 5 職**（Base Lv 40 & Job Lv 35 解鎖）：騎士（Knight）、巫師（Wizard）、獵人（Hunter）、祭司（Priest）、刺客（Assassin）。
- **2.5D 普隆德拉廣場大廳與 13 座經典關卡＋無盡之塔**：
  - 普隆德拉噴水池廣場可自由走動，與遠征隊長、鐵匠霍爾格亨、礦石商人、普隆德拉圖書館員（內建完整 Wiki 圖鑑）、編年史學者、寵物飼育員、造型師與二轉專精大師互動。
  - 13 座關卡涵蓋普隆德拉南門（`prt_fild08`）、下水道（`prt_sewb1`）、妙勒尼山脈（`mjolnir_09`）、蘇克拉特沙漠（`moc_fild12`）、斐楊森林與洞穴、幽靈船、金字塔、獸人村落、吉芬塔與古城克雷斯特漢姆（`gl_chyard`）。
- **179 種魔物與 25 隻 MVP／Mini Boss 多階段機制的戰鬥**：
  - 黃金蟲、蜂后、虎王、皮里恩、海盜之王、月夜貓、瑪雅、俄塞里斯、死靈、德古拉、巴風特、黑暗之王等經典 MVP 各有專屬地面預警圈（Telegraph Circle）、狂暴階段與主題 BGM。
- **193 件裝備、87 張經典卡片與 18 隻可進化寵物**：
  - 支援裝備精煉（+1～+10）、隨機詞綴、卡片插槽鑲嵌與寵物親密度進化。
- **內建繁體中文／英文／西班牙文三語切換**與 **F2 視覺化除錯面板（`window.RODebug` / `window.__ro`）**。

## 操作說明

| 按鍵／操作 | 功能 |
|---|---|
| `W` `A` `S` `D` 或 `方向鍵`／滑鼠點擊／觸控搖桿 | 普隆德拉廣場與戰鬥中八向移動 |
| `Space`／點擊 NPC | 與普隆德拉廣場 NPC 對話 |
| `1` – `6` | 戰鬥中手動觸發或檢視技能列 |
| `C`／`X` | 開啟角色面板（裝備／背包／卡片／寵物／六維配點／天賦樹）／切換角色 |
| `Esc` | 暫停選單／設定（音量、畫質、語言切換） |
| `F2` 或點擊右下角 `🛠 Debug (F2)` | 開關內建視覺化除錯面板（無敵、秒殺、召喚 MVP、滿等、全卡全裝） |
