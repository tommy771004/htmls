# 野靈旅記 · WILDLING TRAIL（作品 131）

原創像素怪獸收集 RPG。2D 俯視角、固定格子移動、單對單回合制戰鬥。從新遊戲一路玩到擊敗首領、看到通關畫面，之後可以繼續自由探索。需求規格見 [`docs/pokemon.md`](../../docs/pokemon.md)。

- 線上遊玩：<https://htmls-ruddy.vercel.app/web/131-wildling-trail.html>
- 技術：TypeScript 5.9、Vite 7、Phaser 3.90；測試用 Vitest 3 與 Playwright。
- 交付物：`npm run build` 把所有程式、樣式與素材內嵌成單一檔案 `web/131-wildling-trail.html`（約 1.35 MB）。這個檔案不載入任何外部資源，所以網站本身仍然不需要 build step，Vercel 直接提供這個靜態檔。

## 指令

需要 Node.js 22 以上。以下都在 `games/131-wildling-trail/` 目錄下執行。

```bash
npm ci                    # 安裝
npm run dev               # 開發伺服器 http://localhost:5173（可加 ?seed=123 固定亂數）
npm run typecheck         # tsc --noEmit
npm test                  # Vitest：規則、內容驗證、存檔、完整流程
npm run validate          # 只跑內容驗證
npm run build             # vite build，再內嵌成 ../../web/131-wildling-trail.html
npm run test:e2e          # Playwright，對建置好的單檔操作（先 build）
npx vite-node scripts/preview-art.mjs   # 把全部像素素材輸出成預覽圖
```

改了 `src/` 之後要重新 `npm run build`，並把更新後的 `web/131-wildling-trail.html` 一起 commit。

## 操作

| 動作 | 鍵盤 | 手機 |
| --- | --- | --- |
| 移動 / 移動游標 | 方向鍵、WASD（按住可連續走） | 十字鍵 |
| 確認、互動、翻下一句 | Enter、Z、空白鍵 | A |
| 取消、返回 | Escape、X、Backspace | B |
| 開關選單（探索中） | Escape、X | 選單 |

面板裡的項目也可以直接點選。商店數量用上下 ±1、左右 ±10。

戰鬥時下方的旅行手帳會收起，訊息、指令與招式改放在畫面框內的戰鬥框。左邊是訊息，右邊是 2×2 的指令。選招式時，左邊是 2×2 的招式，右邊顯示選中招式的次數、屬性、威力與命中，十字鍵在格子裡移動。背包、隊伍與學招的清單會蓋滿整個畫面框，框的大小不變。手帳讓出的高度都給畫面框使用，所以手機上的戰鬥畫面不會被壓小。

## 流程與引導

畫面下方的「旅行手帳」會一直顯示目前目標，地圖上該去的人物頭上有「!」。

1. 新遊戲 → 4 句操作教學 → 和禾老師說話，三選一初始夥伴（燭尾／泡鰭／苔團），同時拿到 5 個晶籠。
2. 往北到風草道，走進高草叢遇到野生怪獸。
3. 捕捉一隻。在捕捉成功之前，巡林員不讓你進森林。
4. 回芽口村找蘇護士治療，也可以在阿良的店補貨。治療之前巡林員同樣不放行。
5. 穿過霧苔林，打贏守林人・朔，取得挑戰資格。沒有資格時，石冠挑戰場的看門人會擋住並說明原因。
6. 擊敗場主・嵐 → 通關畫面 → 回到地圖自由探索。之後可以繼續捕捉與培育；訓練家可以再戰，但獎金只在第一次勝利時發放。

## 內容

- 地圖（格子 16×16 px）：芽口村、風草道、霧苔林、石冠挑戰場。
- 怪獸 8 種：燭尾、泡鰭、苔團、芽蟲、繭葉、翠翅蛾、霧蝸、燼鴉。
- 進化：芽蟲 Lv6 進化成繭葉，Lv9 再進化成翠翅蛾。
- 招式 12 個：火花、灼息、熱身、爆燃、水泡、疾流、眠泡、潮湧、藤鞭、孢子粉、吸取、葉旋。另有招式全部用完時才會出現的「拚命」。
- 屬性 3 種：焰、潮、苔。
- 道具：晶籠、精晶籠、莓果露、濃莓果露、萬用草。
- 介面：隊伍、收納石、背包、圖鑑（見過／捕捉）、旅行筆記、商店、存檔、設定（音效、減少動態、文字速度）。
- 美術全部以程式繪製成像素圖（`src/art/`），共 188 張，沒有外部圖檔。音效由 WebAudio 即時合成。

## 自訂遊戲規則

這些是本遊戲自己的簡化規則，並非任何既有遊戲的公式。

**能力值**
- HP = ⌊2·基礎·Lv/100⌋ + Lv + 10。
- 攻擊、防禦、速度 = ⌊2·基礎·Lv/100⌋ + 5。
- 等級上限 30。

**經驗值**
- 到達 Lv 所需的累積經驗 = ⌊0.8·Lv³⌋。
- 擊倒一隻敵方怪獸時，每個曾對牠出場、且戰鬥結束時沒有倒下的我方怪獸，都拿到完整的 ⌊經驗基數·敵方Lv/4⌋。訓練家戰再 ×1.5。
- 升級時 HP 依比例補回。

**傷害**
- 基本值 = ⌊⌊⌊2·Lv/5+2⌋·威力·攻/防⌋/50⌋ + 2。
- 再乘上同屬性加成 1.25、相剋倍率與亂數 0.85–1.00，最低 1。

**相剋**
- 焰 → 苔、苔 → 潮、潮 → 焰 為 ×2。
- 反方向為 ×0.5，其他組合 ×1。

**能力階段**
- 範圍 ±4，倍率 +n 為 (2+n)/2，−n 為 2/(2+n)。

**命中**
- 擲 1–100，大於命中率就沒打中。
- 對自己使用的招式與「拚命」必中。

**出手順序**
- 逃跑、交換、道具的優先度依序為 8、7、6。
- 招式依自身優先度（疾流 +1）。
- 同優先度時比較速度（含階段），再相同則各 50%。

**狀態**
- 灼傷：回合末扣最大 HP 的 1/12。
- 中毒：回合末扣最大 HP 的 1/8。
- 睡眠：1–3 回合無法行動。
- 焰屬性不會灼傷，苔屬性不會中毒。
- 萬用草可以治好以上狀態。

**拚命**
- 只有在所有招式次數都用完時才能用。
- 威力 40、無屬性、必中，自己承受造成傷害 1/4 的反作用。
- 敵方招式用完時也會自動使用。

**逃跑**
- 機率 = 50% + (我方速度 − 對手速度)·2% + 已失敗次數·15%，限制在 20%–100%。
- 訓練家戰不能逃。

**捕捉**
- 機率 = 物種捕捉率 × 道具倍率（晶籠 1、精晶籠 1.6）× 狀態倍率（灼傷、中毒 1.5，睡眠 2）× (3·最大HP − 2·目前HP)/(3·最大HP)，限制在 5%–95%。
- 每次嘗試都會消耗一個籠子和一次行動。
- 成功就立刻結束戰鬥。
- 只能捕捉野生怪獸。

**敵方 AI**
- 只從還有次數的招式裡挑，並略過沒有效果的招式（例如對方已經有狀態）。
- 野生怪獸隨機出招。
- 訓練家 75% 選期望傷害最高的招式，25% 隨機出招。

**遭遇**
- 只有成功走進高草叢格子時才判定：風草道 12%，霧苔林 14%。
- 轉身、撞牆、對話與選單都不會觸發遭遇。
- 戰鬥結束後有 4 步保護。

**金錢**
- 起始 300 銅貝。
- 打贏野生怪獸得到 敵方Lv×8。
- 訓練家獎金只在第一次勝利時發放：守林人 300，場主 1000。
- 全隊倒下時損失 10%，回到芽口村診所前並全員回滿。

**隊伍**
- 上限 6 隻，第 7 隻起送進收納箱（上限 60）。
- 兩邊都滿時不能丟籠子，介面會說明原因。

**存檔**
- 存在 `localStorage` 的 `wildling-trail.save`，資料版本 1。
- 只在安全的探索狀態寫入：選夥伴、治療、購買、撿道具與收納變動之後會自動存檔，也可以從選單手動存檔。
- 進入戰鬥前會先存一份快照，戰鬥結果在結算時一次提交。
- 讀檔時會驗證格式、數值範圍與資料參照。
- 存檔損壞時，標題畫面會顯示原因與「重新開始」。重新開始前會把原資料備份到 `wildling-trail.save.corrupt`，在新存檔寫入之前原資料不會被覆寫。

**亂數**
- 全部透過可注入的種子亂數（mulberry32）。
- 網址加 `?seed=數字` 可以固定種子。
- 動畫只讀取已經算好的結果，跳過動畫或減少動態都不會改變結果。

## 架構

| 目錄 | 內容 | 依賴 |
| --- | --- | --- |
| `src/core/` | 規則引擎：戰鬥、捕捉、成長、隊伍、世界移動、存檔驗證、內容驗證、亂數 | 只依賴 `src/data/` |
| `src/data/` | 物種、招式、道具、屬性、地圖、訓練家 | 無 |
| `src/app/` | 遊戲狀態機（標題、探索、對話、選單、轉場、戰鬥、結算、通關）、NPC 劇本、面板 | `core`、`data`；不碰 Phaser 或 DOM |
| `src/art/` | 程序化像素素材 | 無 |
| `src/view/` | Phaser 場景、DOM 介面、鍵盤與觸控輸入、WebAudio | 全部 |
| `src/main.ts` | 把狀態機接到畫面、輸入與音效 | 全部 |

在瀏覽器中，`window.__wildling` 會公開 `{ app, world, battle }`，供 Playwright 讀取狀態。

## 測試

### 已執行並通過（2026-09-24 戰鬥框改版後重跑，本機 Linux、Node 22）

- `npm run typecheck`：沒有錯誤。
- `npm test`：10 個檔案、127 個測試全部通過。涵蓋以下項目：
  - 地圖碰撞、互動距離與面向、安全傳送與條件出口。
  - 站立、轉身、撞牆、對話與選單不觸發遭遇；戰後步數保護。
  - 四種戰鬥行動的合法性、先手擊倒後對手不再攻擊、優先度、HP 與次數上下限、招式耗盡時的拚命。
  - 捕捉成功與失敗的道具消耗、捕捉機率上下限、強制換怪。
  - 隊伍滿員送進收納箱；經驗、升級、學招（替換或放棄）與兩階段進化。
  - 全隊倒下後的恢復、戰鬥中重新整理回到快照。
  - 商店餘額不足、一次性獎勵、讀檔後世界進度一致、11 種損壞存檔、localStorage 不可用或寫入失敗。
  - 快速連按不重複觸發對話、遭遇、購買或結算。
  - 內容驗證，以及全部素材與劇本齊全。
  - 戰鬥框的 2×2 招式格子移動（碰到邊緣停住、不會移到空格）。
  - 固定種子 `20260924` 的完整流程：新遊戲 → 初始夥伴 → 戰鬥 → 捕捉 → 治療 → 森林任務 → 首領 → 通關 → 自由探索 → 讀檔驗證。流程測試由程式自動操作同一個狀態機（沒有預設勝利），按鍵與真人相同。
- `npm run build`：成功，產出單檔 `web/131-wildling-trail.html`。
- `npm run test:e2e`：4 個 Playwright 測試通過，用 headless Chromium 對建置後的單檔操作：
  - 1440×900 鍵盤：開始 → 教學 → 選夥伴 → 走到草地 → 野生戰 → 逃跑。
  - 390×844 觸控：控制區不遮住畫面與手帳、介面沒有水平溢出、點選夥伴卡片、逐一打開每個選單項目。
  - 390×844 觸控戰鬥：手帳收起，戰鬥框在畫面框內而且不和控制區重疊；點選指令與招式、用十字鍵在招式格子裡移動、打開背包時畫面框大小不變。
  - 損壞存檔顯示原因與重新開始，並留下備份。
  - 三個測試都檢查沒有 uncaught exception、`console.error` 或外部網路請求。

### 已執行但失敗

- 無。

### 未能執行

- 實體手機（iOS Safari、Android Chrome）沒有測。手機驗收只做了 Chromium 的觸控模擬。
- Firefox 與 WebKit 沒有測。
- 透過瀏覽器從頭玩到通關沒有自動化。完整通關只在 Vitest 的流程測試裡驗證；瀏覽器測試只涵蓋到第一場野生戰鬥。
- 音效只確認在使用者互動後才啟用、而且可以關閉，沒有實際聽過輸出。

## 已知限制

- 只有一個存檔欄位。
- 沒有暱稱輸入。怪獸以物種名稱顯示。
- 戰鬥只有單對單；沒有雙打、特性或持有道具。
- 平衡以「會換屬性的玩家」為準。只用初始夥伴硬打時，大約要 Lv13 以上才打得贏場主。
- 單檔約 1.35 MB（gzip 後約 390 KB），其中大部分是 Phaser。第一次載入比其他作品慢。
- 標題與通關畫面的展示用怪獸會有些重疊。結算畫面只顯示我方怪獸。
