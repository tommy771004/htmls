- 靜態美術、分包與執行期腳本放在 `assets/286/`（包含 `lineage163/`、`packs/*.bin` 共 335 包分包、`assets/284/` 角色與登入動畫影格、`art-assets.json`、`art-cache-sw.js`、`local-materials327-sw.js`、`auto-worker465.js`、`scenery-worker289.js`）。

  - 後端單元與 18 端點整合測試：`npm run test:lineage`（執行 `node --test server/lineage-web/lineage.test.mjs`）。
  - 無頭 Chrome 實機驗收與縮圖產出：在 `games/286-lineage-web/` 執行 `npm test`（`node tools/accept.mjs`），檢查 5 種視窗尺寸零水平溢位、9 大視圖（`/` 遊戲大廳、`/official` 官方入口、`/guide` 243 筆攻略圖鑑與 NPC 對話查詢、`/form` 冒險者論壇、`/rice` 能力骰子模擬器、`/topup` Origin Pay 簽章結帳與 Google Play 冪等領取、`/gm` GM 控制台、`/privacy` 與 `/privacy2`）互動與零錯誤，並自動輸出 `thumbs/286.jpg`（640×400）。
- 頁面暴露 `window.__lineage` 測試與診斷介面（`ready`、`getState()`、`navigate(route)`、`setStage(stage)`），且當靜態託管無後端時自動降級至瀏覽器內建 `localStore` 後援，確保零 404 與零 `console.error`。
- Cloudflare Edge Worker 與 Durable Object（`R2_ASSETS` 分包 Byte-Range 服務＋`RealmGatewayDO` WebSocket 閘道）位於 `games/286-lineage-web/worker/`；部署 Worker 一律由使用者以自己的 Cloudflare 帳號手動執行 `npx wrangler deploy`，切勿自動執行。
- 登入、創角、選角與遊戲階段（`#/` 且 `stage` 為 `login`／`create`／`select`／`game`）整頁只輸出舞台（`body.ll-stage-only`，不顯示頂部導覽列與狀態卡片，選角槽也不疊名字標籤）。背景音樂由 `app.js` 的 `syncBgm()` 與遊戲內的 `GameAudioManager` 分階段接手控制（登入／選角放 `linmusic_login.mp3`、創角放 `create.mp3`、進入說話之島放 `lineage163/sound/0.mp3` 並隨戰鬥／施法／升級播音效）；`getState()` 會回報 `bgmTrack`／`bgmPlaying`／`bgmMuted`。
- 進入遊戲＝**286 原生 1.63 等距天堂實境客戶端**（`src/game/`：`engine.js`、`map-iso.js`、`sprites.js`、`world-state.js`、`hud.js`、`auto-hunt.js`、`assets.js`，配合 `tools/extract-world-data.mjs` 萃取自 `assets/286/` 的 `src/data/talking-island.json`）。`mountGameFrame()` 在 `#app-root` 外掛載 `#ll-game-host` 與 `LineageGameEngine`，支援說話之島地圖 `0..3` 即時區塊解壓、高畫質重繪建築與遮蔽半透明、8 方向人物／怪物／NPC 動畫、點地尋路與鎖定戰鬥、地面掉寶與拾取、NPC 對話／商店／矮人倉庫／傳送師、經典底部 HUD（F5–F12 快捷列、道具裝備、魔法書、狀態、小地圖）與「內掛符石／喝水符石」。所有進度保存在 `ll286:<帳號小寫>:world_slot_<slot>` 與倉庫鍵值，不覆蓋使用者 284 存檔；刪除角色時 `clearGameSlot()` 一併清除。`window.__lineage.game()` 回報即時快照、`__lineage.engine()` 回報引擎實例。
- 前端何時走後端 API（`shouldUseNetworkBackend()`）：port 8127（`npm start`）、頁面設了 `window.__LINEAGE_BACKEND__`，或在 `*.vercel.app` 上由 `probeBackend()` 探測 `/api/lineage/health` 且 `databaseMode === 'neon-postgres'`。Vercel 的記憶體模式會因冷啟動／多實例遺失帳號，所以那種情況仍用瀏覽器內後援；其他靜態主機不探測（避免 404）。後端只讀 `LINEAGE_DATABASE_URL`，**刻意不讀共用的 `DATABASE_URL`**（127 麻將的庫）；資料表不會自動建立，要先在 Neon 執行 `server/lineage-web/schema.sql`。Vercel 要設 `LINEAGE_DATABASE_URL`、`REALM_WS_SECRET`（與 Worker 的 `REALM_TICKET_SECRET` 相同）、`ORIGIN_PAY_SECRET`、`GM_ADMIN_TOKEN`，選填 `NEXT_PUBLIC_WS_GATEWAY_URL`；三個密鑰沒設會用原始碼裡公開的 dev 預設值。
- 即時連線（`app.js` 的 `connectRealtime()`）：已登入且走後端 API 時，向 `/api/lineage/realtime` 取票證，`wsEndpoint` 是 `ws(s)://`（Vercel 設了 `NEXT_PUBLIC_WS_GATEWAY_URL`）才以 `?ticket=` 連 Worker 的 `/ws`；每 5 秒 `{type:'ping',seq}` 量延遲，`snapshot`／`presence` 帶在線人數，斷線以指數退避（上限 30 秒）重連並重新取票證。狀態只改 `#realtime-badge`（右下角固定標籤，放在 `#app-root` 根層、不在導覽列內：導覽列的 `backdrop-filter` 會讓 fixed 失效），不整頁重繪。`getState().realtime` 回報 `status`／`online`／`latencyMs`。Worker 的 `RealmGatewayDO` 建構子是 `(state, env, pairFactory?)`（Cloudflare 以 `(state, env)` 建立，第三個參數只給測試）。本機實測：`worker/` 下 `npx wrangler dev --port 8788 --var REALM_TICKET_SECRET:<s>`，再以 `REALM_WS_SECRET=<s> NEXT_PUBLIC_WS_GATEWAY_URL=ws://127.0.0.1:8788/ws npm start`。
