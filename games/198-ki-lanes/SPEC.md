# 氣鬥三路 · KI LANES（作品 198）規格

把《七龍珠 FighterZ》的連段手感放進俯視角三路推塔（MOBA）的瀏覽器遊戲。Three.js 0.186.0 + esbuild，打包成單檔 `web/198-ki-lanes.html`。角色是 FighterZ 的六名角色（非官方同人致敬），但模型、特效、地圖、音效全部以程式產生，不使用任何原作的貼圖、模型、圖示、音效或文字素材。

## 1. 機制分析（參考對象的核心機制 → 本作的對應）

**資源規則**（`config.js` 的 `RES`）：

- 魔力型（七龍珠叫魔力、火影叫查克拉）：上限與每秒回復依定位（術士 380＋46／級、每秒 4.6＋0.4／級；坦克 300＋34／級…），裝備可加上限（`mp`）與回復比例（`mpr`）。花費 Q 45→65、W 55→75、E 50、R 100。
- 能量型（海賊王叫體力）：上限 200、每秒回 12，裝備不加。花費 Q 50、W 60、E 40、R 0。
- R 另外花 3 格氣。按住 C 集氣時資源回復 ×3；泉水每秒回 12% 上限；仙豆回 45%；爆氣期間額外回 15%；復活時回滿。
- 資源不夠時技能放不出來，頭上跳「魔力不足」，技能格變暗、花費數字轉紅。AI 補兵與清野只在魔力過半時用 Q，魔力見底且殘血時回城，在泉水等魔力回到 85% 才出門。

**符文**：五系 `RUNE_TREES`（每系的基石 `keys`）、`MINOR_RUNES`（tree、row 1～3、`psv`）、`SHARDS`（3 列）、`RUNE_PAGES`（各定位預設）。英雄身上是 `h.rune`（基石）與 `h.page = { minors[3], sec, secs[2], shards[3] }`；`units.defaultPage(def, key)` 依基石所在系組預設頁，`itemPassives` 以 `rune_` 前綴把小符文併入 `h.psv`，碎片與屬性類小符文在 `statMods`。基石效果在 `traits.js` 的 `runeOnHeroHit`／`runeBeforeAuto`／`afterAuto`／`runeTick`／`beforeTaken`／`afterTaken`；擊殺相關在 `onTakedown` 與 `onUnitDeath`；召喚師技能相關（機巧閃現、萬能卷軸、筋斗雲披風）在 `summoners.js`；商店相關（回饋金、神行鞋、時光藥、乾糧）在 `items.js`。持續傷害（`opts.dot`）不會讓施放者現形。

**英雄天生被動**：`config.js` 的 `PASSIVES`（名稱、說明、`psv`），`units.itemPassives` 以 `hero_` 前綴併入 `h.psv`，和裝備共用效果原語；英雄專屬的種類：`selfLowHp`（殘血增傷與攻速）、`skillPctMax`（技能附加最大血量 %）、`costCut`（技能消耗）、`vsCc`（對被控場者增傷）、`copy`（複製附近敵人施放的技能，下一招增傷）。

## 3. 座標與地圖

- 世界單位 = 公尺，`x` 向右、`z` 向下（朝鏡頭），`y` 向上。地圖 `x,z ∈ [-90, 90]`。
- 青隊主堡 `(-72, 72)`，泉水 `(-82, 82)`；赤隊為點對稱 `(x,z) → (-x,-z)`。
- 路線（青隊→赤隊方向的路點），赤隊的路線是同一條反向：
  - 上路：`(-66,56) (-72,10) (-72,-50) (-62,-64) (-50,-72) (10,-72) (56,-66)`
  - 中路：`(-58,58) (58,-58)`
  - 下路：上路的點對稱反向。
- 河道：`(-90,-90)` 到 `(90,90)` 的反斜線附近帶狀（中心線 `x = z`），寬約 10。
- 塔：每路沿路線距己方端點約 16～20%（內塔）與 37～39%（外塔）處（`map.js` 的 `STRUCTURES` 計算）。
- 障礙物是圓：石牆（`kind: 'wall'`，沿折線每 1.1 公尺取樣、半徑 1.75～2.2、互相重疊成連續的牆）與零散的樹叢、岩石（彼此間隙 ≥ 2.8）。只設計青隊半邊（z > x），點對稱 `(x,z)→(-x,-z)` 到赤隊。石牆沿三路內側、河道兩岸與四個營地外圍（U 形、兩個開口），避開路線、河道、基地、塔下廣場、營地、神龍坑與草叢，所以會在草叢與路口斷開成缺口；先產生草叢再鋪障礙物。移動時推出圓外並沿切線滑動；碰撞、繞障與視線檢查透過 8 公尺空間格（`obstaclesNear`）只查附近的圓。
