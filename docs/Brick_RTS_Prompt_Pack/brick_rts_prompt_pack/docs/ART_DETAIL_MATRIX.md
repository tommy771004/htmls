# 積木美術細節矩陣

這些是原創美術的製作要求，不是現成模型，也不是官方 LEGO 套件結構。每項的遊戲能力仍以 ruleset 為準；裝飾不可偷偷增加防禦、資源、遮蔽或物理破壞機制。

## 人物、動物與機械

| 資產 | 細節與狀態 |
|---|---|
| 村民 | 積木人偶頭／軀幹／髖與手部 socket；斧、鎬、鐮、槌可換；搬木／礦／食物容器可見；移動／工作／建造／修復／死亡。 |
| 近戰步兵 | 劍／矛長度與盾形區別，頭盔與裝甲層級，玩家色在盾或衣甲；攻擊時武器不穿過手掌。 |
| 遠程兵 | 弓、弩、箭袋或槍械輪廓；瞄準／裝填姿勢清楚；射擊方向與權威目標一致。 |
| 騎兵與騎射 | 積木馬頭／身體／腿／鞍、騎士與馬的分離 attachment；騎手不漂浮；部隊半徑與馬體匹配。 |
| 僧侶 | 披袍／手杖或原創宗教器物，治療／轉化與遺跡攜帶姿態，不能只依帽子顏色區別。 |
| 攻城車 | 輪組、車架、撞擊端、防護棚，移動與撞擊連桿；乘員效果由規則驅動。 |
| 投石／展開攻城器 | 軸、長臂、配重／彈性結構、絞盤；收起／展開／裝填／發射不能互相穿模。 |
| 弩砲 | 長型底座、弩臂、箭槽、輪組、轉向與發射動作。 |
| 船隻 | 積木船殼、水線、船首、甲板、桅杆／帆、玩家旗色；運輸／商船／戰船／漁船輪廓各異。 |
| 貿易車 | 輪軸、貨物、牽引動物／原創構造，貨載狀態與經濟事件一致。 |
| 獵物／家畜 | 積木式輪廓、簡單行走／受驚／死亡或耗盡狀態；小型動物遠景可簡化，不能消失成不可選取。 |

## 地景細節

地台有一致的積木模數；草地、土路、沙岸與岩地靠結構與色板辨認。樹葉為可批次實例化的模組，樹幹／樹樁表示可採集與耗盡。礦脈可見斜面晶體但不可全用發光材質。水面用少量透明／不透明積木式表現與受控波紋，不為每格水建昂貴透明疊層。裝飾石、花、工具與貨物只放在對讀圖有益的位置。

## 資產生命週期

1. Construction：地基、樑柱、牆體、屋頂、細節與旗幟，初始提議五段。
2. Operational：idle／work，動作與真實生產、資源返還、科技事件連動。
3. Damaged：局部缺件、有限煙火、可讀 HP，而非全棟消失。
4. Destroyed：少量 pooled 積木碎片與短期裝飾殘骸；導航由 sim footprint 變化決定。
5. Repaired／Upgraded：恢復或換代，保留建築身份與指令關係，不丟失 queue。

## 美術驗收

提供正面、側面、斜俯視與遊戲距離的真實模型截圖；正常遊玩、近看與遠看各驗一次。檢查懸空、接縫透光、破面、z-fighting、透明排序、陰影閃爍、選框錯位、入口阻擋、裝備穿模、不同時代混亂與玩家色不足。

LOD 的視覺切換可平滑，但不可在切換時改碰撞、射程、視野或選取權。外觀不影響權威規則，除非 manifest 明確定義。
