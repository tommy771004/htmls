# 19｜首次使用、玩到卡住、修正再測


假設你第一次使用本遊戲，不熟悉快捷鍵與開發者預設。真的從新工作目錄安裝並在可用的瀏覽器操作；若缺少瀏覽器／依賴／目標硬體，明確列出不能驗證的步驟，不把純程式檢查寫成親自遊玩。

測試路徑：首次進站→等待／失敗重試→設定畫質與音量→建立對局→找出村民→採木與採食物→送返→造房→造軍營→升時代→造兵→偵查→攻擊→撤退／治療→勝败→再開局。進階另跑海上運輸、遺跡、存讀、多人、情境編輯器。

每次遇到阻塞，記錄 seed、ruleset、browser／OS、tick、完整操作、預期／實際、截圖或 log、重現率、嚴重度與根因。優先修不能開始、不能選取、村民無法工作、部隊卡門、黑屏、無法勝利、資料丟失；不是先添裝飾。

額外嘗試：亂按快捷鍵、快速雙擊生產、滿人口、資源不足、拖曳跨 HUD、視窗縮放、切分頁、取消建造、入口被堵、命令目標消失、連續存讀、重連、遊戲結束後再下命令。

修正只觸及必要檔案，增加回歸測試，從原重現步驟再驗證；同時檢查是否引入破圖、穿模、碰撞、迷霧洩漏、音源／GPU 資源洩漏或規則偏差。沒有重測不能標「已修正且通過」。

交付本輪問題表、修正檔案、測試命令與結果、真實截圖／logs、仍未驗證項。依嚴重度重複此迴圈，直到沒有已知阻塞；不要把「沒有已知阻塞」等同完整內容或零 bug。
