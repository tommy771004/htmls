# 07｜經濟、村民、採集與交易


依 Master 實作能持續運作、可被打斷且可恢復的經濟循環。

- 四資源：食物、木材、黃金、石頭；可用庫存、攜帶量、已扣成本與地圖剩餘資源分開記錄。成本扣除與取消退款使用明確 transaction，不容許負值或重複退款。
- 村民狀態機：idle→moveToSource→gather→carry→moveToDropoff→deposit→resume；另含 build、repair、attack、flee、garrison、dead。右鍵換工、Shift 排程、資源耗盡、目標被毀、被招降、路徑中斷都有一致轉換規則。
- 支援伐木、採金、採石、野果、狩獵、家畜／食物來源、農田、岸邊魚與漁船採集等規則，適用單位與建築由資料設定。
- 資源點有工作位置／容量，返還使用合法的相容 drop-off building。中途改派、死亡、駐軍、所有權轉換時的攜帶資源處理，需寫進規則表與測試。
- 獵物／家畜需要移動、驚嚇／反擊或歸屬狀態；食物腐敗、採集效率、回收與科技影響按指定版本核對。不能用單一靜止 food node 冒充全部機制。
- 農田建造、剩餘食物、補種／重播佇列、自動補種開關、費用及農民站位；漁網／魚陷阱等內容按 scope manifest 納入。
- 建造／維修多人協作效率、費用與取消退款從資料讀取。自動返工不覆蓋玩家剛下的新命令。
- 市場買賣四資源的合法對應、手續費、價格變動範圍、團隊進貢與交易 UI；若規則涉及全局或個人市場價格，需對照版本而非猜測。
- 經濟科技更新採集速度、攜帶量、移速或效率時，有明確既有工作影響時間點。

交付純 sim 工作流程與積木人物工作／搬運動作連動。驗收村民可完整採集→送返→續採、斷路不無限等待、農田耗盡補種、不足資源拒絕、死亡不憑空入庫、取消不增殖資源、存讀後攜帶量一致。建立資源流量帳，而不是僅看右上角數字上升。
