# 06｜操作、鏡頭、HUD 與可讀性


製作可長時間操作的桌面 RTS 介面，不直接複製原作圖示／版面像素。

- 單選、拖曳框選、Shift 加減選、雙擊同類範圍規則、Ctrl 數字編組／數字選組、Shift 排程、右鍵依目標派工／攻擊／移動、空閒村民、軍隊快速選取、建築循環、集結點。
- 點擊／拖曳門檻、UI pointer capture、世界與 HUD 事件隔離、右鍵 contextmenu、輸入法／文字框快捷鍵隔離、失焦釋放按鍵、觸控板縮放均需處理。
- 建造有地面吸附、佔地 preview、旋轉允許範圍、合法／非法原因、連續放置、Esc 取消；成本不足／缺科技／人口滿的操作提供具體訊息。
- 鏡頭平移、邊緣捲動可關閉、縮放、minimap 定位。預設固定斜角以保持方向感；旋轉可選，但開啟時需要指南方向與 minimap 一致性，不能讓按鍵移動方向錯亂。
- HUD 顯示四資源、人口／上限、時代、玩家／隊伍、選取詳情、命令格、科技樹、生產佇列、研究進度、目標提示、事件／攻擊警報、暫停與設定。
- 多選混合軍種顯示合法共同命令與明確分組；不能因多選把農民當軍隊或偷偷把全部佇列清空。
- 深色字與淺底／高對比組合以實測確認。積木質感只作邊框和少量細節，不讓 HUD 每格都是反光玩具。支援字體縮放、色盲友善符號、快捷鍵重設、音量分類。
- Tooltip 的費用、時間、前置科技與增益都來自 ruleset；禁用按鈕給原因，不能只是灰色。

交付實際連到 sim commands 的 UI，不使用寫死資源或假倒數。測試 UI 點擊不誤指揮部隊、快按不重扣費、跨 HUD 拖曳、minimap 越界、DPR／視窗 resize、縮放後射線選取、連續框選與 Esc。
