# 12｜遭遇戰 AI、難度與團隊行為


建立使用同一命令 API 的 RTS AI；不能以定時生成部隊或直接扣敵方 HP 代替。

- AI 只透過該玩家合法 observation 讀取視野／最後情報，預設不偷看全圖、不免費造兵、不繞過前置科技。若另設作弊難度，必須明示並獨立規則。
- 經濟配置：村民生產、資源優先級、人口餘裕、採集點／dropoff 距離、農田與補種、補充被毀經濟、貿易與資源短缺。
- 發展：建築位置可達、科技與時代規劃、對地圖／文明條件調整、偵查與敵方意圖估計。找不到建築位置需有恢復策略，不無限重下同一命令。
- 軍事：依可見情報選擇反制、集結、前線補兵、攻城器配合、分隊、撤退／防守／突襲。海圖要能造船、漁業、運輸與登陸。
- 團隊合作：防守盟友、分配敵人、合法資源支援；遵守外交與視野規則。
- 難度調整觀察頻率、決策間隔、規劃深度、操作預算、策略完整度；不要只有 HP 倍率。固定 seed 時結果可重播。
- AI 決策有結構化 reason／blocked reason，提供 debug panel。Think budget 按 deterministic tick 調度，不能讓某台電腦較快導致 AI 多做決策。

驗收：多 seed 的 AI 自我對戰、資源枯竭、村民大量死亡、卡人口、敵方封路、海圖、被突襲、主基地被毀仍可恢復。記錄完成率、死循環、非法命令與長時間閒置。無實跑的對局不可編造勝率。
