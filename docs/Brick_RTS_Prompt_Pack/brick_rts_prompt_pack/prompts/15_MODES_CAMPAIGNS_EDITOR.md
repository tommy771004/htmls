# 15｜模式、原創戰役與情境編輯器


把不同勝利條件、戰役流程與編輯器建立在可擴充的情境系統上。

- 勝利／失敗條件可組合：征服、重要人物存活、遺跡控制、世界奇觀倒數、指定區域控制、限時／資源／擊殺／護送目標等。標準遭遇戰、死亡競賽、弒君與其他指定版本模式逐一對照；未核對的不列為已支援。
- 遊戲設定包含起始／最高時代、資源、人口、地圖、隊伍／外交、速度、揭圖選項、AI 難度、允許／禁用單位／科技。所有設定反映在 sim，不只 UI。
- Scenario schema 含地形、資源、玩家、出生點、預置實體、科技狀態、外交、區域、任務、trigger 和文字本地化 ID。
- Trigger 支援條件、事件、once／repeat、delay、variables、AND／OR 與動作；同 tick 穩定排序，有循環與每 tick 上限，錯誤帶 trigger ID。不可執行外部任意 JS 作為預設情境腳本。
- 編輯器支援地形高度、水陸、樹／礦、建築／單位／歸屬、區域、目標、簡單 trigger 編輯、undo／redo、validation、save／load／export／import／playtest。不能只有放置城堡的 viewer。
- 戰役含選關、開場敘述、關卡目標／更新、過場、勝敗、進度與下一關解鎖。劇情、對話、美術與音樂使用原創或適當授權內容，不直接搬原作戰役文字。
- 製作至少一個原創多關流程驗證：經濟與防守、攻城、海運／登陸；數量是引擎驗收範例，不冒充原作全部戰役。原作劇情內容的逐關重現如未取得／指定合法資料，列為未涵蓋。

驗收：普通勝利、同 tick 雙方敗北優先序、倒數被中斷、護送目標死亡、合作玩家離線、trigger 儲存恢復、匯入損壞情境、undo 後導航與 fog 更新、整條戰役完成並重新讀取進度。
