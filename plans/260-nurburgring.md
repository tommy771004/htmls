# 260 霓虹夜城：紐柏林賽道（北環＋GP，1:1）

使用者在 2026-10-29 決定：

- 真實比例 1:1，北環（Nordschleife）與 GP 賽道一起做。
- 不蓋跨海大橋，新的土地直接接在現有的陸地上。
- 位置選 A：接在灰鷺角國際機場的南面。B（燈籠公園、珊瑚灘南面）會蓋掉鷹巖村 (312, 2733) 與 TRON (2100, 2900)，沒選。

## 圖資

- 下載的原檔與處理腳本放在 session 的 scratchpad，不進 repo。
  - OSM 是 Overpass 查詢：raceway 與方圓 4.2 km 的建築、道路、土地利用、水道、護欄。
  - 地形是 AWS Terrain Tiles（terrarium，z14，x 8505–8512、y 5528–5534）。
- 本地平面座標：
  - 原點 50.35N 6.96E，x 往東、z 往南，單位公尺。
  - KX = 111320·cos(50.35°)，KZ = 110574。
- 高程：20 m 一格，真實高度 295–718 m。
- 北環：
  - 全長 20,712 m，高度 340–628 m，最小半徑 24 m（Wehrseifen）。
  - OSM 的點序和行車方向相反。
- GP：5,114 m，高度 566–622 m。
- 授權：
  - OSM 是 ODbL，要標「© OpenStreetMap contributors」。
  - 地形要照 Terrain Tiles 的出處標示寫進 `assets/260/CREDITS.md`。
  - CGTrader 的 Karussell 圖只當參考，沒有任何檔案進遊戲。

## 擺法（SEA_FR 座標，`?zrot` 跟著轉）

- 轉 180°：真實座標 (x, z) 換成 `X = −x + OX`、`Z = −z + OZ`，其中 OX = −4100、OZ = 6800。轉過來之後 GP 在北邊、對著機場。
- 地形本體取真實 x −3400..3800、z −3950..4200（賽道外留 ≥ 500 m）。
  - 世界範圍是 X −7900..−700、Z 2600..10750，約 7.2 × 8.15 km。
  - 東緣 −700：離珊瑚灘北（G1，最西約 −458）還隔一段海。
- 高度：真實高度減 290 m。
  - Adenau 谷底約 +5 m，Breidscheid 約 +50 m，GP 約 +280–330 m。
  - 所有陸地都在海面上，海面不用挖洞。
  - 不能用「GP 貼海面、Adenau 沉到海面下」的做法：水深、游泳、船、鏡頭在水下的效果都照 `seaFloor` 判斷，有一部分在另一個 session 的檔案裡。
- 引道坡（非真實地形，唯一人造的部分）：
  - 範圍 Z 600..2600。北端貼機場島的南緣（`AIR.isl.z1 = 600`），高度 0。
  - 往南升到地形本體北緣的高度：真實約 430–630 m，減 290 後約 +140–340 m。
  - 寬度從機場南緣那段（X −3300..−1000）往南展開到整個本體寬。
  - 坡面疊緩丘的長波，不是一整面平面。
  - 進場道路要在這 2 km 裡折返一次，才壓得到 8% 以內。
  - GP 離機場南緣約 3.3 km（之前說的 600 m 是沒算坡度的估計）。
- 本體的東、西、南三面：外面 600 m 降到海床 −8，是海崖。

## 順序與驗證

1. 資料工具 → `09-nbr-dem.js`。
2. `09-nbr.js`＋四個掛點。用自己的腳本從機場開上引道、到 GP 的維修區：
   - `deckAt` 不是 null，
   - `waterDepth` 是 0，
   - 沒有卡住或掉下去。
3. 地形網格與材質，看截圖。
4. 賽道路面（照預覽的整平與路緣），看截圖。
5. 進場道路。
6. 建築、森林、護欄。Karussell 與護欄在預覽裡還沒截圖確認過。
7. 四組驗收依序跑，再 `npm run build`。
8. 文件：`CLAUDE-world.md`、`HANDOFF.md`、`README.md`、`CREDITS.md`。
