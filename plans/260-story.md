# 260 霓虹夜城：主線劇本《一手爛牌》規劃

> 狀態：規劃稿（2026-10-26），尚未動工。
> 2026-10-26 使用者已拍板三件事：「門禁 · 今夜」改寫進主線、兩種結局都做、主線任務進行中鎖定只能操作雙主角。另外要求：任務照順序解鎖，但不強迫玩家去接；獎勵照任務難度給。
> 參考來源是 GTA VI 的三支預告與 Rockstar 官方角色簡介。遊戲 2026-11-19 才上市，**完整劇情目前沒有公開**，所以本劇本大半是依預告方向補出來的原創情節。
> 260 的慣例是「結構借用、名稱原創」：角色、幫派、地名、台詞一律原創，不放原作名稱或台詞。

## 二、角色

### 雙主角（新增，原創）

- **羅莎·伊巴拉（Rosa Ibarra）**：拉丁裔，29 歲。年少在地下擂台打過拳，替前男友頂罪坐了三年牢。她心思縝密，脾氣上來時下手很狠。
  - 特殊能力暫定 `focus`「冷靜判讀」：近戰反擊窗口變長，槍械瞄準會吸附弱點。
  - 住處：開場暫住母親在灰石國宅的房子。
- **戴恩·默瑟（Dane Mercer）**：白人，34 歲。在陸軍駐訓時替人揹了黑鍋，不名譽退伍，回城後找不到正職，替霍利斯催收換免房租。他嘴硬心軟，對羅莎死心塌地。
  - 特殊能力暫定 `drill`「戰術呼吸」：衝刺和壓制射擊的耐力翻倍，換彈加快。
  - 住處：錨灣港船廠後面的拖車屋。

兩人的出處：預告1、預告2、預告3、官方；姓名與細節為原創。

### 既有角色怎麼接進來

- **賈克斯**：霍利斯的前跑腿。小劇場那句「少了兩捆」，原來是被霍利斯的人吃掉了，這是第一章的引子。之後他供應軍火（地堡）。
- **范斯**：小劇場裡一直接到「我已經退休了」的電話，打來的是聯邦的舊上司。他在第五章現身當兩人的「接頭人」，是終章抉擇的一方。
- **凱爾**：第二、四章的接應車手（從 69-v3-heist 雇用的司機池升格）。
- **Zero**：電話裡的駭客，第五章和奧帝斯一起解帳本。
- **奧斯卡**：他最後一段委託揭露了赤蠍幫的「帳房」，第二章搶到的帳本就和這間帳房對得上。玩過那段委託的玩家，會多一段對白。
- **赤蠍幫**：天際置業在街頭的打手。
- **陰謀網的其他成員**：
  - 鐵庫保全（股票代號 IVLT）的運鈔車替他們洗錢。
  - 霓鑽賭場是金流出口。
  - 第九分局負責掩護。
- **新增第二個幫派「鐵鏽騎士」**：琥珀工業區的機車幫（出處是官方的工業鎮簡介），幫陰謀網運貨。

### 「門禁 · 今夜」改寫進主線（已決定）

- 新存檔不再以凱爾和「門禁」開場，改從序章 P-1 開始，操作羅莎。
- 「門禁」整段改成第三章的 3-1。兩人要進 LAZARUS 見蒙洛，流程照原本的五步：
  1. 門口的 Marlo 不放行。
  2. 到 AFTERGLOW 找 Juno 拿畫了夜鷹的火柴盒（Juno 是蒙洛的老朋友）。
  3. 拿火柴盒給 Marlo 看，絨布繩撤開。
  4. 走進 LAZARUS。
  5. 在舞池跳滿 5 秒。蒙洛在 VIP 包廂看見，叫人請兩人上樓，接著是 3-2「大橡」。
- 實作上沿用 60-venues 的 `QUEST` 表和 99-main 的跳舞判定，包成主線的一種步驟（`quest`）。
  - 原本完成時給的 $250,000 拿掉，改成照主線的報酬表發錢。
  - 結尾台詞改寫。
- 開場時的 `crew.cur = 1`（凱爾）改成羅莎。凱爾在第二章才登場（2-4 在排水道出口接應）。
- `npm test`（accept）原本會走完整段「門禁」，要改成用 `__nc.story.go('3-1')` 跳到這一關再走。
- 舊存檔裡「門禁」已經完成的，不跳過 3-1：玩到 3-1 時 Marlo 換一句「又是你」，流程照走。

## 三、劇本大綱

一共七幕、38 個任務（終章的兩條路各算一個）。各任務的難度與報酬見第四節。每個任務都有開頭過場（`cineTalk`），結尾是來電（`cineCall`）或對白（`dialog`）。

表格「機制」欄的寫法：

- **side**：既有的 `side.act` 類型，包括 fight、deliver、collect、tail。
- **heist**：69-heist 的流程。
- **新**：要新寫的機制。

## 四、任務的解鎖、自由度與報酬

### 解鎖與自由度（已決定）

- **照順序解鎖**：地圖上一次只出現一個主線起點，也就是下一個還沒完成的任務。完成這一關，下一個起點才會出現。
- **不強迫參加**：
  - 起點會一直留在地圖上等玩家，沒有倒數，也沒有懲罰。
  - 新任務解鎖時，委託人只打一通電話或傳一則簡訊，之後不會再催。
  - 不接主線的時候，現有的支線、比賽、搶案、地盤、股市、置產全部照常可以玩。
- **腳鐐不卡自由活動**：在自由活動中操作羅莎、走出範圍時，先警告 30 秒，之後只加 1 星，不會強制把她拉回來。切換成戴恩就沒有這個限制。4-3 之後腳鐐解除。
- **主線任務進行中鎖定為雙主角**（已決定）：
  - 切換角色的轉盤只剩羅莎和戴恩。
  - 不在任務中的時候，轉盤是五個人：雙主角加上范斯、凱爾、賈克斯。
  - 但范斯、凱爾、賈克斯在劇情中以 NPC 身分出場的那幾關，他們不能被切換成操作角色。
- **失敗與重試**：
  - 死亡、被捕或主動放棄都算失敗，可以馬上重試。
  - ★3 以上、步驟多的任務設中途檢查點，從最後一個檢查點重來。
  - 失敗不扣錢，也沒有其他懲罰。

### 難度與報酬

每個任務有固定的難度（★1–★5），基本報酬照難度給。純對白的任務標「劇情」，不給錢，但會解鎖下一關或功能。

| 難度 | 基本報酬 | 大致的強度 |
| :-- | --: | :-- |
| ★1 | $20,000 | 教學程度：沒有通緝，或只有 1 星；敵人 3 人以下 |
| ★2 | $50,000 | 2 星，敵人 4–6 人；或有時間限制的追車、送貨 |
| ★3 | $100,000 | 3 星；有裝甲的敵人；要有一點操作技巧（籠鬥、跟車） |
| ★4 | $200,000 | 4–5 星，多波敵人；載具戰（船、直升機） |
| ★5 | $400,000 | 大場面：搶案、跳機、吊掛、結局戰 |

- 搶案任務（4-5 搶銀行、F-1 賭場金庫）照原本的分贓算（銀行約 $200–250 萬，扣掉隊員抽成），不另外發基本報酬，只發獎牌加成。
- 這個標準是對照現有的經濟訂的：
  - 起始現金 $180,000。
  - 安全屋 $38–60 萬，車最貴 $125 萬，原本的「門禁」給 $250,000。
  - 主線不算搶案的基本報酬，走一種結局共約 $371 萬（銅牌）到 $557 萬（全金牌）。再加上兩次搶案，大約夠買下一半的車和產業。

### 獎牌（附加目標）

每個任務有 2–3 個附加目標，例如時間內完成、命中率、不換車、不被發現、不受傷。完成的數量決定獎牌，獎牌決定報酬倍率：

| 獎牌 | 條件 | 報酬倍率 |
| :-- | :-- | --: |
| 銅 | 完成任務 | ×1.0 |
| 銀 | 完成一半以上的附加目標 | ×1.25 |
| 金 | 完成全部附加目標 | ×1.5 |

重玩任務時，只發「新獎牌和舊獎牌之間的差額」，避免反覆刷錢。結算畫面沿用 `sideDone`，列出各附加目標有沒有達成，以及拿到的獎牌。

### 框架細節

- 每個任務是 `{ id, ch, title, who, at, steps: [...] }`。步驟有這幾種：
  - 包裝既有活動的：`side`、`heist`、`truck`、`race`、`surv`。
  - 過場與對白：`cine`、`talk`、`call`。
  - 新機制：`monitor`、`cage`、`window`、`boat`、`plane`、`sling`、`jump`。
- 進行中的任務掛在 `side.act`（kind 是 `story`），所以 `missionMark()` 的優先順序（heist → 防守 → `side.act` → QUEST）照舊成立。
- 主線用到 69-heist 時，`heist.st` 跑完才回到主線的下一步，`heistPass`／`heistFail` 要多加回呼。
- 大地圖加一類「主線」標記，用角色字首 R／D，GTA 式的寫法。
- 失敗的處理見第四節。目前搶案的進度不進存檔，所以主線只記到任務和檢查點，不記任務中的狀態。
- 任務進行中的鎖定：`crew` 的轉盤只列雙主角；69-v9 的小劇場和 69-crew 的切換都要先問 `storyLock()`。
- 地圖上只畫下一個未完成任務的起點。走進起點的圈按 E 才開始，起點的圈不會自己觸發任務。
- 測試 API 是 `__nc.story.go('3-2')`、`state()`、`skip()`；驗收腳本 `tools/check-story.mjs` 逐章跳到每個任務，檢查不出錯，並在兩種尺寸下截圖。

### 人物管線

- 現在路人用的是 Quaternius CC0 底模（`blender/people.py`），動畫庫也是它的骨架。
- Sketchfab 的人形要重新綁到 Quaternius 的骨架上，可以參考 266 把模型重綁到 UBC 的做法：
  - 先對照骨名，再轉向。
  - 每根骨頭對齊 T-pose。
  - 縮放到相同身高。
  - 權重改成新骨架的編號。
- 新工具 `tools/cast.mjs` 輸出 `assets/260/cast/*.glb`。主線角色只在 http(s) 下才下載，失敗時用 `crowd()` 的程式外型當替身。
