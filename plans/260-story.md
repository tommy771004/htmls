## 二、角色

### 雙主角（新增，原創）

- **羅莎·伊巴拉（Rosa Ibarra）**：拉丁裔，29 歲。年少在地下擂台打過拳，替前男友頂罪坐了三年牢。她心思縝密，脾氣上來時下手很狠。
  - 特殊能力暫定 `focus`「冷靜判讀」：近戰反擊窗口變長，槍械瞄準會吸附弱點。
  - 住處：開場暫住母親在灰石國宅的房子。
- **戴恩·默瑟（Dane Mercer）**：白人，34 歲。在陸軍駐訓時替人揹了黑鍋，不名譽退伍，回城後找不到正職，替霍利斯催收換免房租。他嘴硬心軟，對羅莎死心塌地。
  - 特殊能力暫定 `drill`「戰術呼吸」：衝刺和壓制射擊的耐力翻倍，換彈加快。
  - 住處：錨灣港船廠後面的拖車屋。

兩人的出處：預告1、預告2、預告3、官方；姓名與細節為原創。

### 既有角色怎麼接進來

- **賈克斯**：霍利斯的前跑腿。小劇場那句「少了兩捆」，原來是被霍利斯的人吃掉了，這是第一章的引子。之後他供應軍火（地堡）。
- **范斯**：小劇場裡一直接到「我已經退休了」的電話，打來的是聯邦的舊上司。他在第五章現身當兩人的「接頭人」，是終章抉擇的一方。
- **凱爾**：第二、四章的接應車手（從 69-v3-heist 雇用的司機池升格）。
- **Zero**：電話裡的駭客，第五章和奧帝斯一起解帳本。
- **奧斯卡**：他最後一段委託揭露了赤蠍幫的「帳房」，第二章搶到的帳本就和這間帳房對得上。玩過那段委託的玩家，會多一段對白。
- **赤蠍幫**：天際置業在街頭的打手。
- **陰謀網的其他成員**：
  - 鐵庫保全（股票代號 IVLT）的運鈔車替他們洗錢。
  - 霓鑽賭場是金流出口。
  - 第九分局負責掩護。
- **新增第二個幫派「鐵鏽騎士」**：琥珀工業區的機車幫（出處是官方的工業鎮簡介），幫陰謀網運貨。

### 「門禁 · 今夜」怎麼處理（建議）

- 原樣保留，當作凱爾的序章，`npm test` 的完整流程也不動。
- 主線在新存檔的開始選單另開，或在「門禁」完成後由手機來電觸發。
- 第三章進 LAZARUS 時，Marlo 已經認得玩家，直接放行。

## 三、劇本大綱

表格「機制」欄的寫法：

- **side**：既有的 `side.act` 類型，包括 fight、deliver、collect、tail。
- **heist**：69-heist 的流程。
- **新**：要新寫的機制。

## 四、要新寫的機制

大小是粗估，可以照大小砍。

### 框架細節

- 每個任務是 `{ id, ch, title, who, at, steps: [...] }`。步驟有這幾種：
  - 包裝既有活動的：`side`、`heist`、`truck`、`race`、`surv`。
  - 過場與對白：`cine`、`talk`、`call`。
  - 新機制：`monitor`、`cage`、`window`、`boat`、`plane`、`sling`、`jump`。
- 進行中的任務掛在 `side.act`（kind 是 `story`），所以 `missionMark()` 的優先順序（heist → 防守 → `side.act` → QUEST）照舊成立。
- 主線用到 69-heist 時，`heist.st` 跑完才回到主線的下一步，`heistPass`／`heistFail` 要多加回呼。
- 大地圖加一類「主線」標記，用角色字首 R／D，GTA 式的寫法。
- 死亡、被捕或中途放棄，就回到這個任務的開頭。目前搶案的進度不進存檔，主線只記到任務層級。
- 測試 API 是 `__nc.story.go('3-2')`、`state()`、`skip()`；驗收腳本 `tools/check-story.mjs` 逐章跳到每個任務，檢查不出錯，並在兩種尺寸下截圖。

### 存檔

- 新增 `motors.story = { v: 1, m: 'P-1', done: {}, flags: { monitor: 1, fame: 0, end: null }, crew5: [...] }`。
- 存檔版本 12 升成 13。舊存檔遷移時補上預設值：已經存在的存檔不強制進序章，等手機來電再開始。
- 目前 `quest.n` 只靠手機快速存檔保存，主線不能走這條路，要寫進 `motors.story`。
