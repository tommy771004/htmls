# 260 霓虹夜城：城市改成不規則路網（像 Los Santos）

2026-10-22 開始。使用者看了 GTA V 的 Los Santos 地圖，選了「整座城市重做」：現在的城市是一張 20×15 的方格（`00-core.js` 的 `avX`／`stZ`），整體輪廓與路網都是方的。目標是讓整體地圖看起來不規則：幾個區塊各有不同的方向、區塊之間用彎曲的幹道接起來、外圍輪廓與海岸線不是直線。

## 做法：分區剛體變換，不重寫生成

城市的生成（地塊、立面、店面、招牌、設施、停車、海岸）全部以方格座標寫成，亂數序列也綁在這個順序上（舊城區的立面要維持不變）。所以不重寫生成，而是在它上面加一層「區（zone）」：

- **邏輯座標**：現有的方格座標。所有生成程式照舊在這裡跑。
- **區**：邏輯平面切成幾塊（`05-zones.js` 的 `ZONES`），每塊有自己的剛體變換（平移＋繞 y 轉 `ry`）。世界座標 = 區的變換 × 邏輯座標。區與區之間的邊界放在道路中心線上；邊界那條路兩區各有一份，各自跟著自己的區走。
- **世界座標**：玩家、車流、行人、子彈、警察、相機、地圖上的點都在世界座標。靜態資料（地塊、碰撞框、路燈、停車位、場館錨點）保留邏輯座標，用到的地方再換算（`toW`／`toL`）。
- **區之間的縫**：區轉了角度之後彼此之間會留下楔形的縫，縫裡是世界座標的內容（草地、樹、路燈），兩區同一條大道的兩份端點用彎曲的「連接道路」接起來。要求每條縫至少 30 m 寬，邊界路的兩份才不會疊在一起。

所以區內的街道仍是直的方格，彎曲只出現在連接道路與海岸。這就是 Los Santos 的樣子（市中心、Vinewood、南區各是一張方向不同的格子，中間是彎的幹道與高速公路），之後不會再做彎曲的方格。

室內場館在 x ≥ 9000（`player.where !== 'out'`），不屬於任何區，座標不變換。

## 換算的位置（第 0 階段的實際工作）

| 項目 | 做法 |
| :-- | :-- |
| 網格 | 立面依街區分塊，掛到該區的 `Group`（區的變換）；`instanced()` 依每個 instance 所在的區把矩陣換成世界座標；整座城合併成一個網格的（人行道板、招牌、跳台）依區拆開。路面每區一張。 |
| 道路 shader | 路面、人行道、草地的標線與路緣是依方格解析計算的：頂點帶 `aL`（邏輯 xz），shader 用 `vL` 算標線，用 `vW` 算光。地上的水花用相機所在區的 `uZone`。 |
| 路燈 | `lampGrid` 原本依方格解析算路燈位置；改成世界座標的路燈表貼圖（每格列出影響範圍蓋到這格的路燈），20-props 的實際路燈位置換算後寫進去。 |
| 碰撞 | 靜態盒保留邏輯 AABB，帶上所屬區的框（`f`）；空間索引放世界座標的外接框。`collideCircle`、`rayBox`、視線、相機防穿牆把點換到盒的框裡算，推出量再轉回世界。圓柱直接換成世界座標。 |
| 路網 | 新的路網圖（`06-roads.js`）：節點是各區的路口（世界座標）加上連接道路的節點，邊是直線或折線。車流、警車追捕（`fieldTo` 改成節點 id 的 Dijkstra）、GPS、路障、叫車、出生點都改用這張圖。號誌依路口各邊在區內的方向分兩相。 |
| 行人、停車 | 行人照舊繞邏輯街區走，擺位置時換成世界座標；停車位在生成時算好世界座標與車頭方向。 |
| 地面高度與區名 | `groundH`、`onRoad`、`district`、街名：先 `toL` 再用原本的邏輯；縫裡另外處理。 |
| 日光陰影高度圖 | 範圍改成世界外框；地塊與實體建築的外框以兩個三角形（`hmTri`）畫進去。直升機的屋頂高度表一樣。 |
| 地圖 | 大地圖與小地圖每區用 canvas 的變換畫原本的矩形；標籤與圖示換成世界座標。 |
| 錨點 | 夜店、酒吧、車庫、車行、家、醫院、警局、銀行、安全屋門口、跳台、拉麵攤等：生成時用邏輯值，執行時的距離判斷與擺位置一律換算（邏輯常數不改值）。`__nc.spots` 給世界座標與朝向，驗收腳本改用朝向算「門前 d 公尺」。 |

## 階段

0. **剛體變換基礎**：上面整張表。測試方式是只有一個區、整座城市（含海岸與遠景）轉 25° 並平移，玩法要和現在一樣，`npm test` 與 `npm run test:glb` 全過。單位變換驗不出任何漏掉的換算，所以一定要轉。
1. **分區與連接道路**：切成 3–4 區（例如舊城＋冠石、光環＋灰石、南面整排含海岸），各自轉不同角度並拉開；縫裡鋪地形、種樹、放路燈，邊界路口之間用彎道接起來（車流與警車照樣走）。
2. **海岸與外圍**：海岸線、河岸改成折線（`inLand` 改成點在多邊形內），北面樓牆後的山區跟著各區的邊界走（北嶺國家公園可以在這時做成可以走的山路）。
3. **重調**：跳台、警察出生點、車流密度、GPS 與地圖標籤依新的路網調整；更新 README、SPEC、HANDOFF 與縮圖。

使用者接著要求：區的邊緣不要是長方形（依區的大小畫出不規則的外緣，區與區才接得自然），區裡的街道與建築也不要整齊的方格排列（參考 GTA V 的藍圖：整座城是一整片，外緣順著海岸與山勢，裡面是方向不同的小片格子）。第二版提案：

- 八區再切成 15 片（A1 舊城 0°、A2 冠石 +7°、B1／B2、C1／C2、D1／D2、E、F1／F2、G1／G2、H1／H2），同一區的兩片角度差 10°～14°，片與片的縫 31～53 m（快速道路經過的縫 64 m 為目標）。
- 整座城只有一條外緣：從中心每 2° 量到各片外框，靠山的北、東兩側用低頻起伏往內咬（離中心越遠咬得越多），河與海那一側不咬。四角都在外緣內的街區才保留（300 塊留約 240 塊），舊城核心 5×5 不能拿掉；`wholeBlocks()` 的實體建築有十幾處被咬到，要改放到別的街區。外緣是一條順著輪廓的收邊路，被拿掉的街區變成邊緣的綠地與山腳。
- 三條斜向幹道（楓林東、琥珀西、錨灣西）穿過的街區改成廣場或綠帶，不做三角形地塊。
