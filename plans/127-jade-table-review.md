# 青雀麻將五項檢查（2026-09-24）

範圍：既有青雀台灣十六張桌規、單人練習、四人好友房及桌面呈現。不新增玩法、不更換後端。

## 發現與修正

| 項目 | 結論與本次修正 |
| --- | --- |
| 規則與計分 | 七搶一由別家付分，但胡張是自己補得；原先漏計槓上開花，補成刻子也誤作明刻。現在分開判斷取得胡張方式與付款者，保留一人付款、不加自摸台，並排除錯加平胡。 |
| 可玩性 | 原先確定胡牌後仍會等只有吃碰選項的玩家。現在無人可提高順位時立即處理，仍等待較近的另一位胡牌者；新增過水原因提示。 |
| 連線與便利性 | 原先被其他分頁接管後仍自動重連，會互搶席位。現在收到 4001 即停止；過期回到入房表單；舊連線回呼不影響新連線。未收到斷線事件時的重連期限也統一為 30 秒。邀請網址直達入房、記住暱稱、重新整理提示連回原桌、桌面標明重連玩家。 |
| 各玩家視角 | 四位玩家均以自己為下方，下家右、對家上、上家左；門風與莊家獨立對應。手機側邊／本家資訊縮窄、對家卡與紀錄入口移位，改善明牌遮擋；橫向本家卡上移避免蓋住手牌。 |
| 動畫 | 原先從最新一筆文字紀錄推測吃碰槓，補花可能蓋掉動作。改成比對副露變化，在動作者位置出現粒子與座位閃光。胡牌時桌上揭示贏家手牌；邀請加入與重連按鈕啟用音訊，保留減少動態效果設定。 |

七搶一判定依 [神來也官方台表「七搶一」分支一](https://www.gamesofa.com/mj/?op=rule_guide&topic=k)，其補牌成胡範例明列槓開、暗刻台與單一付款者。其餘桌規差異沿用 [既有研究](127-jade-table-research.md)，不宣稱全台統一標準。

## 驗證

- `node --test server/jade-table/game.test.mjs`：兩項既有測試通過，補入本次花胡計分、提早胡牌／較近攔胡、四座位投影及席位接管斷線的回歸檢查。沒有引入測試框架。
- 100 局四 AI 模擬、6,109 次狀態轉換：每次總牌數保持 144、每局分數總和保持 4,000，全部結束。這是一次隨機抽樣，不等於窮舉全部牌型。
- 本機四個瀏覽器分頁：同房入座、開局、四方暱稱／門風／手牌位置、南家重新整理後連回原席位，沒有記錄到瀏覽器錯誤。兩伺服器測試另檢查他家暗手不外送、越權出牌被拒絕與跨實例重連。
- 390 × 844 直向、844 × 390 橫向，以及桌機：使用獨立暫存密集牌桌檢查遮擋，觸控寬度各為 52 與至少 44 像素、無水平溢出。暫存頁未納入網站。
- 固定暗槓→補東→自摸：動作文字與座位提示出現、結算逐家六台 220 分，沒有記錄到瀏覽器錯誤。

## 尚未涵蓋與後續優先順序

1. AI 仍為既有簡單牌形策略，未加入向聽數、進張與危險牌判斷。若要提高長期單人可玩性，這比再增加大面積特效更值得優先做。
2. 未進行真實行動網路封包遺失、跨國延遲、大量房間或長時間資料庫負載測試。現在的每秒跨實例同步適用於既有小型好友房目標，不能據本次測試宣稱大型服務容量。
3. 未量測低階手機幀率；視覺檢查確認了操作銜接與版面，並非效能基準測試。
