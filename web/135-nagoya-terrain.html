02 / ALIGNMENT

對得上，才是真實地景。

PLATEAU 輪廓＋空照GSI 空照

同一個原點，同一個投影。

所有資料先轉入 JGD2011 平面直角座標系第 VII 系，再扣除體育館的東向、北向座標。空照的每個像素也反向取樣到同一網格，不以經緯度直接當公尺。

保留高度，移除座標大數。

地面原點標高為 13.56 m。地形與建物一起扣除這個值，Blender 的 X 向東、Y 向北、Z 向上；每一單位就是一公尺。

檢核紀錄 / 體育館中心、天守與本丸周邊輪廓已視覺比對，未見明顯整體旋轉或平移；護城河與城郭在渲染上也與空照位置相符。這是視覺檢核，並非測量精度認證；樹冠、攝影視差與資料年代仍會造成局部差異。

03 / PROVENANCE

每一層，都有來處。

01 — ELEVATION

國土地理院 · 標高

DEM5A（基盤地図情報，原始網格 5 m）；缺值以 DEM10B（10 m）補齊。使用 z15／z14 的 EPSG:3857 XYZ 高程磚，解碼公分值後雙線性取樣，建模網格為 10 m。高程為標高，不把它當橢球高。

02 — ORTHOPHOTO

國土地理院 · 空中写真

全国最新写真（シームレス），EPSG:3857，z17 在中心約 0.98 m／像素。重投影成 2048² 貼圖（約 0.977 m／像素），UV 與地形共用同一個公尺方格。拼接照片不代表同一拍攝日期。

需要 Python 3.11+、Blender 4.5+ 與 curl。解壓縮腳本後執行；重新抓取官方資料、生成分層模型，再自動標註渲染圖。地名不明確時，腳本會要求指定經緯度。

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py --place '愛知県体育館' --radius 1000

更換地名時會嘗試查詢中心、對應城市的 PLATEAU 資料集與日本平面投影；若地名不唯一或資料不支援，會停止並提示需指定的參數。完整限制列於壓縮檔 README。生成在獨立 Blender 背景程序中進行。
