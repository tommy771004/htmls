「這裡」，其實不只一個地方。

你看到的是桌面介面；檔案與指令有自己的工作環境；產生回應的模型則透過服務連接。這座模型把三者放在同一張地圖，讓彼此的關係變得可見。

FOLLOW A REQUEST

送出一句話，接下來呢？

模擬一次需要讀取檔案的請求。流程時間為示意，不代表實際延遲。

  1. 組合上下文
  2. 模型提出工具呼叫

  4. 結果回到模型

準備就緒。這個展示不會發送 API 請求或讀取你的檔案。

FIELD NOTES / 空間筆記

知道邊界，
才知道自己在哪裡。

01 — 介面

對話發生的地方

此頁取材自 Codex 桌面的本機工作情境。輸入、對話、預覽與檔案檢視，是人與代理協作的入口。

02 — 工作區

能留下成果的地方

製作時的專案是 htmls，使用 zsh 執行命令。檔案存在工作目錄裡；這些是製作情境的紀錄，並非正在偵測讀者電腦。

03 — 工具

行動有明確的邊界

模型提出工具呼叫，由工作環境執行並回傳結果。檔案、終端與瀏覽器各有角色；外掛工具也可能連接其他服務，不能都視為本機執行。

04 — 上下文

知道的，是被提供的

訊息、指令與工具結果組成可用上下文。模型不會因為連上工作區，就自動讀過所有檔案；需要透過讀取與查詢取得內容。

05 — 模型

地理位置仍然未知

模型服務在圖中以球形核心表示。無法從此對話確認實際資料中心、GPU 型號或推論節點；機櫃與核心不是實際硬體重建。

06 — 往返

回應可能經過很多次迴圈

遇到需要工具的工作，模型會根據結果繼續處理，也可能再次呼叫工具。展示只取一次讀檔的簡化流程；有些回答不需要工具。
