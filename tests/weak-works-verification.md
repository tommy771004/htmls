## 重跑

需要 Node.js 與 Playwright。測試自行啟動僅綁定 `127.0.0.1` 的臨時 HTTP server，使用隔離瀏覽器 context，不讀取使用者瀏覽器資料。輸出與截圖寫入 OS 暫存目錄，結束時印出路徑。

若專案環境已可匯入 Playwright：

```sh
node tests/weak-works-regression.mjs
```

也可以指定既有安裝，不必修改專案依賴：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
BROWSER_EXECUTABLE='/absolute/path/to/Chrome' \
node tests/weak-works-regression.mjs
```

迷宮物理測試以測試專用 route 在記憶體內暴露狀態；發佈頁面沒有測試入口。
