## 重跑

使用已安裝的 Playwright 執行：

```sh
node tests/bloom-desktop-regression.mjs
```

若使用獨立 runtime，設定 `PLAYWRIGHT_MODULE` 為 Playwright 的 `index.mjs` 路徑、`BROWSER_EXECUTABLE` 為 Chrome 執行檔路徑。腳本自建臨時本機 HTTP 伺服器並自動關閉；截圖輸出至系統暫存目錄。

## 功能範圍

這是獨立單檔 Web 桌面。瀏覽器提供內建離線網站與 `file:///` 虛擬文件閱讀，不載入網際網路網站；終端機執行模擬檔案指令，不執行主機程式。方塊原野為 24 × 24 格的創造模式，支援飛行、碰撞、五種材質、挖掘與建造，需 WebGL。音樂由振盪器與噪聲合成，需使用者按播放啟動。

文件、設定與世界儲存在本機 localStorage。不可用或額滿時通知使用者，保留記憶體內資料並可匯出；清除網站資料會清除保存內容。記事本對未儲存內容提供關窗／切換文件提醒。
